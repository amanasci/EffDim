Build the measurement half of the phase: the a-posteriori chart pruning, the chart-transition cycle
residual, the paper's topology-preservation measures, and the geodesic-distortion statistic that
keeps this representation comparable with 02.1's.

Purpose: two of D-09's three load-bearing gating metric families — the chart-transition cycle
residual and the geodesic distortion — and every non-gating reported quantity are computed by the
functions in this plan. The pruning tolerance that yields D-06's a-posteriori chart count is here
too. The single highest-leverage detail in the whole phase lives here — the
geodesic-distortion metric must be computed on the initial encoder's global embedding, never on
chart-local coordinates, because coordinates from different charts are in unrelated
parameterisations and a pairwise distance between them carries no geometric meaning. Getting that
wrong would silently corrupt the phase's primary comparability metric while producing plausible
numbers.

Output: `notebooks/pu_manifold/cae.py` complete, and `notebooks/pu_manifold/tests/test_cae.py`
carrying a known-answer test for every metric.

  <action>
Add `chart_survival(model, prune_tol)` to `notebooks/pu_manifold/cae.py`.

For each chart decoder, compute the per-layer largest singular value with
`torch.linalg.matrix_norm(layer.weight, ord=2)` exactly as the Lipschitz penalty does, then take
the **sum of the natural logarithms** of those values in float64 as that chart's log-mass. Working
in log space is the contract, not an optimisation: a chart decoder with several layers each of
small spectral norm produces a product that underflows to exactly zero in float32, which would
report a live chart as dead and silently change the surviving count that CAE-05 reports as an
outcome.

The pruning rule compares each chart's log-mass against the largest chart's log-mass: a chart is
pruned when `exp(log_mass_alpha - log_mass_max)` is **strictly less than** `prune_tol`. A chart
whose ratio is exactly `prune_tol` is not pruned — this mirrors the strict-less-than discipline the
gate verdict uses throughout, so a value sitting exactly on a stated tolerance never clears it by
accident in one direction and gets caught by it in the other.

Return a dict with `n_charts_initial`, `n_charts_surviving`, `surviving_indices`, `pruned_indices`,
`chart_logmass` as a float64 numpy array, `chart_mass_ratio` as a float64 numpy array, and
`prune_tol`. All scalars are native Python types so the result serialises straight into the verdict
artifact.

`n_charts_surviving` equals `n_charts_initial` minus one;
`test_pruning_boundary_is_strict_less_than` — construct two charts whose mass ratio is exactly the

Add the remaining evaluation functions to `notebooks/pu_manifold/cae.py`.

`unfaithfulness_coverage(model, x_train, surviving_indices, n_samples, seed)` implements eqs. 20 and
21. Draw `n_samples` points uniformly in the chart space of the surviving charts, decode each
through its chart decoder and the shared embedding decoder, and for each decoded sample find its
nearest training point. Unfaithfulness is the mean squared distance from each decoded sample to
that nearest training point; coverage is the number of *distinct* training points that are some
sample's nearest neighbour, divided by `n_samples`. Return both as native floats along with
`n_samples` and the distinct-count. These are CAE-05's reported, non-gating topology-preservation
measures; the paper's own runs used a hundred samples, and the pre-registered value here is larger
for a less noisy coverage estimate — record the value used.

`fit_global_scale(d2_rep, d2_geo, mask)` returns the single scalar `median(d2_geo[mask] /
d2_rep[mask])`. This is the one global isotropic degree of freedom the pre-registration grants,
fitted on training-split pairs only and then applied to every pair. A neural encoder carries no
constraint tying its output scale to the geodesic scale, unlike the classical and Krein coordinates
02.1 measured, whose scale comes from the eigendecomposition by construction; without this one
disclosed scalar the statistic would be dominated by an arbitrary global factor and would measure
nothing about geometry.

`embedding_distortion(z, geo_pairs, rows, cols, train_mask)` computes the T1 statistic. It takes
`z`, the initial encoder's output for all rows, forms the squared representation distances for the
supplied pair arrays, squares the geodesic array before use because the cached array holds
**unsquared** geodesic distances despite the `r2` in its name (that `r2` refers to the pair-draw
seed, not to squaring), fits the global scale on the pairs whose both endpoints are in the training
split, applies it, and delegates to `geometry_probes.distortion_stats`. Return that function's dict
plus `global_scale_factor` and `n_pairs`. Import `distortion_stats` and `draw_geo_pairs` from
`geometry_probes` — every piece of this evaluation machinery already exists, tested, from Phase
02.1, and reusing it verbatim is what keeps the number bit-comparable with 02.1's own measurement.

The input to this statistic is the initial encoder's global embedding and never a chart-local
coordinate. Two points assigned to different charts have coordinates in unrelated parameterisations,
so a pairwise distance between them carries no geometric meaning; the initial encoder's output is
the one global, near-isometric coordinate system a Chart Auto-Encoder produces, and it is the
correct analogue of 02.1's classical and Krein coordinates. Guard the function against misuse by
raising when the supplied array's feature dimension equals the model's chart dimension while
differing from its embedding dimension, with a message naming the reason.
