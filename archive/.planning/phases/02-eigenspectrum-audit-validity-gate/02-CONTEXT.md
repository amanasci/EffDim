<decisions>
## Implementation Decisions

### Gate verdict rule (SPEC-02/03/06)

- **D-01:** Verdict = worse of two statistics from the full spectrum:
  `r = |λ_min_neg|/λ_max_pos` (catches one large negative; PITFALLS.md Pitfall 3) and
  `m = Σ|λ_neg|/Σ|λ|` (catches the long diffuse tail r reads as clean — 500 negatives at
  0.01·λ_max pass on r). r under ~0.1 is the conventional negligible-non-Euclideanity reading. Rejected: r alone; a
  three-statistic panel.
- **D-02:** Fixed pre-registered literal thresholds:
  | verdict | condition |
  |---|---|
  | PASS | `r < 0.10` and `m < 0.05` |
  | MARGINAL | `r < 0.25` and `m < 0.15` |
  | FAIL | otherwise |
  One-way: fixed before the spectrum is seen; later change = documented amendment. Rejected: stricter
  cutoffs (r<0.05/m<0.02); empirical calibration (costs 2+ extra fits).
- **D-03:** Pre-registration mirrors §4.0: a §6.0 constants cell + cell-index assertion, literals
  copied verbatim into gate_verdict.json. Rejected: git-committed constants module; both.
- **D-04:** Verdict is spectral only. Phase 1 flags (`short_circuit_risk=False`,
  `k_auto_extended=False`, `n_components_no_headroom=True`, `k_star=15`, `fit_key`) are provenance,
  never move the verdict.

### Elbow, frozen d, re-fit branch (SPEC-04/05)

- **D-05:** Elbow = kneedle/max-curvature (normalize axes, max distance from chord), deterministic;
  d-axis sweep range pre-registered in §6.0. Rejected: residual-below-constant; largest eigengap.
- **D-06:** Both curves computed and plotted: Tenenbaum `1−R²(D_geo, D_emb)` (elbow source) and
  eigenvalue `1−cumsum(λ_pos)/Σλ_pos` (cross-check). Divergence reported as a non-Euclideanity
  signal, not just plotted. Consequences: eigenvectors needed beyond d=18 (D-10); R² needs point-pair
  subsampling at n=10,000.
- **D-07:** Elbow ≤ 18: freeze d=elbow, slice columns 0..d-1 of the cached embedding — classical-MDS
  nesting makes the slice the exact d-dim solution; state the argument in the notebook. Smaller d:
  better-conditioned first fundamental form (CURV-04), tighter coordinate support (CURV-08). One-way:
  changing d after Phase 3 invalidates decoder, curvature field, every MKNN number. Rejected: d=18
  always; elbow-with-floor.
- **D-08:** Elbow > 18: halt, human decides. Message states elbow, required n_components, cost
  (fresh fit, minutes, ~1.55 GiB, new fit_key), exact constant to change. Live branch —
  `n_components_no_headroom=True`. Rejected: auto-re-fit; pre-emptive n_components=40.

### Spectrum computation (SPEC-01)

- **D-09:** In-place mean-form double-centring (≡ `-0.5·J D² J`, avoids two dense GEMMs); guarded by
  equivalence assert on a small random matrix. Rejected: literal J matmul; float32 (its ~1e-7 error
  lives exactly where r/m are measured).
- **D-10:** Split eigensolve: `eigvalsh(B)` for all 10,000 values; `eigh(B, subset_by_index)` for
  top-K eigenvectors (K = pre-registered sweep ceiling; LAPACK syevr, deterministic). Rejected: one
  full eigh; reusing the 18-column embedding_ (curve couldn't extend past d=18).
- **D-11:** Spectrum persisted via `npz_cache`, cfg = fit_key + K ceiling; <10 MB; warm re-runs skip
  LAPACK.
- **D-12:** `joblib.load(..., mmap_mode="r")`, drop the Isomap object before centring, print peak
  RSS. Rejected: plain load; hard RAM pre-flight assert.

### Verdict artifact and enforcement (SPEC-06/07)

- **D-13:** Artifact = `notebooks/.cache/gate_verdict_{fit_key}.json` via `json_cache`. fit_key
  keying binds verdict to audited fit — no stale PASS after a re-fit. Accepted cost: cache
  gitignored, regenerated by whoever runs the notebook. Rejected: committed unkeyed copy; both.
- **D-14:** Enforcement inline in the downstream notebook's first cell; **no new pu_manifold
  module** (user decision). Accepted cost: gate rule lives in prose, consumers re-implement and can
  drift — mitigate with a copyable self-contained block + D-16's schema. Do not swap the module back.
- **D-15:** MARGINAL proceeds, but verdict + r/m re-printed at the top of the downstream notebook
  and carried into every downstream artifact. Rejected: ACK_MARGINAL constant; MARGINAL-as-FAIL.
- **D-16:** Artifact self-contained: verdict, r, m, thresholds verbatim, elbow + criterion, frozen d,
  sweep range/K ceiling, fit_key, k_star, flags, timestamp, versions; on FAIL the remediation list
  (re-fit different k / resample new seed / accept documented FAIL) in both artifact and halt
  message. *Planner note:* the rejected FAIL-path test deserves a second look — SPEC-07's halt will
  likely never fire on real data and D-14 removed the testable module.
