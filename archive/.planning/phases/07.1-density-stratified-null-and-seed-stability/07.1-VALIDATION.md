## Sampling Rate

- **After every task commit:** Run the targeted test file for that task
  (`test_density_stratified_null.py`, or the extended `test_crossmodal_curvature_run.py` /
  `test_crossmodal_curvature.py`).
- **After every plan wave:** Run `.venv/bin/python -m pytest notebooks/pu_manifold/tests/ -q` —
  expect the 157 existing tests plus the new ones, all passing, 0 skipped beyond the pre-existing
  CUDA skip.
- **Before `/gsd-verify-work`:** Full suite green, **plus both D-18 no-op proofs** (the `--mode
  smoke` distinct-count comparison and the WR-01 guard-non-firing tests) before either verdict is
  trusted.
- **Max feedback latency:** targeted file < 60s; full suite measured at Wave 0.
