`plant_positive_control`'s loop: for each target, `low, high = 0.0, 2.0`; 40 bisection steps on
`mid = (low + high) / 2`, comparing an achieved statistic against the target; then `slope = high`,
one final `_planted_array` draw, an achieved value recorded (never silently substituted), a
`_relative_precision_distinct_count` of the planted array, and a null call. D-04 changes only the
achieved-statistic call and the null call — the planting mechanism itself does not change,
because bisection converges on whatever metric is evaluated.
