SPLIT. `TRAIN_FRACTION = 0.7`, `SPLIT_SEED = 20260824`, `SPLIT_RULE` = one permutation of
`np.arange(10000)` under `np.random.default_rng(SPLIT_SEED)`, first 7,000 indices train, last 3,000
test, both index arrays returned sorted ascending. ONE split, shared by all three seeds' bucketings,
so the three per-seed verdicts differ only in how the same held-out residuals are bucketed and never
in which points were held out. Deliberately not stratified by bucket, because stratifying would
manufacture the equal per-bucket test counts that D5-08 exists to check for rather than assume.

REGULARIZATION. `RIDGE_ALPHA_GRID = (1e-2, 1e-1, 1e0, 1e1, 1e2, 1e3, 1e4)`,
`ALPHA_PER_TARGET = False` (one shared alpha across all 768 outputs), `FIT_INTERCEPT = True`,
`RIDGE_SELECTION_RULE` = scikit-learn RidgeCV's efficient generalized leave-one-out cross-validation,
evaluated on the training split alone, selecting one alpha from the frozen grid. The GRID and the RULE
are frozen; the selected alpha is an OUTPUT and is reported, never pre-specified. If the design matrix
is well-conditioned in practice, the rule selects a near-zero alpha and degrades gracefully to OLS, so
A2 cannot silently distort the result.

RESIDUAL METRIC. `RESIDUAL_METRIC = "squared_l2_per_point"` — per-point
`r_i = sum_j (y_ij - yhat_ij)^2` — paired with `R2_MULTIOUTPUT = "variance_weighted"`. This is the one
pairing that satisfies 05-CONTEXT.md's "R-squared and per-point residual derivable from one underlying
quantity" constraint exactly, because the variance-weighted aggregate is
`1 - sum_i r_i / sum_i ||y_i - ybar||^2`, the same numerator as the per-point residual. Uniform
averaging across outputs does not share that numerator and is rejected. `05-01` Task 2 pins the
