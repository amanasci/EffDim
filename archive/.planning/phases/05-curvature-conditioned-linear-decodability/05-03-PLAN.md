<per_seed_promotion>
The phase's identity model changes with this plan: the verdict-bearing noun was **the field** and is
now **(seed, field)**. Every rank statistic, every bucket label, every bucket edge set, every
size-matched check and every verdict below the phase level now carries a `seed_stem`.

The correct move is **promote, not add-alongside**: the per-seed field is promoted to primary and the
pooled field is removed entirely. Adding a pooled field alongside three per-seed fields would let a
later reader treat the pooled number as the headline and the per-seed spread as a footnote — which is
exactly the assertion of seed agreement `05-02` measured to be absent. `pool_seed_fields` survives in
`notebooks/pu_manifold/linear_probe.py` as unused, tested code (CLAUDE.md: additive only), but nothing
in Phase 5 calls it and `--mode pool` refuses by name.

Invariant that keeps the promotion from silently reverting: **no phase-level row can exist without
three per-seed rows beside it.** Task 1 encodes it as a test on `combine_seed_verdicts` (exactly three
seeds required, `ValueError` otherwise); `05-05` re-asserts it on the emitted JSONL.
