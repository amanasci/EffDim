## Manual-Only Verifications

- **GEOM-01:** check each method against its own solver; the sharp claim — PSD-constrained
  (LLE/HLLE/LTSA/Laplacian-eigenmaps/MVU) and probability-based (t-SNE/UMAP) methods *cannot
  expose* a negative-eigenvalue statistic, so a clean plot is not evidence.
- **GEOM-02:** each branch carries assumptions, cost at n=10,000, implementation state, Phase 3
  demand; the coordinate-producing vs graph-native fork is stated.
- **GEOM-03:** Cailliez/Lingoes/clipping named diagnostic-blind by construction; judgment
  consistent with GEOM-04's choice.
- **GEOM-04:** read as the Phase 3 planner — can PLAN.md be written from it? The
  extrinsic/intrinsic consequence of the chosen branch must be explicit.
- **GEOM-05:** D_FROZEN=5 not simply declared wrong (curved targets can need fewer dims);
  dimension re-derived from the chosen representation's own diagnostic.
