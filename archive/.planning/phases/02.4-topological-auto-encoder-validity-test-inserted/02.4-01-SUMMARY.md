# Phase 02.4 Plan 01: End-to-End TopoAE Slice Summary

**`notebooks/pu_manifold/topoae.py` implements 0-dim persistence (hand-rolled Union-Find/Kruskal MST, lexicographic tie-break), the symmetric topological loss with live gradients, and a `train_topoae` loop mirroring `cae._train_decoder_protocol` -- proven end-to-end on a synthetic fixture and hardened with 11 passing tests covering R1's determinism/batch-floor and R2's reproducibility/non-finite-halt requirements.**

- **Completed:** 2026-08-06T22:54:48-04:00

## Accomplishments

- Implemented the phase's only genuinely new algorithmic code: `persistence_pairs` (0-dimensional persistence via a hand-rolled Union-Find/Kruskal MST, verified against the paper's own reference implementation per RESEARCH.md) and `topological_loss` (the paper's `match_edges="symmetric"` two-directional loss, gradients flowing through edge lengths, never edge selection)
- Implemented `train_topoae`, mirroring `cae._train_decoder_protocol`'s single-stage seeding/batching/three-way-stopping discipline (not `cae.train_cae`'s two-stage FPS structure, since a TopoAE has no charts) -- `drop_last=True`, D-15's λ warm-up-then-ramp-then-constant schedule, and a `ValueError` halt naming the epoch and batch on a non-finite loss
- Proved the whole computational path end-to-end on a synthetic fixture: persistence pairing → topological loss → a real training run → baseline-relative T1/T2/T3 stand-ins → a verdict → a `topoae_verdict_tracer.json` artifact under a `tmp_path`-scoped cache dir
- Hardened R1: deterministic tie-break across 10 in-process calls and a fresh subprocess on a hand-built tied fixture, the batch-size-2 floor (1 raises, 2 succeeds), spanning-tree correctness (edge count, no cycles, full vertex coverage) on a random 40-point fixture, float32-input up-cast equivalence, and gradient isolation to exactly the MST-selected distance-matrix positions
- Hardened R2: bit-identical `history` and `reconstruction_stats` across two runs at the same seed (exact `==`, no tolerance), a different seed provably changing the history, the λ schedule's exact-0/strictly-increasing-ramp/exact-constant shape, a short final batch (`n % batch == 1`) completing training while `persistence_pairs` is spied on and never called below 2 points, and an empirically-confirmed non-finite-loss halt
