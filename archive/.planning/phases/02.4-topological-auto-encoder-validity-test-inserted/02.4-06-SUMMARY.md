## Issues Encountered

- Building the registry-audit script for Task 3 initially globbed
  `topoae_fit_meta_{FIT_KEY}_amend01_*.json`, which also matched each artifact's own
  `*.meta.json` cache-manifest sidecar (a cfg-only file with no `epochs_run`/`history` keys).
  Because `"json" < "meta.json"` lexicographically, the sidecar sorted after the full artifact
  and silently overwrote it in the audit dict, producing a `KeyError: 'epochs_run'` on the
  next access. Fixed by excluding `*.meta.json` explicitly in the glob loop. This is a
  one-off scripting mistake in this plan's own verification tooling, not a defect in
  `notebooks/pu_manifold/cache.py` or the runner -- noted here because it is exactly the kind
  of silent-wrong-file failure mode `cache._manifest_matches`'s raise-on-mismatch guard exists
  to prevent for the *cfg* dimension, and this was its filename-glob analogue in throwaway
  audit code, not a cache-contract violation.
