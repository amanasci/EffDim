<decisions>
## Implementation Decisions

### T1 — the topological fidelity statistic

- **D-01:** T1 is **the paper's `L_t` evaluated on held-out data**, not a combinatorial matched-pair
  fraction and not a Wasserstein diagram distance. Measures the method's own claim and stays
  comparable to published numbers. — **Reversibility:** one-way — once the threshold is committed
  with git-ancestry proof, changing which statistic gates is post-hoc metric selection, the exact
  move the milestone's pre-registration discipline exists to prevent.
- **D-02:** T1's threshold is a **baseline-relative margin** over the matched-capacity
  `cae.PlainAutoEncoder`, not an absolute number. Self-calibrating, needs no value invented for data
  it was never measured on, and reuses the "must beat, not tie" rule 02.2 established as CAE-03.
- **D-03:** T1 **gates on the MST over the entire held-out set** in one pass (n ≈ 2,000, a trivial
  2,000×2,000 matrix), because that captures *global* topology — a latent can preserve every
  64-point neighbourhood while scrambling how regions connect. The batch-wise average at training
  batch size is **reported, non-gating**, for consistency with how the loss was optimised.
- **D-04:** `L_t` is a sum of two directional terms. They are **computed separately and the worse
  one gates** — not summed then compared. Input→latent catches destroyed structure, latent→input
  catches invented structure; these are different failures. Matches the worse-of-two rule Phase 2's
  gate already applies to `r` and `m`.
- **D-05:** Latent coordinates are **normalised to unit variance** before `L_t` is computed, rather
  than fitting a global scale from the target as `cae.fit_global_scale` does. Nothing is fitted from
  the target, which is cleaner. **Stated cost:** 02.4's T1 number is therefore **not** directly
  comparable to 02.2's CAE distortion figure — a different normalisation means a different
  statistic. Record this in the pre-registration so no later reader compares them.
  — **Reversibility:** costly — switching to `fit_global_scale` after thresholds are committed would
  require re-deriving the T1 margin and re-running every fit.

### T3 — the rank-structure measure

- **D-06:** T3 is **`min(trustworthiness, continuity)`** at the gating `k`. Both are bounded [0,1],
  both are reported by Moor et al. themselves so the numbers are citable, and the worse-of-two rule
  matches T1 and Phase 2's gate.
- **D-07:** **`k` sweep over {5, 15, 30}, gating at `k = 15`.** 15 is `k*` — the neighbourhood size
  the Isomap graph behind every geodesic in this milestone was frozen at by 01-04's pre-registered
  plateau rule — so the gating `k` inherits an existing justification. The other two rungs are
  sensitivity, showing whether the verdict is an artifact of one neighbourhood scale. Ranks are
  computed once, so the sweep is near-free.
- **D-08:** T3's threshold is a **baseline-relative margin**, consistent with T1 and T2.
- **D-09:** T1 and T3 **gate independently, with their overlap documented**. Both are two-sided and
  may correlate — T1's MST measures the *connectivity skeleton*, T3 measures *local neighbourhood
  ordering*, and a latent can preserve one while breaking the other. The pre-registration states
  plainly that a joint FAIL on both is **one** structural finding, not two independent ones.
- **D-10:** T3 is *higher-is-better* but `cae.verdict_from_metrics` applies **strict less-than**.
  Express the gating quantity as `1 − min(trustworthiness, continuity)` so the comparison runs the
  same direction as T1 and T2. 02.2 hit this exact issue with its reconstruction margin and inverted
  the quantity for the same reason.

### Batch size and loss weighting

- **D-11:** **λ is tuned on the Swiss roll fixture, then frozen** in `02.4-PREREGISTRATION.md`
  before any PU fit. Legitimate because the fixture is not the gate data. **Stated risk:** a λ tuned
  on a 2-d sheet in 3-d may not transfer to a ~20-d manifold in 768-d; the pre-registration must say
  so. — **Reversibility:** one-way — λ moves T1 and T2 in opposite directions, so re-selecting it
  after any gate result is seen is precisely the post-hoc tuning SPEC prohibition 1 forbids.
- **D-12:** **The λ sweep lives in a separate `notebooks/diagnostics/` runner, NOT inside the
  sanity-check notebook.** `CLAUDE.md` caps that notebook at ~15 cells with no threshold tables and
  no pre-registration apparatus; a sweep inside it would break those rules. The sweep runner and the
  sanity-check notebook share the same Swiss roll generator; the notebook consumes the frozen λ.
- **D-13:** **Phase task order is inverted from the obvious one.** Swiss roll fixture → λ sweep → λ
  frozen → `02.4-PREREGISTRATION.md` committed → only then any PU fit. The git-ancestry ordering
  proof still holds, but the planner must not assume the pre-registration comes first.
- **D-14:** **Batch size 64**, matching 02.2 under the same compute ceiling on the same data — keeps
  the two experiments comparable on training protocol, and the per-batch distance matrix stays a
  trivial 64×64. Pre-registered as a **method constant, not a tunable**: the MST is built per batch,
  so batch size sets the scale of topology the model can learn.
- **D-15:** **λ warm-up then constant.** Reconstruction-only for a stated number of epochs, then ramp
  λ to its frozen value, so the topological term cannot dominate before the latent means anything.
  Adds two constants — **warm-up length and ramp shape** — both of which must be pre-registered and
  reported in the verdict artifact.
- **D-16:** **The primary rung alone produces the verdict.** A split across other rungs — one
  passing T1 and failing T2, another the reverse — is reported as a measured **T1/T2 frontier**,
  genuinely informative about the method, and never promotes a different rung to primary.
  Pre-registering this is what makes SPEC prohibition 2 (no post-hoc primary-d selection)
  enforceable rather than aspirational. — **Reversibility:** one-way — same garden-of-forking-paths
  exposure as D-11.

### Latent ladder, primary dimension, and seeds

- **D-17:** **Ladder = {8, 16, 20, 24, 32, 40}, primary `d = 20`.** Each end of the range answers a
  prior claim: 8 is 02.1's coordinate-branch elbow (`classical_p`), 40 tests the dimension-starvation
  finding directly (`02-FINDINGS.md` §6.4 — 100% of neighbourhoods needed more than 18 dims for 90%
  local variance, so every fit this milestone has produced may have been starved). Primary 20 sits
  inside the measured local intrinsic cluster (TwoNN 19.5, local-PCA median 25.0) **and** matches
  02.2's `D_CHART` exactly, so a TopoAE verdict is directly comparable to the CAE's FAIL at the same
  width. 20 was inserted into the ladder specifically so the primary rung is *in* the sweep — a
  primary outside the ladder would be an unpre-registered configuration.
  — **Reversibility:** costly — changing `d` after training invalidates all fits and thresholds.
- **D-18:** **3 seeds on the primary rung, 1 on each other rung** — 8 fits total. The verdict rests
  on the rung with a variance estimate; the others carry the sensitivity story.
- **D-19:** **Per-fit ceiling cut from 02.2's 2h to ~1h**, via a tighter pre-registered epoch cap, so
  8 fits land at ~8h — back inside 02.2's overnight envelope. **Stated limitation:** the larger rungs
  (32, 40) may be under-trained at that cap, which must be reported as a known limitation of the
  sensitivity rungs rather than discovered afterwards. The primary rung at `d = 20` must be verified
  to converge within the cap before the ladder is committed.
- **D-20:** **The worst of the 3 primary-rung seeds gates each metric**; mean and spread are
  reported. Makes a PASS mean "this works reliably" rather than "this worked once" — and the phase's
  own conclusion about 02.1's decoder check was that single-seed gaps cannot be separated from
  initialisation noise.

### Claude's Discretion

- Encoder and decoder widths and depth (follow `cae.mlp_stack` conventions).
- C2-smooth activation choice (tanh / softplus / SiLU) — required by DEC-02 and CURV-01..03
  downstream; report the substitution and any reconstruction cost, as CAE-06 did.
- Holdout split fraction and seed — pre-registered, but the numbers are the planner's call.
- `topoae_verdict_{fit_key}.json` and `topoae_handoff_{fit_key}.json` schema fields, modeled on
  `gate_verdict_{fit_key}.json` and 02.1's `geometry_handoff_{fit_key}.json`.
- MST implementation details beyond the locked lexicographic `(distance, i, j)` tie-break.
- Warm-up length and ramp shape values (D-15) — chosen by the planner, but pre-registered.
- Ordering of the 8 fits so a mid-run interruption leaves usable state.

## Existing Code Insights

### Reusable Assets

`cae.py` is 1,187 LOC and much of it is already generic. Import, never copy — `cae.py` must stay
byte-identical (SPEC prohibition 5).

- `cae.verdict_from_metrics` — **already threshold-agnostic**: reads a `GATING_METRICS` list and
  applies strict less-than, raising `ValueError` on any absent or non-finite metric rather than
  letting it become a FAIL. Takes T1/T2/T3 unmodified.
- `cae.PlainAutoEncoder` + `cae.train_plain_ae` + `cae._train_decoder_protocol` — the matched-capacity
  baseline for T2, and the baseline `CLAUDE.md` mandates for the Swiss roll notebook. One class
  serves both roles.
- `cae.reconstruction_stats` — aggregate plus per-output-dimension error, which is what T2 needs.
- `cae.embedding_distortion` + `cae.fit_global_scale` — the reported (non-gating) distortion context
  metric. Note `embedding_distortion` squares `geo_pairs` internally because the cached array holds
  unsquared distances.
- `cae.activation_module` — C2-smooth activation selection, already excludes ReLU-family.
- `cae.unfaithfulness_coverage` — the paper-derived topology measures, reported non-gating.
- `cae.to_native` — numpy/torch scalar casting for `json_cache` serialization.
- `cae.write_cae_verdict` / `cae.write_cae_handoff` — artifact writer shape to mirror.
- `geometry_probes.distortion_stats` — the distortion statistic 02.1 validated.
- `scipy.sparse.csgraph.minimum_spanning_tree` — already a dependency, already used in
  `geometry_probes_run.py`. Supplies 0-dim persistence with **no new package**.

### Established Patterns

- Pre-registration committed before evidence, ordering proved by `git merge-base --is-ancestor`
- Machine-readable verdict/handoff JSON keyed by `fit_key`, with thresholds in the `json_cache` cfg
  so a post-hoc edit raises a manifest mismatch instead of silently re-verdicting
- Gitignored `notebooks/.cache/` artifacts: the runner halts if absent rather than regenerating,
  because regenerating changes provenance
- Module + mirrored test file under `notebooks/pu_manifold/` and `notebooks/pu_manifold/tests/`
- No package installs without a blocking checkpoint; venv carries numpy 2.5.1, scipy 1.18.0,
  scikit-learn 1.9.0, torch 2.13.0+cpu, joblib, pytest 9.1.1
- Swiss roll sanity check mandatory for every new manifold model (`CLAUDE.md`), ≤ ~15 cells, no
  cache access, committed with outputs

### Integration Points

- Training data: the frozen Phase 1 normalized subsample, L2-normalized 768-d rows
- T2's baseline and the Swiss roll baseline are the same `PlainAutoEncoder` class at matched capacity
- On PASS: the handoff names what Phase 3 consumes — encoder weights, latent coordinates, primary
  `d` — and carries the DEC/CURV buckets a coordinate-producing win reinstates
