## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gitignored cache → runner | The Phase 1 subsample and the Phase 2 eigenspectrum are irreproducible here; a regenerated substitute would silently change provenance |

| TopoAE cfg → baseline cfg | An under-powered baseline would make every one of the three baseline-relative margins meaningless in the model's favour |
