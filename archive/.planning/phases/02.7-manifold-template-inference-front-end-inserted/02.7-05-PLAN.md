<objective>
Complete D-14's synthetic generator: canonical embedding, random orthogonal lift into `R^D`, a
**named** ratified smooth nonlinear warp, non-uniform sampling and noise — with the **Jacobian
rank checked at sampled points, not assumed**. Plan `02.7-01` built the `S^1` path for the
tracer; this plan adds `S^2`, `T^2` and `ball`, and the rank check for all four.

Purpose: the rank check is non-negotiable and is the reason D-14 rejects a randomly-initialised
net as the immersion. A "random smooth map" that stops being an immersion self-intersects or
collapses a dimension, and then the ground-truth label is **silently wrong** — the benchmark
would be scoring the front end against an answer that is itself incorrect, and every accuracy
number downstream becomes unattributable. There is no way to detect that after the fact.

Output: `template_immersion.py`'s full four-template surface with per-template rank checking,
and the negative-control test.

    `canonical_sample(template, n, rng, d=None)`:
    - `S1` — `p(t) = (cos t, sin t)`, already implemented by the tracer; keep the analytic
      tangent `v(t) = (-sin t, cos t)`, which has no singularity anywhere.
    - `S2` — sample via a **normalized Gaussian**, `u = g / ||g||` with `g ~ N(0, I_3)`. Do not
      use the spherical-angle parametrization: it has a genuine coordinate singularity at the
      poles whose Jacobian drops rank even though `S^2` itself does not, and autodiffing a
      composite through it would misreport a perfectly good rank-2 immersion as rank-1 there.
      The normalized-Gaussian sample has no chart at all to be singular.
    - `T2` — the standard embedding `((R + r cos v) cos u, (R + r cos v) sin u, r sin v)` with
      `R > r > 0` fixed as recorded module constants; its Jacobian never drops rank for any
      `(u, v)` under that constraint, so it is safe to autodiff directly.
    - `ball` — the identity embedding: `B^d` already sits in `R^d`, so there is no
      canonical-embedding step beyond sampling inside the unit ball at the requested intrinsic
      dimension `d`.

    orthonormal complement of `u` for `S2` via a QR, the coordinate directions for `ball`), so
    the rank check in Task 2 never has to re-derive it.

    `random_orthogonal_lift(d_from, D, rng)` — QR of a Gaussian `(D, d_from)` matrix, returning
    the orthonormal `Q`. Assert orthonormality to float64 tolerance before returning.

    not defaults set here.
