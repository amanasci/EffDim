<objective>
Complete D-02's significance instrument: a per-cloud, per-metric bootstrap confidence band
(Fasy et al. 2014), and the Betti-vector reading that consumes it. Plan `02.7-01` created the
thin version for the tracer; this plan makes it the phase's real instrument, with the
known-answer tests that make its output trustworthy.

Purpose: SC-3 already mandates that persistence survive bootstrap/subsampling, so the band is
**one** instrument rather than two. Critically it is derived **per metric** — Euclidean and
graph geodesic have non-comparable filtration scales, and a single hand-set constant would
need a different value for each, which is per-metric tuning through the back door. A
largest-gap cut is undefined exactly where it matters most: when the true Betti number is 0
there is no gap to find and the rule manufactures a cycle, which is the expected PU case.

Output: `confidence_band.py`'s full surface plus `test_confidence_band.py`.

    `bootstrap_band(D, degree, B, alpha, seed)` implements Fasy et al.'s bottleneck bootstrap
    exactly as RESEARCH.md's verified example gives it: `rng = np.random.default_rng(seed)`,
    `idx = rng.integers(0, n, size=n)` — WITH replacement, same size `n` as the original, which
    is the bootstrap and not Fasy's alternative subsampling method — `D_boot = D[np.ix_(idx,
    idx)]`, then `persim.bottleneck` between each replicate's degree-`k` diagram and the
    **original's** (not pairwise between replicates), and `c_alpha` as the `1 - alpha` quantile
    of the `B` bottleneck distances. Return `{"c_alpha", "band", "boot_distances", "B",
    "alpha", "seed", "degree", "n"}` with `band = 2 * c_alpha`. Because the resample operates on
    row/column indices, the identical function serves the Euclidean and geodesic arms with no
    adapter — state that in the docstring, since it is the property that makes D-02's
    per-metric requirement cheap to honour.

    Add `bands_for_diagram(D, maxdim, B, alpha, seed)` returning one band per degree `0..maxdim`
    in a dict keyed by degree, so a caller cannot accidentally apply an `H_1` band to an `H_2`
    diagram. Add `band_spread(D, degree, B, alpha, seeds)` returning the per-seed `c_alpha`
    list plus `{"min", "max", "range"}` — reporting spread, applying no bar, and never
    substituting an average for the individual values. This is the instrument for assumption
    A-04: PH seed/draw variance is still unmeasured in this project, and if it swamps the
    between-template differences that is a finding about the criterion, to be reported rather
    than absorbed.

    `significant_bars(dgm, band)` returns the boolean mask `(dgm[:, 1] - dgm[:, 0]) > band`.
    `betti_vector(dgms, bands)` returns the 3-tuple `(beta_0, beta_1, beta_2)` where `beta_0`
    is the count of significant `H_0` bars **plus 1** — `finite_pairs` has already dropped
    `H_0`'s single true infinite bar, so the `+1` restores the always-present base component —
    and `beta_1`/`beta_2` are the plain significant counts under their own degree's band.
    Validate that `bands` supplies a band for every degree present in `dgms` and raise
    `ValueError` naming the missing degree otherwise.

    Do **not** add a `thresh` parameter anywhere. RESEARCH.md Pitfall 2 verified that
    `ripser`'s thresh-truncated diagrams carry multiple infinite-death bars per degree and that
    `persistence_probe.finite_pairs` would silently discard genuine long-lived features —
    turning a real `S^2`/`T^2` void into an absent one, which is precisely the "wrong template
    with no way to detect it" failure D-03's abstain design exists to avoid. Record that in the
    docstring as the stated reason the parameter is absent, together with assumption A-03: the
    band is this phase's practical stand-in for a sampling-density guarantee and is not a proof
    that the recovered homology is the manifold's.

    Note in the docstring that D-02's band loop and D-08's independent-draw loop are two
    different procedures whose `ripser` costs multiply rather than substitute — `(draws) x (1
    main + B bootstrap) x (2 metrics) x (grid cells)` — so no caller sizes compute by counting
    one of them.
