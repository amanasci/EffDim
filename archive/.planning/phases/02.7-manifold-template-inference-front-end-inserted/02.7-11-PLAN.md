<objective>
SC-6: one read-only probe of the PU embeddings, reporting whatever it finds — including "no
template in library" or "abstain". Sealed fits are read; nothing is refit.

Purpose: this is the only place in the phase where the front end meets real data, and it runs
**last**, after the benchmark has established what the front end's accuracy and abstention rate
actually are — because a PU abstention means nothing without knowing how often the instrument
abstains on clouds whose answer is known.

**The likely outcome, stated in advance so it cannot be read as a failure.** The ROADMAP records
that PU topology beyond connectedness is bounded — no cycle above roughly 3x the manifold's
local thickness at `n <= 2000`, with no power analysis at all for `beta_2`. The expected reading
is `beta_0 = 1`, no persistent `beta_1`, a clean `d_hat` plateau: the **ball** row, a positive
call of the trivial template and not an abstention. If PU is ball-like, "does restricting to a
template help?" has no answer on PU, because there is no non-trivial template to restrict to —
and SC-6 finding exactly that is a complete, reportable outcome that legitimately terminates the
deferred topological-VAE arm. **It is not a failure of this phase.**

The ball row must say *which* ball: D-04's joint key exists so `B^2` and `B^18` are
distinguishable, because they are materially different objects to constrain a VAE to.

Output: `pu_template_probe_run.py` and `02.7-PU-PROBE.md`.

*Planning note: spec-less probe fallback skipped: phase has no requirement IDs to probe
(visible skip).*
</objective>
