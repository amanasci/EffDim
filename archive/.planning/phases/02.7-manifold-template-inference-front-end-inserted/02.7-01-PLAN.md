<objective>
Prove the whole front end end to end on one path before building any of it out: a single
synthetic `S^1` cloud, lifted to **production dimensionality `D = 768`**, measured under both
distance metrics, read through `ripser` at `maxdim=2` (D-11's cap), turned into a per-metric
significant Betti vector, and classified by D-01's Betti-vector lookup. One template, one `k`,
one draw, no sweep, no grid, no tally.

Purpose: an architectural dead-end in this pipeline — a geodesic matrix `ripser` will not
accept, an `H_2` call that will not finish at `D = 768`, a significance band that cannot be
computed per metric — must surface after one commit, not after ten. This is also where the
phase's structural guarantee is installed: **the four new modules carry no default value for
any ratifiable threshold**, so SC-1's "ratified blind" property is true by construction rather
than by discipline.

Output: four new `notebooks/pu_manifold/` modules in thin-but-production form, the geodesic
symmetrization regression test, and a tracer runner that prints one labelled result per metric.
