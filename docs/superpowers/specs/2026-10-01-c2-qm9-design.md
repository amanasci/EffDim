# C2: the paper's battery on QM9 molecules

Date: 2026-10-01
Branch: `c2-qm9` (from `encoder-scaling@928b61c`)

## Goal

Test whether the paper's claims — the mismatch partial, the counterfactual help/hurt asymmetry and the
thinned sign test — hold in a domain unrelated to galaxies: SMILES-model embeddings of QM9 molecules with
DFT labels. This is sub-project C2 (for the extended version; not a rebuttal item). It reuses C1's sweep
machinery (manifest, job queue, aggregation, runner 11's reproduction guard).

Two Opus design reviews (one per design section) and a domain review shaped this spec; their findings are
folded in.

Success criteria:

1. The molecule table has N = 130,744 rows with the drop counts below, and its sha256 is pinned.
2. All 8 embeddings pass validation, the determinism check and the batch-invariance check; their sha256s
   are pinned in `molecules.yaml`.
3. `molecules_d.json` (d per encoder) is committed before the first probe record exists; every probe
   record carries its sha256.
4. Every probe job finishes; every `robust` guard passes in exact mode.
5. The molecule report regenerates byte for byte from the records (pinned test); the synthetic ID bias
   table and per-job wall time and peak RSS are in the report.
6. The galaxy side is unchanged: the CPU equivalence gate (`docs/superpowers/harness/gate.sh`, GATE PASS)
   holds, the galaxy job argv tests pass, and the committed C1 report still regenerates byte for byte.
7. `paper/latex/main.tex` is unchanged.

## Decisions

| Topic | Decision |
|---|---|
| Data | HF `yairschiff/qm9` at a pinned revision; HF row i is QM9 index i+1 |
| Molecules | drop the 3,054 uncharacterized (figshare file 3195404, pinned sha256), RDKit-canonicalise, dedup on the canonical string keeping the lowest index: N = 130,744 |
| Labels | gap (primary; Hartree converted to eV), mu (Debye), alpha (bohr^3), cv (cal/mol/K) |
| Encoders (8) | DeepChem/ChemBERTa-5M-MTR, -10M-MTR, -77M-MTR, -10M-MLM, -77M-MLM; ibm-research/MoLFormer-XL-both-10pct; ChemFM/ChemFM-1B, ChemFM/ChemFM-3B |
| Embedding | float32 everywhere; masked mean of the last hidden layer (special tokens included, stated); right padding; pad = eos where a model has none; pinned model revisions and a pinned `transformers`; MoLFormer `trust_remote_code=True`, `deterministic_eval=True` |
| Weights | downloaded to `/tmp/effdim-hf` on the pod root disk (`cache_dir` passed explicitly), deleted after each model |
| Protocol | unchanged: row-normalised embeddings on the unit sphere, sphere-projected decoder, 512 anchors, k = 2048, alpha = 100 plus tuned alpha* (runner 11), multi-scale controls |
| d | d_ID = round(median of mle, two_nn, tle, mind_mlk) on a pinned 10k subsample; run at d = min(d_ID, 20); a d = 16 run for all 8 encoders as the common baseline |
| Battery | per encoder at d = min(d_ID, 20): main_xfit, seed1, seed2, cf, thin, robust; plus main_d16 (split, d = 16), skipped where d = 16 already |
| Reporting | a separate molecule report with pre-stated claims |

## 1. Molecule table — `curvature-experiment/sweep/qm9_prepare.py` (local, CPU)

- Load `yairschiff/qm9` at a pinned revision; QM9 index = HF row + 1 (there is no index column; the rule
  was verified against all 3,054 uncharacterized SMILES).
- Drop the indices in `uncharacterized.txt` (download `ndownloader.figshare.com/files/3195404`, pinned by
  sha256).
- RDKit-canonicalise the GDB17 `smiles` (no stereo in the source); drop any that fail to parse (none
  expected).
- Deduplicate on the canonical string, keeping the lowest QM9 index (87 groups; their label differences are
  printed-precision noise).
- Convert gap from Hartree to eV; keep mu, alpha, cv as given.
- Output `curvature-experiment/data/qm9/qm9_molecules.parquet` (columns `qm9_index, smiles_canonical,
  n_heavy_atoms, gap, mu, alpha, cv`, sorted by `qm9_index`) and `qm9_molecules.summary.json` (revisions,
  sha256s, every drop count, N). Both committed; the table's sha256 goes into `molecules.yaml`.

## 2. Embeddings — `curvature-experiment/sweep/embed.py` (pod GPU, outside the job queue)

- One invocation per encoder: `--encoder`, `--table`, `--out-dir`, `--cache-dir /tmp/effdim-hf`,
  `--batch-size`, `--device cuda`.
- `CUBLAS_WORKSPACE_CONFIG=:4096:8` set before CUDA initialises; `torch.use_deterministic_algorithms(True)`;
  eval mode; float32.
- Tokenise the canonical SMILES with the model's own tokenizer, `padding_side="right"`, attention mask,
  special tokens as the tokenizer adds them; pad = eos when there is no pad token.
- Masked mean over the attention mask of the last hidden state; float32.
- Output `molecules/<encoder>.parquet`, column `<encoder>_molecules` (list<float32>), rows in table order;
  sidecar JSON (model id, revision, `transformers` version, dtype, pooling, padding side, SMILES-list
  sha256, parquet sha256).
- Validation: N rows, all finite, no all-zero row.
- Determinism: the first 2,048 molecules embedded twice must be identical. Batch invariance: one molecule
  embedded alone equals the same molecule embedded in a batch with a longer one (max |diff| <= 1e-6).
- The weights directory is deleted after a successful write; `df -h /tmp` checked before ChemFM-3B (about
  12 GB of float32 weights).

## 3. Code changes for a second domain (default-preserving)

- **Runners** (split, counterfactual, thin, runner 11): `--expected-rows N` (default: the galaxy
  constant) and `--label-map identity` (default: the galaxy map). The loader shims replace
  `pl.LABEL_COLUMN_MAP` with the identity map over `--labels` and `pl.SENTINEL_VALUES` with `()`;
  `load_physics` itself is not changed. Runner 11 gains `--labels` and `--d` (replacing its hard-coded
  `d = 16`, the `d == 16` reference filter and `EXPECTED_LABELS`).
- **Manifest** (`sweep/manifest.py`): optional per-encoder `parquet_file`, `column`, `parquet_sha256`;
  optional top-level `labels`, `label_map`, `expected_rows`, `label_table_sha256`. The galaxy
  `encoders.yaml` loads unchanged. New `curvature-experiment/molecules.yaml`.
- **Jobs** (`sweep/jobs.py`): the encoder's d comes from `--d-file` (`molecules_d.json`); a missing entry is
  an error; geometry filenames and the cf `--d` carry it; `main_d16` added for molecules; every argv
  carries `--d-file-sha256` into the records. Galaxy argv byte-identical (existing tests).
- **Queue** (`sweep/run_queue.py`): `--manifest`; `--timeout-h` (wraps each job in `timeout`); each job
  run under `/usr/bin/time -v` so peak RSS and wall time land in its log; the low-disk latch becomes
  resettable (launches pause while free space is below `--min-free-gb` and resume after pruning).
- **Aggregation**: `extract`/`aggregate` take their label list from the manifest; `--manifest`; a molecule
  report (below). The galaxy report regenerates byte for byte.
- **Setup**: `transformers` pinned in the GPU requirements; `setup_pod.sh` takes `--manifest`, checks the
  molecule table and embeddings by sha256 for molecules, and keeps its galaxy checks for galaxies.

## 4. Intrinsic dimension — `curvature-experiment/sweep/intrinsic_dim.py` (pod CPU)

- Per encoder: row-normalise, pinned 10,000-row subsample, call `effdim.geometry`'s estimators directly
  (`mle`, `two_nn`, `tle`, `mind_mlk` for d; `danco`, `mind_mli`, `ess` recorded; `gmst` skipped for cost).
  d_ID = round(median of the four); d = min(d_ID, 20).
- Synthetic bias check: unit spheres of true dimension 8, 16, 24 in D = 384, 768, 3072, n = 10,000; each
  estimator's bias reported. All read low at higher true dimension; the report says so.
- Reference only: the same procedure on DINOv3-B galaxy embeddings (the white paper's 18 came from a
  different DINOv3 dataset, so this is not a gate).
- Output `curvature-experiment/data/qm9/molecules_d.json` {encoder: {d_ID, d, estimators}}, committed before
  any probe job.

## 5. Run order (each gate passes before the next)

1. Local: molecule table (gate: N = 130,744 and the drop counts). Commit.
2. Local: synthetic ID bias check. Reported.
3. Pod: setup on `c2-qm9`; verify the table's sha256.
4. Pod GPU: embeddings, small models first (gates: validation, determinism, batch invariance). Pin the
   parquet sha256s in `molecules.yaml`. Commit.
5. Pod CPU: intrinsic dimension → `molecules_d.json`. Commit and push before step 6.
6. Pod phase A: ChemFM-3B alone (GPUs 0–3, `--threads 8`, `--timeout-h 8`, `--min-free-gb 10`). Stop and
   report if `robust` exceeds 8 h or any job exceeds 120 GB RSS.
7. Pod phase B: ChemFM-1B alone (same settings).
8. Pod phase C: the six small encoders (8 GPUs, `--threads 3`).
9. Fetch, aggregate the molecule report, regeneration test, commit.

Phases bound how much geometry exists at once (at d = 20: about 0.8 MB x D per file, 2.5 GB for ChemFM-3B);
pruning is on for molecules.

## 6. Molecule report (pre-stated claims)

- (a) mismatch partial negative and significant, per label, at d = min(d_ID, 20) and at d = 16;
- (c) counterfactual help > random help and help > 0.5; (c') reversal hurts; (d) thinned sign test
  p_help < 0.05 — per label;
- alignment reported descriptively (no molecular prior for its sign);
- reproduction guard, staleness, synthetic ID bias table, d per encoder, per-job wall time and peak RSS;
- a heavy-atom-count-only ridge baseline's global R^2 for the size-driven labels (alpha, cv);
- stated limits: ChemBERTa-2's 5M/10M/77M are pretraining-set sizes (same architecture, hidden 384, 3
  layers), so only ChemFM 1B -> 3B is a model-size pair; MTR models were pretrained on RDKit descriptors
  including molar refractivity (close to alpha), so alpha is expected near-linear for them; neighbourhoods
  cover about 1/64 of the data (galaxies 1/42); special tokens are inside the mean pool.

## 7. Tests (TDD, local)

1. `qm9_prepare`: index rule, exclusion by index, canonicalisation, dedup keeping the lowest index, one
   unit-conversion assert, summary counts — on a small fixture.
2. `embed`: masked mean on toy tensors; validation rejects wrong row counts, NaN and all-zero rows;
   right padding and pad = eos; batch invariance on a tiny random `LlamaConfig` model built offline with a
   stub tokenizer.
3. Runner shims: `--label-map identity` and `--expected-rows` with a toy table and embeddings; runner 11
   `--labels`, `--d`; default galaxy paths unchanged (gate).
4. `manifest`: the new optional fields; the galaxy manifest unchanged.
5. `jobs`: d from `--d-file`, missing entry errors, d carried in filenames and `--d`, `main_d16` present
   and skipped at d = 16, galaxy argv unchanged.
6. `run_queue`: `--manifest`, `--timeout-h` wrapping, the resettable disk latch.
7. `intrinsic_dim`: estimator subset, rounding, the cap at 20, the synthetic check on a small sphere.
8. `extract`/`aggregate`: labels from the manifest; the molecule report's claims; the galaxy report still
   regenerates byte for byte.
9. End-to-end CPU smoke: a small synthetic table and embeddings through split → cf → thin → robust with
   the molecule flags.

## Out of scope

Other molecule datasets; middle-layer embeddings; scaffold splits; feature standardisation (it would
