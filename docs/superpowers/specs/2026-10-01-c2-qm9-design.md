# C2: the paper's battery on QM9 molecules

Date: 2026-10-01
Branch: `c2-qm9` (from `encoder-scaling@928b61c`)

## Goal

Test whether the paper's claims — the mismatch partial, the counterfactual help/hurt asymmetry and the
thinned sign test — hold in a domain unrelated to galaxies: SMILES-model embeddings of QM9 molecules with
DFT labels. Sub-project C2, for the extended version (not a rebuttal item). It reuses C1's sweep machinery
(manifest, job queue, aggregation, runner 11's reproduction guard).

A domain review, two Opus section reviews and an Opus spec review shaped this spec; their findings are
folded in.

Success criteria:

1. The molecule table has N = 130,744 rows with the drop counts below; its sha256 is pinned.
2. All 8 embeddings pass validation, the determinism check and the batch-invariance check; their sha256s
   are pinned in `molecules.yaml`.
3. `molecules_d.json` is committed before the first probe record exists; every split, cf and robust record
   carries its sha256 in its environment row.
4. Every probe job finishes; every `robust` guard passes in exact mode.
5. The molecule report (`curvature-experiment/results/qm9/QM9_REPORT.md` and its tables) regenerates byte
   for byte from the fetched records and timing files (pinned test).
6. The galaxy side is unchanged: the CPU equivalence gate passes
   (`CLOSURE_WORK=$HOME/.cache/effdim-closure docs/superpowers/harness/gate.sh <repo> <label>` → `GATE PASS`),
   the galaxy job argv tests pass, and the committed C1 report still regenerates byte for byte.
7. `paper/latex/main.tex` is unchanged.

## 1. Molecule table — `curvature-experiment/sweep/qm9_prepare.py` (local, CPU)

- Load `yairschiff/qm9` at a pinned revision; QM9 index = HF row + 1 (no index column; verified against all
  3,054 uncharacterized SMILES).
- Drop the indices in `uncharacterized.txt` (`ndownloader.figshare.com/files/3195404`, pinned sha256).
- RDKit-canonicalise the GDB17 `smiles` (no stereo in the source); a failed parse is dropped and counted
  (none expected).
- Deduplicate on the canonical string keeping the lowest QM9 index (87 groups; their label differences are
  printed-precision noise).
- Gap: Hartree → eV. mu, alpha, cv as given.
- Output `curvature-experiment/data/qm9/qm9_molecules.parquet` (`qm9_index, smiles_canonical,
  n_heavy_atoms, gap, mu, alpha, cv`, sorted by `qm9_index`) and `qm9_molecules.summary.json` (revisions,
  sha256s, every drop count, N). Both committed. `qm9_prepare` writes the table's sha256 into
  `molecules.yaml` (`label_table_sha256`); the table is both the label table and the SMILES source.

## 2. Embeddings — `curvature-experiment/sweep/embed.py` (pod GPU, outside the job queue)

- Invocation per encoder: `--encoder <short name> --manifest molecules.yaml --out-dir <root>/hf
  --cache-dir /tmp/effdim-hf --batch-size <n> --device cuda`.
- `CUBLAS_WORKSPACE_CONFIG=:4096:8` set before CUDA initialises; `torch.use_deterministic_algorithms(True)`;
  eval; float32.
- Tokenise the canonical SMILES with the model's own tokenizer, `padding_side="right"`, attention mask,
  special tokens as the tokenizer adds them; pad = eos when the tokenizer has no pad token.
- Masked mean over the attention mask of the last hidden state.
- Output `<root>/hf/molecules/<name>.parquet`, column `<name>_molecules` (list<float32>), rows in table order;
  sidecar `<name>.json` (HF id, revision, `transformers` version, dtype, pooling, padding side, batch size,
  SMILES-list sha256, parquet sha256).
- Validation: N rows, all finite, no all-zero row.
- Determinism: the first 2,048 molecules embedded twice must be byte-identical.
- Batch invariance: one molecule embedded alone and inside a batch with a longer molecule must agree to
  max |diff| <= 1e-5 x its row norm. If a model fails, that model is embedded with batch size 1 (recorded in
  the sidecar) and the check is repeated.
- The weights directory is deleted after a successful write; `df -h /tmp` checked before ChemFM-3B (about
  12 GB of float32 weights).
- The parquet sha256s are copied from the sidecars into `molecules.yaml` (`parquet_sha256`) and committed.

## 3. Code changes for a second domain (default-preserving)

- **Record readers** (`sweep/extract.py`): `cf_summary(npz, labels=LABELS)` and `sign_test(cf, thin, thr,
  labels=LABELS)`; the default keeps the galaxy behaviour. Runner 11 passes its `--labels`; aggregation
  passes the manifest's labels.
- **Runners**:
  - split, counterfactual, runner 11: `--expected-rows N` (default the galaxy constant; it sets
    `pl.EXPECTED_N_PHYSICS_ROWS` before any shim is installed), `--label-map identity` (default the galaxy
    map; the shims replace `pl.LABEL_COLUMN_MAP` with the identity map over `--labels` and
    `pl.SENTINEL_VALUES` with `()`; `load_physics` is not changed), `--d-file-sha256` (optional; written to
    the environment row).
  - runner 11 also gains `--labels` (replacing PRIMARY+SECONDARY and `EXPECTED_LABELS`) and `--d`
    (replacing its hard-coded `d = 16` and the `d == 16` reference filter).
  - The thin runner needs no change (its loader has no row-count check).
- **Manifest** (`sweep/manifest.py`): `parquet_file` and `column` become optional dataclass fields (default
  None → the galaxy `physics/<name>_test.parquet` and `<name>_galaxies`); optional `parquet_sha256` per
  encoder; optional top-level `labels`, `label_map`, `expected_rows`, `label_table_sha256`. The galaxy
  `encoders.yaml` loads unchanged. New `curvature-experiment/molecules.yaml` (repo `yairschiff/qm9`,
  snapshot = the pinned revision, n_rows 130,744, label_table = the table path on the pod, the 8 encoders
  with `parquet_file: molecules/<name>.parquet`, `column: <name>_molecules`, family, dim, params,
  params_source, in_paper false).
- **Jobs** (`sweep/jobs.py`): `build_jobs(..., d_file=None)`; with a d file, the encoder's d_run comes from it
  (a missing entry raises), geometry filenames and the cf `--d` carry it, molecule argv add `--labels <manifest
  labels> --label-map identity --expected-rows <n_rows> --d-file-sha256 <sha>` to split/cf/robust, and
  `main_d16` is added (split, fit seed 0, d 16, no `--hessian-xfit`, no `--geometry-out`, record
  `scaling__<enc>__main_d16.jsonl`) unless d_run = 16. Without a d file the galaxy argv is byte-identical.
- **Queue** (`sweep/run_queue.py`): `--manifest`, `--d-file`, `--timeout-h` (each job's argv prefixed with
  `timeout <h>h`; the queue reaps every job with `os.wait4` and writes `{"exit", "max_rss_kb", "wall_s"}` to
  `<root>/timing/<id>.json` itself, so a timed-out job still gets a timing file, with exit 124; no
  `/usr/bin/time`, which the shared pod root does not guarantee). The
  existing disk guard is kept as is (launches defer below `--min-free-gb`; the run exits non-zero and is
  rerun); phases bound disk use.
- **Aggregation** (`sweep/aggregate.py`): `--manifest`, `--timing-dir`; labels from the manifest; claim (a)
  at d = 16 reads `main_d16`, or `main_xfit` where d_run = 16; a molecule report writer (section 6) to
  `results/qm9/`. The galaxy report regenerates byte for byte.
- **Setup** (`sweep/setup_pod.sh`): `--manifest`; for molecules it skips the galaxy snapshot assertion and
  parquet download and checks the molecule table and embeddings by sha256; it installs effdim into the pod
  venv (`pip install --no-deps -e <repo>`). `transformers`, `rdkit` and
  `datasets` are pinned in `curvature-experiment/requirements.txt` (the GPU requirements derive from it).

## 4. Intrinsic dimension — `curvature-experiment/sweep/intrinsic_dim.py` (pod CPU)

- Per encoder: row-normalise; a 10,000-row subsample with seed 20261001; one shared k-NN of squared
  distances with k = 10 (as `src/effdim/api.py` does); `mle_dimensionality`, `two_nn_dimensionality`,
  `tle_dimensionality`, `mind_mlk_dimensionality` from `src/effdim/geometry.py`; d_ID = round(median);
  d_run = min(d_ID, 20).
- Synthetic bias check: unit spheres of true dimension 8, 16, 24 in D = 384, 768, 3072, n = 10,000; each
  estimator's bias reported. All read low at higher true dimension; the report says so.
- Output `curvature-experiment/data/qm9/molecules_d.json` {name: {d_ID, d_run, estimates}}, committed and
  pushed before any probe job.

## 5. Run order (each gate passes before the next)

1. Local: molecule table (gate: N = 130,744 and the drop counts). Commit.
2. Local: synthetic ID bias check. Reported.
3. Pod: setup on `c2-qm9` with `--manifest molecules.yaml`; the table's sha256 verified.
4. Pod GPU: embeddings, small models first (gates: validation, determinism, batch invariance). Pin the
   parquet sha256s in `molecules.yaml`. Commit and push.
5. Pod CPU: intrinsic dimension → `molecules_d.json`. Commit and push before step 6.
6. Phase A: chemfm_3b alone (GPUs 0–3 for its four split jobs, `--threads 7` (4 x 7 = 28 of 30 cores), `--timeout-h 8`,
   `--min-free-gb 10`). Stop and report if `robust` exceeds 8 h or any job exceeds 120 GB RSS. `--threads`
   is constant within a phase (runner 11 checks the cf run's thread count).
7. Phase B: chemfm_1b alone (same settings).
8. Phase C: the six others (8 GPUs, `--threads 3`).
9. Fetch records, arrays and timing files to `curvature-experiment/.cache/qm9/`; aggregate; regeneration
   test; commit. (Timing files are the queue's own `os.wait4` records, one per job, failed or timed out included.)

Pruning is on for molecules. At d = 20 a geometry file is about 0.8 MB x D (2.5 GB for chemfm_3b).

## 6. Molecule report (pre-stated claims)

- (a) mismatch partial negative and significant, per label, at d_run and at d = 16;
- (c) counterfactual help > random help and help > 0.5; (c') reversal hurts; (d) thinned sign test
  p_help < 0.05 — per label, at d_run;
- alignment reported descriptively (no molecular prior for its sign);
- reproduction guard, staleness, d per encoder (d_ID and d_run), the synthetic ID bias table, per-job wall
  time and peak RSS;
- stated limits: only ChemFM 1B → 3B is a model-size pair; the MTR models were pretrained on RDKit
  descriptors including molar refractivity (close to alpha), so alpha is expected near-linear for them;
  neighbourhoods cover about 1/64 of the data (galaxies 1/42); special tokens are inside the mean pool; d = 20
  is the cap and sits at an open question from the d = 20 spike findings, which the d = 16 baseline covers.

## 7. Tests (TDD, local)

1. `qm9_prepare`: on a small fixture parquet + exclusion file — index rule, exclusion by index,
   canonicalisation, dedup keeping the lowest index, one unit-conversion assert, summary counts.
2. `embed`: masked mean on toy tensors; validation rejects wrong row counts, NaN and all-zero rows; right
   padding and pad = eos; batch invariance on a tiny random `LlamaConfig` model built offline with a stub
   tokenizer.
3. `extract`: `cf_summary`/`sign_test` with molecule labels.
4. Runner shims: `--label-map identity`, `--expected-rows`, `--d-file-sha256` with a toy table and
   embeddings; runner 11 `--labels`, `--d`; default galaxy paths unchanged (gate).
5. `manifest`: the optional fields; the galaxy manifest unchanged.
6. `jobs`: d from the d file, missing entry raises, d in filenames and `--d`, molecule argv flags,
   `main_d16` present and skipped at d_run = 16, galaxy argv unchanged.
7. `run_queue`: `--manifest`, `--d-file`, `--timeout-h` wrapping and timing files.
8. `intrinsic_dim`: estimator subset, rounding, the cap at 20, the synthetic check on a small sphere.
9. `aggregate`: labels from the manifest, claim (a) at d = 16 from `main_d16`, the molecule report sections,
   the galaxy report still regenerating byte for byte; molecule regeneration test over the fetched records.
10. End-to-end CPU smoke: a synthetic 4,000-row table and 64-dim embeddings with the molecule flags through
    split → cf → thin → robust (finite rows, guard passes).

## Out of scope

Other molecule datasets; middle-layer embeddings; scaffold splits; feature standardisation (it would change
the protocol); the DINOv3 ID reference and the recorded-only estimators (cut as unneeded); a heavy-atom
baseline; a resettable disk latch; editing `main.tex`.
