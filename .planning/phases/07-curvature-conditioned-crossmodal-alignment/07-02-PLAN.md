**Add to `notebooks/pu_manifold/crossmodal_curvature.py`** (pure functions only; no file I/O, no
defaults on any pre-registered parameter — the caller passes the frozen constant explicitly, which

accident):

`split_indices(n, split_seed, holdout_fraction)` — re-declares `curvature_field_pu_run._split`'s
algorithm rather than importing a diagnostics module: `np.random.default_rng(split_seed).permutation(n)`,
first `int(round(n * holdout_fraction))` entries are holdout, the rest train. Returns
`(train_idx, holdout_idx)`.

`per_point_mknn(z1, z2, k)` — the D7-04 gap-fill. Coerce both to float64 arrays, raise `ValueError`
naming the offending array when row counts differ, then return `(A & B).sum(axis=1) / k` where `A`
and `B` come from `mknn._membership_matrix`, composed exactly as `mknn.mknn_score` does. Do not
rebuild `NearestNeighbors` locally — `_membership_matrix` is a plain unmangled top-level function
and carries the project's fixed k+1-neighbour, self-excluded convention plus its own non-finite,
`n < 2` and `k + 1 > n` guards, which this function inherits by composition. Docstring must state
that this returns the array `mknn_score` computes internally and averages away, and that the two
must never diverge.

`two_tailed_permutation_null(h, m, n_resamples, seed, quantile_per_tail)` — implements
`SIGNIFICANCE_TAIL_RULE`. Call `curvature_probe.permutation_null(h, m, n_resamples, seed,
quantile_per_tail)` for the positive tail and `curvature_probe.permutation_null(-h, m, n_resamples,
seed, quantile_per_tail)` for the negative tail, leaving `curvature_probe.py` unedited. Return a
dict carrying both tail dicts under `positive_tail` and `negative_tail`, plus `observed_rho` (the
positive tail's `observed_rho`, which is the actual Spearman of `h` against `m`), `clears_either`
(the boolean OR of the two `clears_null` values), and `direction` (the string `"positive"`,
`"negative"` or `"neither"`). Docstring must state why: `curvature_probe.permutation_null` is
one-sided by construction, the research hypothesis predicts a negative association, and Spearman on
a negated array is exactly the negated Spearman because average-rank reversal is exact including
ties — so the negated call is a mirror of the same statistic, not a second, different one.

`apply_verdict(per_d_results, positive_control_cleared_at)` — mechanically applies `VERDICT_RULE`.
Takes a mapping from `d` to that `d`'s `clears_either` boolean and the smallest positive-control
target rho that cleared (or `None`). Returns one member of `VERDICT_VALUES`: all `d` clearing gives
`ASSOCIATION DETECTED`; all `d` not clearing gives `NO DETECTABLE RELATIONSHIP` unless
`positive_control_cleared_at` is `None`, in which case it gives `UNDERPOWERED -- NO CLAIM`;
disagreement gives `SPLIT ACROSS d`. Raise `ValueError` if `per_d_results`' keys are not exactly
`set(D_SWEEP)` — a verdict computed from a partial sweep is not a verdict. Assert the returned
string passes `verdict_is_terminal`.
