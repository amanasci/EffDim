# Phase 02.7 Plan 02: k-Sweep and the Component Curve Summary

**`geodesic_graph.py` gains D-06's k-sweep (`k_sweep_components`, `geodesic_matrices_over_k`, `contiguous_stable_range`) and a numerically-proven D-07 no-bridging regression test — disconnection is reported, never repaired, with the no-fabricated-edge property asserted against the true inter-blob separation.**

## Performance

- **Duration:** ~10 min
- **Tasks:** 2
- **Files modified:** 2

## Accomplishments

- **`k_sweep_components(data, k_values)` reports the whole component curve.** One entry per `k`, every `component_readout` key attached (`n_components`, `largest_size`, `dropped_fraction`, `largest_mask`) plus `k` itself — never a chosen `k`, never a summary statistic over the curve.
- **`geodesic_matrices_over_k(data, k_values)` gives one geodesic matrix per swept `k`**, keyed by `k`, so a caller can build one persistence diagram per sweep point without hand-rolling the graph-build/shortest-path sequence at every `k`.
- **`contiguous_stable_range(values)` is bar-free by construction** — it takes no minimum-length argument, verified by an `inspect.signature` assertion. D-06's "non-trivial contiguous range" threshold stays a ratified constant plan `02.7-08` fixes and supplies; this module measures the run, it does not decide whether the run counts as stable.
- **D-07's no-bridging guarantee is proven numerically, not assumed.** `test_disconnected_graph_no_bridging` builds an unequal-size two-blob fixture, then asserts the exact component count (2), the exact matrix size (the larger blob only), the exact `dropped_fraction` (`n_small / (n_large + n_small)`), and — the direct evidence no fabricated edge crossed the gap — that the returned matrix's maximum entry is strictly below the true inter-blob separation computed independently via `scipy.spatial.distance.cdist`.
- **A positive control accompanies every disconnection test.** `test_k_sweep_components_single_blob_stays_connected` proves a well-sampled single blob reads `n_components == 1` and `dropped_fraction == 0.0` at every swept `k`, so a module that always reported disconnection would not pass.
- **Structural enforcement of D-07 confirmed:** `grep -c "minimum_spanning_tree"` and `grep -c "graph + graph.T"` both return 0 against `geodesic_graph.py`.
- **T-02.7-05's guard added:** `geodesic_distance_matrix` accepts an opt-in `min_component_size` (default `None`); when supplied and violated it raises `ValueError` naming the observed `dropped_fraction` rather than returning a matrix over a shard.
- **Full `notebooks/pu_manifold/tests/` suite: 223 passed** (216 from plan `02.7-01` + 7 new tests in this plan), no regression.

## Decisions Made

- **`min_component_size` is optional (default `None`), not a required no-default argument.** Critical-note-3 in this plan's launch context bars a default on any *ratifiable threshold* signature, but `None` here means "this module chooses no numeric minimum of its own" rather than silently applying a substantive threshold — the same non-choice as omitting the parameter entirely. Making it required would have broken plan `02.7-01`'s existing tracer and test call sites (`geodesic_distance_matrix(data, k)`), which this plan's `<files>` scope for Task 1 (`geodesic_graph.py` only, no test-file rewrite listed) did not license reworking. Documented in the module docstring and this SUMMARY's frontmatter rather than left implicit.
- **`geodesic_matrices_over_k` returns a `Dict[int, Tuple[D_geo, readout]]`** keyed by `k`, read from the plan's own `{k: (D_geo, readout)}` framing, over an alternative list-of-triples shape — gives O(1) caller lookup by swept `k`.
- **`contiguous_stable_range`'s tie-break (first-occurring run on equal-length ties) is an unspecified-by-plan implementation choice**, made for determinism since the plan's behavior block does not name a tie policy.
