## Template decision rule + abstain

### Q1 — What mechanism makes the template call?

| Option | Description | Selected |
|--------|-------------|----------|
| Betti-vector lookup table | Persistent Betti numbers via a significance rule, matched against a fixed table; no row matches → abstain. Discrete, auditable, legible abstain condition | ✓ |
| Diagram distance to analytic references | Sample each template at matched n/D/noise, score bottleneck+Wasserstein, pick nearest; abstain on thin margin. Reuses `ph_agreement` | |
| Hybrid — Betti proposes, distance confirms | Betti narrows candidates, distance breaks ties and can veto | |

**User's choice:** Betti-vector lookup table → **D-01**
**Notes:** Diagram distance rejected for reintroducing the matched-reference confound; hybrid rejected for putting a second axis in play after seeing results — structurally `02.6-FINDINGS.md` §4's failure.

### Q2 — What counts as a significant bar?

| Option | Description | Selected |
|--------|-------------|----------|
| Bootstrap confidence band | Per-cloud, per-metric noise band from subsampling (Fasy et al.); a bar is significant if it clears the band | ✓ |
| Fixed fraction of diagram diameter | `life > tau * max filtration scale`, tau ratified blind | |
| Largest-gap cut | Sort lives, cut at largest ratio gap; no ratified constant | |

**User's choice:** Bootstrap confidence band → **D-02**
**Notes:** Chosen partly because SC-3 already mandates bootstrap survival (one instrument, not two), and because a per-metric band is what lets Euclidean and geodesic — whose filtration scales are not comparable — share one rule. Largest-gap flagged as undefined precisely in the expected PU case (true Betti 0 → no gap → manufactured cycle).

### Q3 — How is abstain defined?

User interrupted to ask what abstaining implies. Clarified before re-asking: abstain collapses three distinct situations — off-library, no global template applies, and measurement won't support a call — which carry opposite downstream instructions (widen library / terminate arm / retry harder). Also clarified that a wrong template is the expensive failure (sends the follow-on VAE phase to the wrong `Z`), that `beta_0=1` with no `beta_1` is a *positive* ball call rather than an abstention, and that abstentions mean different things on the synthetic arm (always a miss) and on PU (possibly correct). Question reformulated with the four conditions named explicitly.

| Option | Description | Selected |
|--------|-------------|----------|
| Named disjunction, logged per condition | Four conditions (a) off-library, (b) no global template applies, (c) metric disagreement, (d) measurement untrustworthy; which one fired is recorded | ✓ |
| Two-level: abstain plus a separate reason code | Binary flag with reason as secondary metadata, not first-class conditions | |
| Single condition — no table row matches | Minimal, one thing to ratify | |

**User's choice:** Named disjunction, logged per condition → **D-03**

### Q4 — Does the table key on the Betti vector alone or (Betti, d_hat) jointly?

| Option | Description | Selected |
|--------|-------------|----------|
| Joint (Betti vector, d_hat) key | `S^1=((1,1),d=1)`, `S^2=((1,0,1),d=2)`, `T^2=((1,2,1),d=2)`, `ball=((1,0,…,0),d=d_hat)` | ✓ |
| Betti alone; d_hat only sets the degree ceiling | Single signal drives the decision | |
| Betti alone, with d_hat as a veto | d_hat can force abstain but never selects the row | |

**User's choice:** Joint key → **D-04**
**Notes:** Decided on the ball row being a catch-all otherwise — `(1,0,0)` is contractible at every dimension, and the ROADMAP prior says PU is likely exactly that at `d_hat ~ 18–25`.

## Spectral / kNN distance construction

Opened with a scouting correction: `notebooks/pu_manifold/mknn.py` is three `NotImplementedError` stubs, not the built asset the ROADMAP reuse table claims. This arm is new code under every option.

### Q1 — What exactly is the second distance?

| Option | Description | Selected |
|--------|-------------|----------|
| Graph geodesic on the kNN graph | Symmetric kNN graph, Euclidean edge weights, all-pairs shortest path — Isomap's distance without the embedding step | ✓ |
| Diffusion distance at time t | Random-walk spectral distance; more noise-robust, two parameters | |
| Euclidean in a spectral embedding | Laplacian eigenmaps then plain Euclidean PH; cheapest PH | |

**User's choice:** Graph geodesic → **D-05**
**Notes:** Spectral embedding rejected for interposing a second manifold-learning step between data and measurement — the 02.6 confound structure repeated in the instrument.

### Q2 — How is k chosen?

| Option | Description | Selected |
|--------|-------------|----------|
| Betti stability over a k range | Sweep k, require the Betti vector to hold over a non-trivial contiguous range, report the curve | ✓ |
| Smallest k that connects the graph | One deterministic rule, no sweep | |
| Inherit Phase 1's frozen k* = 15 | Already pre-registered on this dataset | |

**User's choice:** Betti stability over a k range → **D-06**
**Notes:** `k* = 15` explicitly not inherited — frozen for `n = 10,000` at `D = 768`, while the benchmark varies `n`, `D` and density by design.

### Q3 — Disconnected graph handling

| Option | Description | Selected |
|--------|-------------|----------|
| First-class read-out; geodesics on the largest component | Component count is a `beta_0` estimate; dropped-point fraction reported; >1 surviving component fires abstain (b) | ✓ |
| Bridge components with MST edges | sklearn Isomap-style repair, keeps every point | |
| Raise k until connected | Define the sweep's lower bound as the connectivity threshold | |

**User's choice:** First-class read-out → **D-07**
**Notes:** MST bridging rejected as fabricating geodesics and silently converting a genuine "no global template" cloud into a confident call.

### Q4 — Sampling contract at 10,000 points

| Option | Description | Selected |
|--------|-------------|----------|
| Fixed n_ph budget, several independent draws, spread reported | Budget pinned identically across both metric arms and every benchmark cell | ✓ |
| Landmark / witness complex | Full cloud witnesses a small landmark set; scales better | |
| Full cloud, cap homology at H1 | No subsampling | |

**User's choice:** Fixed budget with independent draws → **D-08**
**Notes:** Witness complex would need `gudhi`, a new undeclared dependency on top of the existing `ripser`/`persim` gap with `pyproject.toml` frozen — deferred rather than adopted.

## Dimension protocol → homology ceiling

### Q1 — Which of the eight frozen estimators run?

| Option | Description | Selected |
|--------|-------------|----------|
| All eight, spread reported, no aggregation | Every estimator at every k in the sweep | ✓ |
| A ratified subset of three or four | Cheaper per k, harder to cherry-pick from | |
| All eight, but one named estimator drives the ceiling | Removes ambiguity about what d_hat means | |

**User's choice:** All eight → **D-09**

### Q2 — How is a single d_hat resolved?

| Option | Description | Selected |
|--------|-------------|----------|
| Plateau-and-consensus, ratified blind | Integer where a ratified majority plateau over a contiguous k range; no consensus → abstain (d) | ✓ |
| Median across estimators, plateau in the median curve | One curve, one plateau rule | |
| Ceiling from the max, table key from the plateau | Conservative on degrees | |

**User's choice:** Plateau-and-consensus → **D-10**
**Notes:** Median rejected on the concrete `5/5/5/20/20/22/24/25` case — it reports a plateau no estimator individually supports, which is how `d_frozen = 5`'s suspect neighbourhood arose. Phase 02's split would have *failed* the chosen rule rather than produced a number.

### Q3 — The homology degree ceiling

| Option | Description | Selected |
|--------|-------------|----------|
| Cap at H_2, cap stated as a limitation | Library maximum; amends SC-3's literal text; `beta_3`-blindness written into assumptions | ✓ |
| min(d_hat, 2) | Same ceiling expressed as a function of d_hat | |
| Literal H_0..H_dhat with a compute abort | Honours SC-3 exactly | |

**User's choice:** Cap at H_2 → **D-11**, with the consequence recorded as assumption **A-01**
**Notes:** Literal reading rejected because it aborts by construction on PU — no answer for the one cloud the phase exists to probe — and its abort threshold would become an unratified constant doing the capping anyway.

## Benchmark design + how accuracy scores

### Q1 — The scoring contract

| Option | Description | Selected |
|--------|-------------|----------|
| Three-way tally: correct / wrong / abstained | Every cell in one bucket, all three counts reported; error rate is the third number | ✓ |
| Accuracy over non-abstained, plus abstention rate | Standard selective-prediction convention | |
| Three-way tally, split further by abstain reason | Same buckets, abstentions decomposed into conditions a/b/c/d | |

**User's choice:** Three-way tally → **D-13**
**Notes:** Selective-prediction convention rejected on the case it permits — abstain on 95% of cells, be right on the rest, score 100% accuracy.

### Q2 — What the immersion actually is

| Option | Description | Selected |
|--------|-------------|----------|
| Canonical embedding → random rotation → warp, Jacobian rank verified | Rank checked at sampled points, not assumed | ✓ |
| Canonical embedding + random rotation only | Pure isometry; ground truth exact, immersion guaranteed | |
| A randomly initialised neural net as the immersion | Closest to how real manifolds arise; 02.6 built one | |

**User's choice:** Canonical + rotation + verified warp → **D-14**
**Notes:** The rank check was the deciding factor — a map that stops being an immersion makes the ground-truth label silently wrong, and every downstream accuracy number unattributable.

### Q3 — The benchmark grid

| Option | Description | Selected |
|--------|-------------|----------|
| Factorial on (D, noise); n and density as OFAT arms; D=768 mandatory | The D-by-noise interaction is the phase's premise and stays in the design | ✓ |
| Full factorial on all four axes, coarse levels | 324 cells before replicates at three levels each | |
| One-factor-at-a-time on all four, plus one D=768 cell | Cheapest; no interaction observable | |

**User's choice:** (D, noise) factorial with OFAT arms → **D-15**

### Q4 — The Swiss roll check's baseline

Flagged before asking: `02.6-CONTEXT.md` D-02 records the roll's ambient `beta_1 = 1` from near-touching spiral arms, so the Euclidean arm is predicted to see a spurious cycle on a contractible sheet — making SC-5 a live test of abstain condition (c).

| Option | Description | Selected |
|--------|-------------|----------|
| In-library positive controls at matched n/D/noise | A sampled `S^1` and `T^2` alongside the roll — CLAUDE.md's "baseline known to succeed" | ✓ |
| Euclidean versus geodesic on the roll alone | The two metrics as each other's baseline | |
| Permutation null — the roll with coordinates shuffled | Structure-versus-noise separation | |

**User's choice:** In-library positive controls → **D-16**
**Notes:** Decided on the observation that the roll's correct answer *is* the trivial template, so a degenerate always-emits-disk front end passes the roll check without controls.
