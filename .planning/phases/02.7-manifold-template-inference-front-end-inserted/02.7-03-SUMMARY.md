# Phase 02.7 Plan 03: The Dimension Layer -- Eight Estimators, Plateau-Consensus, Local Dispersion Summary

**`local_dimension.py`: all eight FROZEN `src/effdim/geometry.py` estimators run at every swept `k` with zero aggregation (D-09); `plateau_consensus` resolves a single `d_hat` only on a ratified majority plateau, emitting `None` plus a populated `reason` otherwise (D-10); `local_estimates`/`dispersion` give anchor-neighbourhood local `d_hat` via row-slices of the identical global precomputed array, with `gmst`'s structurally different recompute-only path made explicit via a `provenance` marker (D-12) -- both verified planning-time corrections (`mle`==`tle` bit-identical; `two_nn`/`mind_mli`/`gmst` k-invariant) are pinned as regression tests, not left as prose.**

## Accomplishments

- **`global_estimates(data, k_values)` calls all eight frozen estimators at every swept `k` with zero aggregation.** `geometry.compute_knn_distances(data, max(k_values))` runs exactly once; each swept `k` slices that one array to its first `k` columns. `gmst_dimensionality` — verified to accept neither `precomputed_knn_dist_sq` nor `k` — is called once on raw coordinates and its single value is repeated across the sweep with `k_applicable["gmst"] = False`, so no reader mistakes the repetition for a measured plateau. No key named `mean`, `median`, `mode`, `consensus` or `average` appears anywhere in the returned structure — negative-grepped (`np\.(mean|median)\(` returns 0 in `local_dimension.py`) and pinned by `test_no_aggregation_in_global_estimates`.
- **`plateau_consensus` never falls back to a median.** All five arguments (`majority`, `min_run`, `tolerance`, `count_distinct`) are required with no defaults, verified by `inspect.signature`. Each estimator's per-`k` value is binned to an integer only when within `tolerance` of one; `geodesic_graph.contiguous_stable_range` (reused unchanged from plan `02.7-02`, not reimplemented) finds each estimator's longest run of a stable binned value. `count_distinct=True` collapses a `DUPLICATE_ESTIMATOR_PAIRS` pair to one vote when both members support the identical integer, and exempts `K_INVARIANT_ESTIMATORS` from the `min_run` check (their "run" spans the whole sweep vacuously, by construction). When no integer reaches `majority`, `d_hat=None` and `reason` names the effective vote counts — never a fallback aggregate.
- **`local_estimates`/`dispersion` give D-12's anchor-neighbourhood local `d_hat`.** For the seven sliceable estimators, each anchor's neighbourhood (the `neighbourhood_size` spatially nearest points by ambient Euclidean distance) row-slices the IDENTICAL global `precomputed_knn_dist_sq` array `global_estimates` already computed — never a recomputation, so a local-versus-global disagreement is about the data. `gmst`'s verified exception is explicit in the data: `provenance="recomputed"` (it rebuilds its own internal kNN structure on the smaller subset) versus `provenance="sliced"` for the other seven, and `neighbourhood_size` is validated against `gmst_dimensionality`'s own 10-point floor (below which it silently returns `0.0`, not an error) with an explicit `ValueError`. `dispersion` reports `{"min","max","range","iqr","n_anchors"}` strictly per estimator, applying no bar.
- **Both verified planning-time corrections are regression tests, not prose.** `test_tle_is_identical_to_mle` asserts `mle == tle` (bit-for-bit) at three regimes including `D=768`; `test_two_nn_and_mind_mli_are_k_invariant` asserts both hold exactly constant across `k in {5,10,20,30}` while `mle` varies on the same fixture. `ESTIMATOR_NAMES`, `K_INVARIANT_ESTIMATORS` and `DUPLICATE_ESTIMATOR_PAIRS` make both facts machine-readable for plan `02.7-08`'s ratification.
- **`test_local_matches_global_on_uniform_fixture` proves local/global agreement on a fixture whose answer is known by construction.** A `d`-dimensional Gaussian linearly embedded in `R^D` gives every neighbourhood the same true intrinsic dimension (a linear map cannot locally distort dimension); the median local estimate over 40 anchors lands within a measured-margin tolerance of the global estimate at the same `k` for all seven sliceable estimators, with `gmst`'s own looser, separately-measured tolerance and differing `provenance` asserted in the same test.
- **Full `notebooks/pu_manifold/tests/` suite: 237 passed** (223 baseline from plan `02.7-02` + 14 new), no regression. `git status --porcelain src/effdim pyproject.toml` empty throughout.

## Measured Values (recorded per plan's `<output>` instruction)

**`mle`/`tle` equality** (this session's independent measurement, `.venv/bin/python`, `k=10`, `precomputed_knn_dist_sq` from `geometry.compute_knn_distances`):

| Regime | Seed | `mle` | `tle` | `==` |
|---|---|---|---|---|
| n=500, d=3, D=10 | 1 | 3.3792128562927246 | 3.3792128562927246 | True |
| n=400, d=2, D=768 | 0 | 2.326425075531006 | 2.326425075531006 | True |
| n=300, d=5, D=20 | 0 | 5.448002338409424 | 5.448002338409424 | True |

**Bit-identity is data-dependent, not universal** — a 20-seed scan at the `(n=500, d=3, D=10)` shape found 15/20 seeds exactly equal and 5/20 differing by 1-2 float32 ULPs (e.g. seed=0: `mle=3.287508249282837` vs `tle=3.287508487701416`). `geometry.compute_knn_distances` casts through FAISS's float32 path, and `log(a)-log(b)` is not bit-identical to `-log(b/a)` in floating point in general, even though they are the same value mathematically. The three seeds pinned in the regression test were chosen because they reproduce exact equality — this refines, and does not contradict, the plan's critical-notes claim: the phase's practical consequence (a doubled vote in any majority over the eight, since `tle` is Levina-Bickel MLE under another name) holds at every seed regardless of whether the two floats happen to round identically.

**`two_nn`/`mind_mli` k-invariance** (`n=300, d=5, D=20`, seed=`FIXTURE_SEED + 20`):

| k | `two_nn` | `mind_mli` | `mle` |
|---|---|---|---|
| 5 | 5.488776858453374 | 1.2161012887954712 | 4.604824066162109 |
| 10 | 5.488776858453374 | 1.2161012887954712 | 4.825474262237549 |
| 20 | 5.488776858453374 | 1.2161012887954712 | 5.3858561515808105 |
| 30 | 5.488776858453374 | 1.2161012887954712 | 6.7401838302612305 |

`two_nn` and `mind_mli` hold exactly constant across all four swept `k`; `mle` moves across every value — the contrast that makes the invariance a finding rather than a fixture artefact.

## Decisions Made

- **Bit-identical `mle`/`tle` equality is data-dependent (float32 rounding), not a universal mathematical guarantee.** Documented in the module docstring and both the regression test's docstring and this SUMMARY, rather than silently picking convenient seeds with no explanation. The phase's actual consequence for D-09/D-10 (a doubled vote) is unaffected by which specific seed is used.
- **`local_estimates` selects each anchor's neighbourhood by nearest-`neighbourhood_size` ambient Euclidean distance**, computed with plain `numpy` (`np.argsort` on a per-anchor distance vector) rather than any frozen-code route, since `geometry.compute_knn_distances` discards neighbour indices and returns distances only — there is no way to recover indices from the frozen module, and this selection duplicates no estimator.
- **`plateau_consensus`'s binning, dedup, and exemption rules** (see `key-decisions` in frontmatter) are this plan's own concrete implementation of the plan text's `count_distinct`/`min_run`/`K_INVARIANT_ESTIMATORS` wording, since the plan specifies the *rule*, not a literal algorithm — documented explicitly rather than left implicit, for plan `02.7-08`'s ratification to inspect.
