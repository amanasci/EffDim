# Phase 02.7 Plan 01: Manifold-Template Inference Front End -- Tracer Summary

**End-to-end tracer proving the geodesic-graph + bootstrap-band + Betti-lookup pipeline works at production dimensionality D=768 on one synthetic S^1 cloud, with the frozen geometry.py's symmetrization bug fixed and pinned by regression test.**

## Performance

- **Duration:** ~45 min (includes a ~4-minute full-scale H2 bootstrap run)
- **Tasks:** 3 (Task 1 checkpoint, Task 2 tracer implementation, Task 3 regression test)
- **Files modified:** 6 (5 created code files + 1 test file)

## Accomplishments

- **Task 1 checkpoint resolved: `ratify-as-written`.** D-01 and D-04 confirmed exactly as `02.7-CONTEXT.md` states them: the template call is a Betti-vector lookup table keyed jointly on `(Betti vector, d_hat)`, with no diagram-distance computation and no reference cloud anywhere in the phase. No amendment.
- **Four new production-shaped modules, no ratifiable threshold carrying a default anywhere.** `geodesic_graph.py`, `confidence_band.py`, `template_immersion.py`, `template_decision.py` — every one importable in isolation, every threshold-bearing signature (`bootstrap_band`'s `B`/`alpha`/`seed`) verified by `inspect.signature` to carry no default.
- **The verified `graph + graph.T` symmetrization bug is fixed and pinned.** `geodesic_graph.build_symmetric_knn_graph` uses `graph.maximum(graph.T)`; `test_maximum_symmetrization_not_sum` asserts the fix recovers the exact true distance (`0.5`) and that the additive form would have doubled it (`1.0`) — confirmed by temporarily reverting the fix and observing the test fail exactly as expected (see below).
- **The tracer runs end to end at production dimensionality (`D=768`) and exits 0**, both at `--smoke` (n=120, ~11s) and at full scale (n=300, ~250s wall clock, dominated by the H2 bootstrap band).
- **Full `notebooks/pu_manifold/tests/` suite: 216 passed, no regression** from the two new tests added.

## Decisions Made

- **Task 1 checkpoint: ratify-as-written.** No new information surfaced during research or planning that would justify reopening D-01/D-04 at this late stage; the amendment option existed to record the door was open, not because a concrete alternative was on the table.
- **`lookup()` accepts Betti vectors shorter than 3 entries** (e.g. `S1`'s `(1,1)` exactly as `02.7-CONTEXT.md` D-04 writes it), zero-padding on the right to `(beta_0, beta_1, 0)` before matching against the table. This reconciles D-04's literal 2-tuple for `S1` with D-11's 3-entry `(H0,H1,H2)` ceiling used by every other row, and is required for the plan's own acceptance test (`lookup((1,1),1)=='S1'`) to pass. `_normalize_betti` rejects anything longer than 3 entries with an explicit `ValueError`, since D-11 caps homology at `H_2`.
- **Ball-row label format: `ball_d{d_hat}`** (e.g. `ball_d18`). D-04's text specifies the *requirement* — `B^2` and `B^18` must be distinguishable outputs — but not a literal return format; a plain, machine-parseable string carrying the joint key's `d_hat` was chosen over a tuple or superscript notation.
- **`template_immersion.immerse`'s `d_true` lookup is keyed only on `"S1"`** in this plan, since `canonical_sample` raises `NotImplementedError` for `"S2"`/`"T2"`/`"ball"` before that lookup is ever reached — the dict is deliberately minimal rather than pre-populated with values for templates this plan does not build.

### Symmetrization regression test failure value (Task 3)

With the fix (`graph.maximum(graph.T)`) temporarily reverted to the additive form (`directed + directed.T`), `test_maximum_symmetrization_not_sum` failed as:

```
assert 0.5 < 1e-12
 +  where 0.5 = abs((1.0 - 0.5))
```

`fixed_value` (actually the buggy additive value under the revert) = `1.0`; `true_dist` = `0.5` — the additive form doubled the true distance exactly as `02.7-RESEARCH.md` Pitfall 3 predicted. The fix was then reverted back to `graph.maximum(graph.T)` and the test re-confirmed passing (`diff` against the pre-edit file showed the restored file was byte-identical to the original).
