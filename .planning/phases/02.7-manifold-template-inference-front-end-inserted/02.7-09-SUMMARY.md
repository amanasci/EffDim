Imports `template_decision`, `geodesic_graph`, `confidence_band`, `local_dimension`, `template_immersion`, `persistence_probe` unchanged from `notebooks/pu_manifold/`. Runs the roll (3,000 points generated, subsampled to `n_ph` for the front end, stated explicitly) plus D-16's in-library `S1`/`T2` positive controls (via `template_immersion.immerse`, `check_immersion=True`, both verified genuine immersions) through the full front end: D-09/D-10's eight-estimator dimension consensus, D-12's local dispersion, D-06/D-07's geodesic component read-out, D-02/D-11's per-metric bootstrap-banded Betti vectors up to `H_2`, and D-01/D-03/D-04's joint decision.

Exits 0 against the committed notebook.
- **The real finding (not a clean pass).** All three clouds abstained: roll (`d_hat=2`, condition **(b)**), S1 control (`d_hat=1`, condition **(b)**), T2 control (`d_hat=None`, condition **(d)**, no consensus). Section 5's per-estimator dispersion breakdown isolated the driver: `gmst`'s local dispersion range was `22.201` (roll), `3.587` (S1), `26.521` (T2) — `2.6x`-`14.0x` the next-widest estimator (`two_nn`) at every cloud, with per-anchor values ranging from `-16.379` to `20.916` (negative "dimension" estimates, which no other estimator ever produces). **Verified, before committing, to reproduce unchanged at `n_ph` 150, 200, and 300** — not an artifact of the sanity notebook's own reduced sample size.
- **A bypass diagnostic separated two independent findings.** Calling `template_decision.lookup` directly (bypassing `decide`'s abstain-condition precedence) showed the **Betti-lookup decision core is sound**: `lookup(betti=(1,1,0), d_hat=1) -> 'S1'` on both metric arms for the S1 control. The roll's own bypassed lookup returned `None` on both arms — its `beta_0 in {26, 29}` never matches the `ball` row's `beta_0=1`, a **separate** finding consistent with `02.7-SCREENING-RULE.md` §11's already-named H0 residual risk, not addressed by this plan.
- **The D-02 live prediction (roll's ambient `beta_1=1` -> Euclidean-arm-only spurious cycle) was not exercised through `decide()`'s own path** — condition (b) fires before condition (c) in the fixed precedence order, and (b) fired first on every measured run. The raw Betti vectors *did* disagree (`euclidean=(26,1,0)` vs `geodesic=(29,1,1)`), reported directly since `decide()` never reached (c) to report it as the reason. Recorded as a gap in what SC-5 demonstrated, not as a pass on it — see the amendment §6.
- **Checkpoint resolved by the user**: amend the rule, excluding `gmst` from D-12's local-dispersion vote only (not D-09's global spread/consensus vote); the Swiss roll finding accepted as real and the notebook approved as committed, unmodified.
- **`02.7-SCREENING-RULE-AMENDMENT-01.md`** ratified, committed **alone** (`948d13f`), amending `02.7-SCREENING-RULE.md` (`7aa699d`). States plainly that the amendment was written after seeing an unfavourable result, then argues its defensibility: the exclusion criterion (provenance-match between an estimator's local and global call) was already recorded in `local_dimension.py`'s own module docstring, verified unchanged against `src/effdim/geometry.py:396-400`, before any cloud in this phase was scored — the amendment applies a pre-existing structural rule, phrased generally (never "exclude gmst" by name), rather than inventing one to fit the data. Explicitly states what it does NOT rescue (the roll's own H0 finding) and does NOT resolve (whether condition (c) would fire under the amended gate). No re-run required or performed — no benchmark cloud has been scored under either document.
- **`local_dimension.gating_dispersion`** added (`235916c`), landing after the amendment. Computes the provenance-matched estimator set dynamically from `local_estimates`' own `"provenance"` tags (excludes exactly `{"gmst"}` as a measured consequence, never a hardcoded name), restricts `dispersion()`'s report to that set for `template_decision.decide`'s gate. `dispersion()` itself is unchanged — still all eight estimators, no aggregation, its own existing regression test untouched. `template_decision.decide` requires no code change.
