# Phase 02.7 Plan 06: Manifold-Template Inference Front End -- Decision Rule Summary

**`template_decision.py`'s `decide()` completes D-01/D-04's joint `(Betti, d_hat)` lookup gated by D-03's four named abstain conditions in a fixed precedence order, and `tally()`/`assert_labelled()` complete D-13's three-way scoring and the metric-label invariant -- 7 new tests, 266/266 passing.**

## Performance

- **Duration:** ~40 min

## Accomplishments

- **`decide(arms, dimension_readout, connectivity_readout, bounds)`** evaluates the four named abstain conditions in a fixed, docstring-stated precedence order -- **(d) measurement untrustworthy** (no `d_hat` consensus, estimator spread over `bounds["spread_bound"]`, or a Betti/dimension contradiction) checked first, then **(b) no global template** (`n_components > 1`, or local dispersion over `bounds["dispersion_bound"]`), then **(c) metric disagreement**, then **(a) off-library** -- so the conditions most predictive of an unreliable measurement gate a confident label before it is ever offered.
- **The Betti/dimension contradiction check (D-04's stated reason for the joint key)** is real code, not just a docstring claim: `_betti_dimension_contradiction` matches a betti vector against every non-ball `TEMPLATE_TABLE` row and fires when the row's own `d` disagrees with the measured `d_hat` -- verified directly on the plan's own example, `beta_2 = 1` at `d_hat = 1` (matches `S2`'s `(1, 0, 1)` but not `S2`'s `d = 2`), which routes to abstain `(d)`, never a confident label.
- **The ball row stays a positive call.** `beta_0 = 1`, no persistent `beta_1`, a clean `d_hat` plateau, both arms agreeing returns `abstained=False` and a `ball_d{d_hat}` template -- pinned by `test_ball_row_is_a_positive_call_not_an_abstention` so this path is reachable only as a success.
- **`tally(results)`** puts every result into exactly one of `correct`/`wrong`/`abstained`, returns all three counts plus `total`, and three SEPARATE rates -- `accuracy`, `abstention_rate`, `error_rate` -- never accuracy computed over non-abstained cells only. `by_condition` counts sum to `abstained`.
- **`assert_labelled(readout)`** raises `ValueError` naming the offending key when a per-metric value (`"betti"`) is not itself a dict keyed by `{"euclidean", "geodesic"}` -- wired into both of `decide()`'s return paths.
- **No threshold carries a default anywhere.** `_require_bounds` raises `ValueError` naming every missing key in `bounds` before any comparison runs; `_REQUIRED_BOUNDS = ("dispersion_bound", "spread_bound")` is the exact set plan `02.7-08`'s ratified rule document must supply.
- **7 new tests, all passing**, exactly the verbatim names the plan and `02.7-VALIDATION.md`'s per-task map require: `test_lookup_table_known_answers`, `test_abstain_conditions`, `test_tally_sums_to_total`, `test_no_readout_without_metric_label`, `test_ball_row_is_a_positive_call_not_an_abstention`, plus two supporting tests (`test_decide_raises_on_missing_bound_key`, `test_tally_raises_on_abstained_without_valid_condition`).
- **Full `notebooks/pu_manifold/tests/` suite: 266 passed** (259 baseline + 7 new), no regression. `src/effdim/` and `pyproject.toml` untouched (`git status --porcelain` empty on both).

## Decisions Made

- **`decide()`'s `dimension_readout`/`connectivity_readout` contract mirrors `local_dimension`'s and `geodesic_graph`'s own output key names directly** (`d_hat`, `reason`, `"range"` inside `spread`/`local_dispersion`, `n_components`, `dropped_fraction`) rather than inventing a new shape -- a future runner can pass `plateau_consensus`/`spread`/`dispersion`/`component_readout`'s return dicts straight through with no adapter. No runner wiring these together exists yet in this phase; that is out of this plan's scope (`files_modified` names only `template_decision.py` and its test file).
- **"No stable `k` range was found" (D-03's third (d) sub-condition) is realized as `d_hat is None`.** `local_dimension.plateau_consensus` already fails closed to `None` precisely when no estimator's binned value holds a sufficient contiguous-`k`-range run (its own `min_run` requirement), so re-testing "is there a stable range" as a second, independent check inside `decide` would re-derive a fact `plateau_consensus` already established. Kept as one check, not two.
- **The Betti/dimension contradiction check runs on both arms individually, before checking arm agreement.** If checked only after confirming agreement, a single bad arm could in principle be laundered past (d) into a (c) or (a) call depending on ordering details; checking both arms first closes that gap regardless of what the other arm reports.
- **`assert_labelled`'s tracked-key list currently holds only `"betti"`.** It is this module's one actual per-metric output; kept as a small explicit allowlist (`_PER_METRIC_KEYS`) rather than a generic recursive scan over all dict values, since a broad scan risks false positives on legitimate non-metric dict values this module's read-outs also carry (e.g. `abstain_detail` strings, `connectivity` sub-dicts).
- **Tasks 1 and 2 committed separately despite the cross-reference** (`decide()`, built in Task 1, calls `assert_labelled()`, built in Task 2). Task 1's two call sites were stubbed with a `# plan 02.7-06 Task 2 wires assert_labelled(result) in here.` comment instead of an undefined-name call, verified stand-alone (all Task 1 acceptance criteria pass with `assert_labelled` absent from the module, since no Task 1 acceptance-criteria command exercises that code path), then Task 2's commit adds `tally`/`assert_labelled` and replaces both stub comments with the real call. Both commits are independently syntax-valid, importable, and pass their own task's acceptance criteria -- no broken intermediate state in git history.
