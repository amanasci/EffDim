# Phase 02.7: Manifold-Template Inference Front End (INSERTED) - Context

**Gathered:** 2026-08-11
**Status:** Ready for planning

<domain>
## Phase Boundary

This phase builds and measures the **inference front end only** — the pipeline that takes an
unlabelled point cloud and decides *which* template manifold it looks like, or declines to
decide. Three stages: intrinsic dimension → persistent homology under two distance metrics →
a template decision over a small named library with an explicit **abstain** option.

It trains no VAE, restricts no auto-encoder, selects no template for PU, and makes no curvature
claim. The topological-VAE arm (Acosta et al., `2212.10414`) is a deferred follow-on phase,
gated on this front end working.

The question it answers: **can a latent manifold template be inferred from an unlabelled point
cloud at all, and with what accuracy and abstention rate.** Selection accuracy is only
measurable where the template is known by construction, so the phase is synthetic-first with a
single read-only PU probe at the end.

**Three scope decisions fixed at insertion (2026-08-11) and not reopened here:** front end only;
synthetic first with PU as one final read-only probe; both Euclidean and spectral/kNN distances
reported separately and never collapsed.

</domain>

<decisions>
## Implementation Decisions

Sixteen decisions, D-01..D-16, across the four areas discussed. Every one of them is an input to
the ratified decision rule that SC-1 requires be committed **before any synthetic cloud is
scored** — see D-16.

### The template decision rule (SC-1)

- **D-01:** The template call is made by a **Betti-vector lookup table**, not by diagram distance
  to reference clouds and not by a hybrid. Extract persistent Betti numbers, match against a
  fixed table, no row matches → abstain.
  — **Why:** the library is tiny and Betti numbers do not determine homeomorphism type anyway, so
  a lookup states exactly what is being claimed and makes the abstain condition legible. Diagram
  distance would require constructing a reference cloud at matched `n`/`D`/noise for every
  template, reintroducing the matched-reference confound. A hybrid puts two thresholds in play
  and makes a second axis available after seeing results — structurally the failure
  `02.6-FINDINGS.md` §4 recorded.
  — **Reversibility:** one-way — this phase's whole output contract is "a classifier over a small
  named library". Swapping the mechanism after measurement would be the second criterion tried
  for the same question, and `02.6-FINDINGS.md` §4 already records one criterion changed after an
  unfavourable result. The record cannot absorb another.

- **D-02:** A bar is **significant** iff it clears a **bootstrap/subsample-derived confidence
  band** computed per cloud, per metric (Fasy et al. persistence confidence sets). Not a fixed
  fraction of diagram diameter, not a largest-gap cut.
  — **Why:** SC-3 already mandates that persistence survive bootstrap/subsampling, so this is one
  instrument rather than two. Critically, the band is derived **per metric**: Euclidean and graph
  geodesic have non-comparable filtration scales, and a single hand-set constant would need a
  different value for each, which is per-metric tuning through the back door. A largest-gap cut
  is undefined exactly where it matters most — when the true Betti number is 0 there is no gap to
  find and the rule manufactures a cycle, which is the expected PU case.

- **D-03:** **Abstain is a named disjunction, and which condition fired is recorded.** Four
  conditions:
  - **(a) off-library** — the Betti vector matches no table row;
  - **(b) no global template applies** — more than one component survives the k range, or local
    `d_hat` dispersion exceeds the ratified bound;
  - **(c) metric disagreement** — Euclidean and geodesic arms disagree on the Betti vector;
  - **(d) measurement untrustworthy** — no `d_hat` plateau, or estimator spread over the ratified
    bound, or no stable k range.
  — **Why:** the four carry *opposite* downstream instructions — (a) widen the library, (b)
  terminate the follow-on arm, (c)/(d) retry with more data or a better metric. One
  undifferentiated abstention rate hides which applies, and the deferred VAE phase reads this
  output to decide whether it runs at all. The ROADMAP Design note already names boundary,
  multiple components and mixed intrinsic dimension as abstain triggers; (b) is where they live.
  — **Note for planning:** abstain is the *cheap* failure. A wrong template sends the follow-on
  phase to constrain a VAE to the wrong `Z` and derive curvature through it — a confident wrong
  number with no way to detect it. The whole rule is built around that asymmetry.

- **D-04:** The lookup table keys on **(Betti vector, `d_hat`) jointly**, not on the Betti vector
  alone. Rows: `S^1 = ((1,1), d=1)`, `S^2 = ((1,0,1), d=2)`, `T^2 = ((1,2,1), d=2)`,
  `ball = ((1,0,...,0), d=d_hat)`.
  — **Why:** `beta = (1,0,0)` is contractible at *every* dimension. Keyed on Betti alone the ball
  row is a catch-all that swallows any acyclic cloud whether `d_hat` is 2 or 18 — and the ROADMAP
  prior says PU is likely exactly that. The joint key makes the output a *named* manifold
  (`B^2` and `B^18` are materially different objects to constrain a VAE to), and turns a
  Betti/dimension contradiction — `beta_2 = 1` at `d_hat = 1` — into a detectable inconsistency
  that routes to abstain (d).

### The spectral / kNN distance arm (SC-3)

- **D-05:** The second distance is the **graph geodesic on the kNN graph** — symmetric kNN graph,
  edges weighted by ambient Euclidean length, all-pairs shortest path. This is Isomap's distance
  without Isomap's embedding step. Not diffusion distance, not Euclidean-in-a-spectral-embedding.
  — **Why:** it is the documented fix for the failure this phase's premise names (Euclidean PH
  losing a noisy circle in high ambient `D`); it carries one parameter, not two; and it feeds
  `persistence_probe.persistence_diagram(D, ...)` unchanged, which already takes a distance
  matrix. A spectral embedding would interpose a second manifold-learning step between the data
  and the measurement, making a failure unattributable — the confound structure
  `02.6-FINDINGS.md` recorded, repeated in the instrument instead of the model.

- **D-06:** `k` is not a single chosen value. **Sweep `k` and require the Betti vector to hold
  over a non-trivial contiguous range**; report the whole curve. No stable range → abstain (d).
  — **Why:** mirrors SC-2's plateau discipline rather than inventing a second convention, and
  SC-3 already demands persistence survive a range rather than appear at one radius. Phase 1's
  frozen `k* = 15` is **not** inherited here: it was frozen for `n = 10,000` PU points at
  `D = 768`, and the synthetic benchmark varies `n`, `D` and density by design, so a fixed `k`
  means a different effective neighbourhood radius in every cell.

- **D-07:** **Graph disconnection is a first-class read-out, never repaired.** Component count at
  each `k` is reported as its own number (it is a direct `beta_0` estimate); geodesic PH is
  computed on the **largest component only**, with the dropped-point fraction reported alongside;
  more than one surviving component fires abstain (b). **No minimum-spanning-tree bridging.**
  — **Why:** bridged edges are not in the data, so every geodesic crossing one is fabricated, and
  bridging silently converts a genuine "no global template" cloud into a confident single-template
  call. Raising `k` until connected reintroduces the knife-edge connectivity rule and would make
  abstain (b) structurally unable to fire on this metric.
  — **Reversibility:** costly — the choice is baked into what abstain (b) means and into the
  benchmark's abstention-rate numbers; changing it invalidates every measured rate.

- **D-08:** **Fixed `n_ph` point budget, several independent draws, Betti spread reported.** The
  budget is pinned **identically** across the Euclidean arm, the geodesic arm and every benchmark
  cell. A landmark/witness complex is **not** used.
  — **Why:** PU is 10,000 points; a dense float64 geodesic matrix is ~800 MB before ripser
  allocates anything, and H1 at that size is itself the wall. Subsampling reuses the same
  machinery D-02's bootstrap band already needs, so it costs no new instrument. The identical-
  budget clause is the "assert the comparison is fair" discipline carried forward from 02.6 — not
  merely that each arm ran. A witness complex would need `gudhi`, a *new* undeclared dependency
  stacked on the existing `ripser`/`persim` reproducibility gap, with `pyproject.toml` frozen.
  — **For research:** 02.6 worked at `n <= 2000` and the ROADMAP's own PU topology prior is stated
  at that scale; that is the natural starting point for the ratified budget, but the budget itself
  is a research question, not a decision taken here.

### Dimension protocol and the homology ceiling (SC-2, SC-3)

- **D-09:** **All eight frozen estimators run** — `mle`, `two_nn`, `danco`, `mind_mli`,
  `mind_mlk`, `ess`, `tle`, `gmst` — at every `k` in the sweep, spread reported, **no
  aggregation**.
  — **Why:** SC-2 asks for several estimators and their spread; the code is already built and
  frozen so the marginal cost is a function call; and this is the project's own library being
  exercised on the question it exists for. Phase 02's `d_frozen = 5` was flagged suspect precisely
  because three estimates clustered at 18–25 — **disagreement is the signal**, and averaging it
  away is what produced the suspect number.

- **D-10:** A single `d_hat` is resolved by a **plateau-and-consensus rule, ratified blind**: the
  integer at which a ratified majority of the eight plateau at the same value over a non-trivial
  contiguous `k` range. **No consensus → no `d_hat` is emitted and abstain (d) fires.**
  — **Why:** same plateau structure Phase 1 used to freeze `k*`, and it never produces a number
  the estimators do not actually agree on. A median across estimators is defined even when they
  are bimodal — a `5/5/5/20/20/22/24/25` split medians to ~20 and reports a plateau no estimator
  individually supports, which is how `d_frozen = 5`'s suspect neighbourhood arose. Phase 02's
  split would have **failed** this rule rather than yielding a number.
  — **`d_frozen = 5` is not inherited.** This phase re-estimates and reports its own `d_hat`
  against that record.

- **D-11:** The homology degree ceiling is **capped at `H_2`**, the library maximum — not
  `H_dhat`. **This amends SC-3's literal text** ("degrees `H_0` through `H_dhat`"), and the
  amendment is stated, not silent.
  — **Why:** `{S^1, S^2, T^2, disk/ball}` is fully separated by `H_0, H_1, H_2`; higher degrees
  buy the decision nothing, and the PU prior points at `d_hat ~ 18–25` where ripser is
  combinatorially hopeless. A literal reading with a compute abort would produce no answer for the
  one cloud the phase exists to probe, and the abort threshold would become an unratified constant
  doing the capping anyway.
  — **Consequence, carried as assumption A-01:** abstain (a) can never fire on high-degree
  homology. A cloud with non-trivial `beta_3` reads as `(1,0,0)` and is called a ball.

- **D-12:** **Local `d_hat` is obtained by calling the frozen estimators on anchor-point
  neighbourhood subsets**, via the `precomputed_knn_dist_sq` argument they already accept.
  Dispersion is reported; a ratified dispersion bound fires abstain (b). **No code in
  `src/effdim/` is touched, and no estimator is duplicated.**
  — **Why:** SC-2 requires reporting strong `d_hat` variation across the cloud as evidence against
  a global template, and abstain (b) needs it. `geometry.py:81` computes per-point estimates and
  discards them via `np.mean`, and the module is frozen — verified during this discussion. Calling
  the frozen estimator on subsets keeps the local number bit-identical in provenance to the global
  one, so a local-versus-global disagreement is about the data rather than about two
  implementations. A notebook-scoped per-point Levina–Bickel would give a denser field but creates
  a second copy that can drift, and only MLE is pointwise — the other seven would have no local
  counterpart.

### Benchmark design and scoring (SC-4, SC-5)

- **D-13:** Scoring is a **three-way tally — correct / wrong / abstained** — every cell in exactly
  one bucket, all three counts reported. Accuracy is `correct/total`, abstention is
  `abstained/total`, and **error rate `wrong/total` is the third number**. Not accuracy-over-
  non-abstained.
  — **Why:** it makes the abstain-versus-wrong tradeoff visible as data rather than encoding a
  preference in a formula — the "never collapse read-outs into a score" discipline applied to the
  benchmark itself. Under the selective-prediction convention a front end that abstains on 95% of
  cells and is right on the rest scores 100% accuracy, which is exactly the failure SC-4's
  "a selector that never abstains is not thereby better" warning is about, running in the other
  direction.
  — **Note:** on synthetic, ground truth is always in-library, so an abstain is a miss (mostly
  condition (d)). On PU, abstain may be the *correct* answer. The two arms' abstentions do not
  mean the same thing — a further reason the numbers stay separate.

- **D-14:** The immersion is **canonical embedding → random orthogonal lift into `R^D` → ratified
  smooth nonlinear warp**, with the **Jacobian rank checked at sampled points, not assumed**.
  — **Why:** the rank check is non-negotiable. A "random smooth map" that stops being an immersion
  self-intersects or collapses a dimension, and then the ground-truth label is silently wrong —
  the benchmark would be scoring the front end against an answer that is itself incorrect, and
  every accuracy number downstream becomes unattributable. A randomly initialised net as the
  immersion (02.6 built one) has nothing constraining it to be an immersion and would fail exactly
  where the cloud gets interesting.

- **D-15:** The grid is a **full factorial on `(D, noise)`, with `n` and sampling density as
  one-factor-at-a-time arms off a ratified baseline cell. `D = 768` is a required level.**
  — **Why:** the phase's entire premise is a `D`-by-noise **interaction** — Euclidean PH is
  documented to lose a *noisy* circle in *high* ambient dimension, and neither factor alone
  reproduces it. Decomposing them would design the effect out of the benchmark: both metrics could
  agree everywhere simply because the cell where they diverge was never visited. A full four-axis
  factorial is 324 cells before replicate draws at only three levels each, which this phase is not
  sized for. `D = 768` is required, not optional, per the discipline carried forward from 02.6
  where three defects passed every toy-scale check and failed at real scale.

- **D-16:** The CLAUDE.md-mandated Swiss roll check (SC-5) runs **in-library positive controls at
  matched `n`/`D`/noise** alongside the roll — a sampled `S^1` and `T^2` whose expected labels are
  non-trivial. These are CLAUDE.md step 6's "baseline known to succeed".
  — **Why:** the roll's correct answer *is* the trivial template, so a front end that has silently
  degenerated into always emitting `disk` **passes the roll check** with no controls. The controls
  are what make the disk call falsifiable.
  — **Live prediction to test, not a formality:** `02.6-CONTEXT.md` D-02 records that the Swiss
  roll's **ambient** `beta_1 = 1`, from near-touching spiral arms. The Euclidean arm is therefore
  predicted to see a spurious cycle on a contractible sheet where the geodesic arm should not —
  making SC-5 a live test of abstain condition (c).

<assumptions>
## Assumptions

- **A-01 — the `H_2` cap makes the front end blind to `beta_3` and above (from D-11).** Abstain
  condition (a), "off-library", cannot fire on high-degree homology. Any cloud with non-trivial
  `beta_3` reads as `(1,0,0)` and is classified as a ball. The front end's claim is therefore
  bounded to "off-library *as detectable through* `H_0..H_2`", and must never be described as
  having ruled out higher-genus or higher-degree structure. This is a stated bound, not a
  measurement.

- **A-02 — Betti numbers do not determine homeomorphism type.** Inherited from the ROADMAP Design
  note and restated because D-01 makes it load-bearing: PH yields *candidates*, not a unique
  manifold. The approach works only because the hypothesis class is small. The front end is a
  classifier over a named library and must never be described as recovering the manifold.

- **A-03 — homology recovery from finite samples needs sampling-density and regularity
  assumptions an arbitrary cloud does not guarantee.** D-02's bootstrap band is the phase's
  practical stand-in for a density guarantee; it is not a proof that the recovered homology is the
  manifold's.

- **A-04 — PH seed/draw variance is still unmeasured in this project.** Carried forward from
  `02.6-CONTEXT.md` A-03. D-08 reports spread across independent draws; if that spread swamps the
  between-template differences, that is a finding about the criterion and should be reported as
  one rather than absorbed.

- **A-05 — the ratified `n_ph` budget may not be large enough to resolve `H_2` on `S^2`/`T^2` at
  `D = 768`.** D-08 and D-15 interact: the budget is pinned identically across all cells, and the
  hardest cell is high-`D`, high-noise, `H_2`. If `S^2` and `T^2` are unrecoverable at the pinned
  budget, the benchmark measures the budget rather than the front end. The research pass should
  size this before the budget is ratified, since ratification precedes measurement.

</assumptions>

<specifics>
## Specific Ideas

- **The abstain-versus-wrong asymmetry is the design's load-bearing idea.** A wrong template sends
  the deferred VAE phase to constrain a latent space to the wrong `Z` and derive curvature through
  it — a confident wrong number with no detection path. Abstention is the cheap failure. Every
  decision in the rule (D-02's per-metric band, D-03's four conditions, D-13's three-way tally)
  exists to keep that asymmetry visible.
- **`beta_0 = 1`, no persistent `beta_1`, clean `d_hat` plateau is NOT an abstention.** It matches
  the `ball` row and is a positive call of the trivial template — the likely PU answer per the
  ROADMAP prior. If PU is ball-like, "does restricting to a template help?" has no answer on PU
  because there is no non-trivial template to restrict to, and SC-6 finding exactly that is a
  complete, reportable outcome that legitimately terminates the follow-on arm. **It is not a
  failure of this phase.**
- **The `ball` row must say *which* ball.** D-04's joint key exists so that `B^2` and `B^18` are
  distinguishable outputs; they are materially different objects to constrain a VAE to.

</specifics>
