## The chosen warp, and the rank_tol at which all four templates pass at D=768 (for plan 02.7-08's ratification)

**Warp form (`smooth_warp`):** for a lifted point `x in R^D`, a fixed random orthonormal frame `W` (drawn once via QR of a `D x D` Gaussian, seeded by `warp_seed`):

```
projections = x @ W
warp        = strength * sin(freq * projections)
warped      = x + warp @ W.T
```

Its Jacobian w.r.t. `x` is `I + strength*freq * W @ diag(cos(freq*projections)) @ W.T` -- a symmetric perturbation of the identity, invertible whenever `strength*freq < 1` (the eigenvalues are `1 +/- strength*freq*cos(...)`, bounded away from 0 at the small `strength` this plan tests). `T2`'s major/minor radii are fixed module constants `T2_MAJOR_RADIUS=2.0`, `T2_MINOR_RADIUS=1.0` (matching `02.7-RESEARCH.md` Pitfall 1's own measured `(R=2,r=1)` pair).

**Measured this session, at `D=768`, `strength=0.05`, `freq=1.0`:** all four templates (`S1`, `S2`, `T2`, `ball` at `d=5`) pass `is_immersion=True` with `min_rank==expected_rank` at `rank_tol=1e-6` -- singular values of the true tangent directions sit at `O(1)` against float64 noise at `~1e-14`, so `1e-6` cleanly separates them with wide margin. No template was observed near the rank-tolerance boundary in this session's runs (all measured `ranks` arrays were uniformly at `expected_rank`, no marginal per-point entries). Plan `02.7-08` should treat `1e-6` as a starting point with wide headroom, not a tightly-calibrated bound -- this session did not sweep `strength`/`freq`/`rank_tol` jointly to find where the check starts failing.
