### Implementation choices made where the plan's action text was underspecified

**1. "recon rel err" formula.** The plan's Task 1 action text names two things without giving
one exact formula tying them together: "computes held-out reconstruction relative error via
`cae.reconstruction_stats`." `reconstruction_stats` itself returns `mse_per_dim`/`mse_total`/
`mean_norm`, none of which is literally a "relative error." Resolved by following the
established convention already used elsewhere in this same phase and its predecessor
(`notebooks/02.2_swiss_roll_cae_check.ipynb`'s `rel_err` cell, and `02.6-03-PLAN.md` Cell 8's
"mean relative error per point" appearing immediately after a `cae.reconstruction_stats` call):
`mean(||x - y|| / ||x||)` over held-out points, computed alongside (not instead of)
`cae.reconstruction_stats`, whose `mse_per_dim` is retained as an extra provenance field
(`recon_mse_per_dim`, printed per seed) rather than discarded. This is the more literal
reading of the plan's own two-part instruction and matches every sibling notebook's own
convention in this phase — not a Rule 1/2/3 fix, a documented interpretation of an
underspecified formula.
