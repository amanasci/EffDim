<objective>
Run the nine-fit PU grid and select `n_charts` by the rule that was written down before any of these
numbers existed.

There is no gate on this side. PU has no analytic `H`, so D-02's floor does not apply and nothing
here passes or fails — there is a diagnostics table to read and a configuration to choose from it.
The discipline that replaces a gate is that the rule was fixed in advance and the evidence stays
uncollapsed: four separate diagnostics, three seeds, a printed table, a lexicographic order.

D-12's escalation trigger is expected to fire. A quick task measured the CAE preserving H0 merge
structure about five times worse than a plain AE at matched embedding dimension using roughly eight
times the parameters. Different chart counts may change that; the prior is that it does not. Whether
firing means running a `d` sweep — which no budget in this phase covers — is a developer decision,
put at a checkpoint rather than answered by the planner or absorbed silently.

Purpose: pick the fit the whole downstream curvature field is computed from, on evidence, by a
pre-declared rule.
Output: nine recorded fits, one printed table, one selected `n_charts`, one recorded escalation
decision.
</objective>
