candidate `n_neighbors` values, then full Isomap fits at only the 3-4 surviving values, then the

Purpose: sklearn does not raise on a disconnected k-NN graph — it warns and silently bridges
components with fabricated long edges. Symmetrically, a short-circuit edge at too-large k
reroutes many shortest paths and produces a globally distorted embedding that looks fine. The
scan catches the first; the stability comparison catches the second. Every sweep constant,
including the three plateau thresholds, is fixed in a cell that executes before the first fit,
enforced by a cell-index assertion — the milestone's garden-of-forking-paths concern bites here.

<discretion_resolved>

**Open item 1 — the three numeric thresholds for the D-10 plateau criterion.** All three fixed
in `§4.0`, before the first stage-2 fit, ordering asserted mechanically by a cell-index check.

- **Metric 1 — Procrustes disparity, threshold `<= 0.10`.** `scipy.spatial.procrustes(A, B)`
  disparity absorbs the axis sign/rotation ambiguity inherent to eigendecomposition-based
  embeddings (not a bug); 0.10 means >=90% of aligned variance shared — loose enough for smooth
  deformation as k grows, tight enough that a short-circuit edge fails it decisively.
- **Metric 2 — relative leading-eigenvalue change, threshold `<= 0.15`, self-normalized** by each
  spectrum's own leading eigenvalue (Isomap's global scale is arbitrary, FEATURES.md §4) — tests
  spectrum *shape* stability, not uniform rescaling. Max possible value is 1.0.
  `max_i |lam_i(k2)/lam_1(k2) - lam_i(k1)/lam_1(k1)|`.
  - **Metric 3 — Spearman correlation of geodesic distances, threshold `>= 0.95`**, on a fixed
  sample of `GEO_PAIR_COUNT = 100_000` index pairs drawn once (`GEO_PAIR_SEED`), reused unchanged
  across every adjacent-k comparison (PITFALLS Pitfall 2: rank ordering should change smoothly; a
  discontinuity signals a short-circuit edge switching on/off). Sampled rather than all ~50M pairs
  to keep each npz inside D-13's ~1 MB budget.
- **Load-bearing consequence:** D-13 doesn't persist `dist_matrix_` for sweep fits, so pair
  distances must be extracted inside the fit loop, while the matrix is still in memory.
- **Plateau selection rule (pre-registered here, applied by plan 04):** `k*` is the centre of the
  widest maximal run of consecutive swept k values where all three adjacent-pair metrics pass.
  `MIN_PLATEAU_RUN = 3` (>=2 consecutive passing adjacent pairs). Even-length run centre ties to
  the **lower** k. No run `>= 3` -> halt with remediation options, no silent fallback.

Cross-references: plan 01 answers items 2 (D-08 margin) and 4 (output-hygiene); plan 02 answers
item 3 (provisional `d`); plan 04 answers items 5-6 (section numbering, Phase 1->2 interface).

</discretion_resolved>
