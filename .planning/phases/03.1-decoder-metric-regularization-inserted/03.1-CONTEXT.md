# Phase 03.1: Decoder Metric Regularization (INSERTED) - Context

**Gathered:** 2026-08-18
**Status:** Ready for planning

<domain>
## Phase Boundary

A **weight ladder measuring whether the `scale` and `christoffel` decoder priors fix the two
metric pathologies Phase 3 diagnosed**, run on the `d=20` **saddle** fixture, which has analytic
`H` and currently fails. Plus **CURV-04 closure**: recording the metric's absolute scale
(`λ_min`, `λ_max`, `det(g)`) alongside the scale-invariant ratio `cond(g)`.

**This is measurement, not implementation.** `decoder_priors.py` already implements all four
modes, opt-in and default-off, through a contextmanager that never edits `cae.py`. The only new
code this phase writes is a runner, a Swiss roll notebook, and the CURV-04 instrumentation.

**The two pathologies, both measured in `03-FINDINGS.md` §5:**

1. **Uniform collapse** (seeds 20260814, 20260815) — the *entire* metric spectrum, `λ_max`
   included, sits at `~1e-07` (`det(g) ~ 1e-162`, `‖J‖_F ~ 1e-03`). A near-non-immersion in
   every direction at once. Their `‖H‖` is `g⁻¹ (~1e+09)` times `II (~1e-05)` — arithmetic on a
   near-singular metric, which is why it comes out **constant per chart**, agreeing to twelve
   significant figures.
2. **Anisotropy** (seed 20260813) — `λ_min = 1.017e-07` at a *healthy* `λ_max = 3.352`. The only
   fit of three whose metric has a real absolute scale, and the only one producing a spatially
   varying field.

**Why each arm exists.** Measured under a uniform rescaling `J -> cJ`: `christoffel` and
`cond(g)` are **exactly invariant** — blind to collapse. `conformal` is **minimized** by
collapse, so as a prior it would actively reward the pathology. `isometry` saturates at
`‖I‖²_F = d` with parameter gradient vanishing as `g -> 0` — a nudge, not a barrier. Only
`scale` (`(log det g / d)²`) diverges, with gradient `∝ g⁻¹`. So **`scale` targets the collapse
and `christoffel` targets the anisotropy**, and the two are never collapsed into one weight.

**Not in scope**: any PU fit (the roadmap: "PU comes after, if and only if a control clears");
reopening any sealed verdict; editing `cae.py`; resuming the phase-2 stage.

</domain>

<decisions>
## Implementation Decisions

### Test bed and arm matrix

- **D-01:** **The `d=20` saddle is the only fixture.** It is the sole control that scores all
  four axes — its analytic `H` is varying and mixed-sign, so `rho` and `R²` are defined, where
  the sphere's constant `H` leaves both undefined by construction. It is also the cleanest
  failure on record to try to move: `rho = −0.0151`, `R² = 0.000002`, cosine `−0.000478`,
  magnitude ratio `9955`, `cond(g) ≈ 1.88e+08`, 4/4 charts. At `d=4` the identical fixture gives
  `rho = 0.989`, `R² = 0.980`, so the gap is the *fit's*, not the estimand's. The sphere is not
  run. — **Reversibility:** reversible — a sphere arm can be added later at the cost of its own
  fits; nothing in the runner's design forecloses it.

- **D-02:** **Three arms plus a baseline: `weight=0`, `scale` ladder, `christoffel` ladder, then
  one combination cell.** The combination arm is **best-of-each**: run the two single-mode
  ladders first, pick each mode's best weight on D-08's read-out, then run **one** cell at
  `(best_scale, best_christoffel)` × 3 seeds. Cost is additive, not multiplicative. **This cell
  is a post-hoc confirmation, not an independent measurement, and must be labelled as such in
  every table it appears in** — its weights were chosen after seeing the ladders.

- **D-03:** **3 seeds per cell, median *and* full spread always printed.** Matches Phase 3's own
  three-seed reporting unit so 03.1's numbers are directly comparable to the 52× spread that
  motivated this phase; reuse seeds `20260813 / 20260814 / 20260815` where the fixture allows.
  **Never report a single draw.** Stated limitation to carry into the write-up: 3 draws cannot
  separate a small real effect from seed noise, and the phase says so rather than implying
  otherwise. — **Reversibility:** costly — the seed count sizes the entire compute budget.

- **D-04:** **Ladder weights are calibrated per mode at init, not hand-picked in absolute
  units.** Measure each penalty's raw value at epoch 0 on the saddle, then set weights so the
  penalty contributes a **declared fraction of the base loss** (e.g. `{0.01, 0.1, 1.0} ×
  base_recon / base_penalty`). Rationale: the two penalties differ by ~2 decades in raw
  magnitude on real checkpoints — `scale` measured `62.09 / 346.05 / (seed 15)` against
  `christoffel`'s `2.34` — so one shared absolute ladder would spend roughly half its cells
  where one mode does nothing measurable. The calibration probe is nearly free. **The fractions
  are declared in the plan before the probe runs**; only the resulting absolute weights are
  data-derived.

- **D-05:** **The `weight=0` baseline is re-fit fresh inside 03.1, 3 seeds, under this phase's
  own protocol** — Phase 3's sealed `d=20` saddle row is *not* reused as the comparison point.
  Rationale: `03-NOTE-isometry-prior-spike.md` §5 flags exactly this trap — its own `weight=0`
  arm "is not comparable cell-for-cell to the sealed grid" because early stopping differed. Also
  follows Phase 3's D-10 (fresh fits only). At `weight == 0.0` `decoder_prior_active` installs
  nothing at all, so the baseline is **structurally**, not merely numerically, the untouched
  `cae.train_cae` code path.

### Compute budget and the halt rule

- **D-06:** **Envelope is overnight, ~8–12 h, on CPU.** Sized to what the arm matrix actually
  costs rather than to a round number that must then be defended. Precedent: Phase 3's `03-07`
  PU sweep ran a ~5.6 h nine-cell grid against a 5 h envelope and was accepted. **This is the
  decision that killed the predecessor** — `03-NOTE-isometry-prior-spike.md` §3 recorded
  `BUDGET NOT MET` with **zero cells trained**, because the first-order prior tripled per-epoch
  cost (`3.685s → 10.699s`) and the cheapest candidate projected `3636s` against a `3000s`
  budget. `christoffel` at `chart_dim=20` costs roughly `chart_dim` times a Jacobian **on top of
  that**. — **Reversibility:** costly — the ladder, seed count and epoch budget all size off it.

  **CPU, not GPU:** every number this phase compares against — the sealed `03` rows, the exact
  anchor `rho_chart = -0.06041003026778113`, the spike's own timing — was measured on CPU, so
  nothing needs re-anchoring and reproduction stays exact. `chart_curvature` refuses anything but
  float64, where consumer-GPU throughput is poor anyway.

- **D-07:** **The pre-declared relief valve, if the timing probe still projects over the
  envelope, is to cut `CHRISTOFFEL_MAX_ROWS_PER_CHART`** (currently 8). This is legitimate
  because `decoder_priors.py` documents that constant as **a compute bound, not a tuning knob
  for the penalty's strength** — "the penalty is a batch mean either way, so a subsample
  estimates the same quantity with more variance rather than a different quantity." Declaring it
  up front means the fallback is a **stated variance cost on a term the module already
  sanctions**, not a redesign under time pressure — which is what the spike's own `--probe`
  docstring forbids. Consequence to report: wider error bars on the `christoffel` arm
  specifically. **Explicitly not the valve:** cutting the fixture's sample count (Phase 3's
  Amendment 1 raised `N_POINTS` 3000 → 12000 precisely because curvature is a second-derivative
  quantity), or cutting epochs (under-training is a confound Phase 3 spent a whole quick task
  on).

### The read-out

- **D-08:** **Two-tier read-out, tiers never merged.**
  - **Tier 1 — mechanism.** Does the metric itself improve as weight rises? `λ_min`, `λ_max`,
    `det(g)`, `cond(g)` moving toward healthy.
  - **Tier 2 — estimand.** Do the four axes move toward 1? cosine / magnitude ratio / `R²` /
    `rho`, **scored separately, never collapsed** (milestone-standing rule: at seed 0 a decoder
    scored cosine `0.9706` while calibration slope was `−0.1856` at `R² 0.0533`).

  Tier 2 is the point; **Tier 1 is what tells a real null apart from a broken hookup.** A prior
  with no measurable effect on its own target quantity was never actually tested. The halted
  spike's runner already framed itself around a `MECHANISM DEMONSTRATED` verdict for this reason.
  The two tiers may disagree, and if they do, both are reported.

- **D-09:** **Held-out reconstruction is printed beside every cell as the bias guard.** Both
  penalties are parameterization-only by construction — `scale` is a function of `g` alone,
  `christoffel` is test-proven to penalize the tangential part of `D²F` and never the normal part
  — so neither can move `H = tr_g(II)`, which is a property of the decoder's *image*. But those
  tests prove the **penalty** is invariant, not that the **fitted surface** is unchanged: the
  remaining risk is the decoder fitting a different, easier surface, and on a fixture with fixed
  analytic truth that shows up directly as reconstruction degradation. **Stated rule: an
  improvement bought with materially worse reconstruction is not an improvement.** **No hard
  numeric threshold** — the last reconstruction threshold proposed in this milestone
  (`mse_per_dim < 2.5e-04`) was **deferred as circular**, anchored to the model's own measured
  ceiling, and that objection is unchanged.

- **D-10:** **Diagnostics table with the reading rule stated in the plan. No declared bar, no
  verdict artifact.** No `PREREGISTRATION.md`, no ratification commit, no git-ancestry proof, no
  verdict JSON, no threshold table. The plan states **before anything runs** which direction on
  which axis counts as the prior working, and that a null is a complete answer. Rationale:
  Phase 3's D-15 and the ROADMAP's own start-simple instruction; **03.1 selects nothing
  downstream on its own**, so there is nothing a gate would protect. Note for the planner: a
  floor on the estimand was considered and rejected — nothing in this milestone bounds what
  `rho` is achievable at `d=20` on a saddle, so any floor would be invented rather than
  calibrated. — **Reversibility:** reversible — machinery can be added to a later step if one
  turns out to need it.

- **D-11:** **If both arms are null, 03.1 reports the null plainly and stops.** Escalation is an
  **explicit user decision**, per `02-NOTE-phase-2-stage-on-hold.md` §5's rule that only a named
  user decision resumes a held phase. The phase does **not** pre-commit to a conclusion the data
  has not produced (e.g. "therefore the substrate is wrong"), and does **not** widen its own
  scope — more weights, a `d` sweep, the sphere fixture — to avoid reporting a negative result.
  Consequence, stated rather than hidden: **Phase 4 stays blocked** with no proposed route out.

### Code shape and deliverables

- **D-12:** **The combination arm nests the existing contextmanager.** Two `with
  decoder_prior_active(...)` blocks, `scale` outer and `christoffel` inner; the inner shim wraps
  the already-patched `cae.chart_loss`, both penalties land in `total`, and the `finally` blocks
  unwind in order. **Zero new machinery, and the two weights stay structurally separate — never
  collapsed into one — which is exactly what the roadmap demands.** The signature is not
  extended and no combined `PRIOR_MODES` entry is added. **Required by this choice: a test
  proving the nested wrapper *composes* rather than replaces, and that restore is exact through
  both levels including on exit by exception** — mirroring the existing
  `test_decoder_prior_active_restores_on_exit_by_exception`.

- **D-13:** **A new runner under `notebooks/diagnostics/`, copied from
  `synthetic_control_run.py`** — its `d=20` saddle fixture, training protocol and metric call
  sequence copied rather than restated. Follows the milestone runner pattern: resumable,
  per-cell timed, `--smoke` / `--dry-run` / `--resume`, one JSONL record per cell. **It must
  reproduce one of `synthetic_control_run.py`'s sealed rows exactly — `==`, not a tolerance —
  as an anchor check before the ladder is trusted.** That is the move that established
  faithfulness in the halted spike (`ANCHOR OK: rho_chart == -0.06041003026778113 exactly`), and
  it is what distinguishes a faithful copy from a re-derivation. **Additive only:**
  `synthetic_control_run.py` and `swiss_roll_isometry_prior_sweep_run.py` are not edited.

- **D-14:** **`notebooks/03.1_swiss_roll_decoder_prior_check.ipynb` — one notebook covering all
  three modes (`scale`, `christoffel`, and the nested combination).** This **discharges the
  standing obligation** recorded in `03-NOTE-isometry-prior-spike.md` §6 — "if the prior is ever
  adopted, a Swiss roll prior check must exist and pass before any PU fit runs with a non-zero
  prior weight" — which is currently undischarged, and which predates both `scale` and
  `christoffel`. Per CLAUDE.md: import the model code unchanged from `notebooks/pu_manifold/`,
  generate the roll in-notebook with `make_swiss_roll`, latent dim 2, train from scratch under
  two minutes on CPU, plot original vs reconstruction as both 3-D and x-z scatter coloured by
  `t`, compare against `cae.PlainAutoEncoder` at the same bottleneck, end with three or four
  printed pass/fail lines. **No caching, no thresholds, no verdict JSON, under ~15 cells.**
  — **Reversibility:** one-way — CLAUDE.md states the check is "not a follow-up task"; a PU fit
  with a non-zero prior weight may not precede it.

- **D-15:** **CURV-04's absolute-scale instrumentation lands in `chart_curvature.py`, so every
  caller inherits it.** `chart_mean_curvature` already returns `metric_condition_number`; add
  `λ_min`, `λ_max` and `det(g)` there, and the new ladder runner, `synthetic_control_run.py` and
  `curvature_field_pu_run.py` all get them with no separate edits. One place, one test, no
  drift. **Required by this choice: the reverse path must be shown still bit-identical**, in the
  same shape D-09 of Phase 3 required when the mode toggle was added to this same module.
  **Phase 3's recorded grids are NOT re-run** — the roadmap's observation that no existing record
  can be re-audited for collapse stands as a recorded limitation, not as work this phase buys.

## Existing Code Insights

### Reusable Assets
- `decoder_priors.decoder_prior_active(model, weight, mode)` — the scoped shim. Rebinds
  `cae.chart_loss` to a wrapper that calls the original, adds the penalty **to `total` only**
  (leaving `recon` and `xent` unpolluted in `train_cae`'s history), and restores in a `finally`
  including on exit by exception. **At `weight == 0.0` it installs nothing at all.** Chosen over
  forking `train_cae` because `cae.py` is the sealed 02.2 architecture with RNG-order-dependent
  anchors, and an unfaithful fork is a failure mode this project has already paid for.
- `decoder_priors.isometry_penalty` / `christoffel_penalty` — structurally identical: same
  `no_grad` encode → `chart_coords` → argmax assignment (**the same assignment
  `chart_curvature.chart_curvature_field` uses**, so the prior constrains the decoder at the
  coordinates curvature is actually measured at), same per-chart loop, gradient into
  `chart_decoders` and `embedding_decoder` only — never `chart_encoders` or `chart_predictor`.
- `decoder_priors.metric_deviation(g, mode)` — pure tensor function over the first-order modes,
  no model and no dtype guard, so its answers are exactly known and independently checkable. It
  **refuses second-order modes structurally** (there is a test for that).
- `synthetic_controls.make_saddle_control` — the `d=20` fixture with analytic `H`.
- `cae.PlainAutoEncoder` / `train_plain_ae` — the matched baseline CLAUDE.md's notebook rule
  requires.

### Established Patterns
- **Expensive grids are runner scripts** under `notebooks/diagnostics/` (resumable, per-cell
  timed, `--smoke` / `--dry-run` / `--resume`, JSONL per cell); notebooks are reserved for
  presentation and for CLAUDE.md's Swiss roll checks.
- **Exact-equality anchor checks** (`==`, not a tolerance) prove a copied runner is a faithful
  copy rather than a re-derivation, before its new results are trusted.
- **Four axes scored separately, never collapsed** — direction (cosine), magnitude (median ratio
  and per-point CV), calibration (slope, intercept, `R²`), rank (Spearman).
- **`CURVATURE_CONVENTION = "trace"`**, `H = tr_g(II)`, regression-guarded. A unit sphere gives
  `‖H‖ = d`, not 1. This codebase has already shipped and fixed exactly one factor-of-`d` bug.
- **Notebooks are committed executed, with outputs.**
- `chart_curvature` runs **float64 only** (`_assert_float64` refuses otherwise) — relevant to
  D-06's CPU choice.

### Integration Points
- `chart_mean_curvature`'s return dict is the single point where D-15's `λ_min` / `λ_max` /
  `det(g)` fields enter; every runner reads from there.
- `notebooks/pu_manifold/tests/` — D-12's nesting test and D-15's bit-identity check land beside
  the existing projector-equivalence, sphere known-answer, and `decoder_priors` invariance tests.
- Phase 4 consumes `‖H‖` by **quantile partition**, so **ordering** is the quantity that
  ultimately matters — which is why the saddle (where `rho` is defined) was chosen over the
  sphere (where it is not).

## Specific Ideas

- **The predecessor's failure mode is the thing to avoid, and it was budgetary, not scientific.**
  `03-NOTE-isometry-prior-spike.md` delivered "tested, working infrastructure and zero
  measurement." D-06 and D-07 exist entirely so that 03.1 produces numbers.
- **The combination cell's post-hoc status is not a footnote.** Its weights are picked after
  seeing the ladders, and every table carrying it says so.
- **A null is a complete outcome.** The phase reports "regularizing the parameterization does not
  rescue the `d=20` CAE metric" as plainly as it would report a success, and does not widen scope
  to avoid saying it.
- **Tier 1 exists so a null is interpretable.** Without evidence the penalty moved its own target
  quantity, a flat Tier 2 cannot be told apart from a prior that was never really active — the
  same logic behind CLAUDE.md's Swiss roll rule.
- **The sphere is not run**, but it is the obvious first extension if the saddle moves: a
  constant analytic `H` makes flattening bias unusually readable.
