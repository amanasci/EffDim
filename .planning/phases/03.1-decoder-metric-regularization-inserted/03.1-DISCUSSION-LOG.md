## Test bed & arm matrix

### Which `d=20` fixture carries the measurement?

| Option | Description | Selected |
|--------|-------------|----------|
| Saddle only | Only fixture scoring all four axes — varying, mixed-sign `H`, so `rho` and `R²` defined. `d=20` row: `rho = −0.0151`, `R² = 0.000002`, cosine `−0.000478`, mag ratio 9955. At `d=4` the same fixture gives `rho = 0.989` | ✓ |
| Both sphere and saddle | Sphere adds a constant-`H` control making flattening bias readable; doubles the fit budget | |
| Sphere only | Cheapest, simplest analytic `H`, but only 2 of 4 axes defined and ordering unmeasurable | |
| Saddle, add sphere only if saddle moves | Sequential; buys the second fixture only when there is something to confirm | |

**User's choice:** Saddle only.
**Notes:** Ordering is the quantity Phase 4 consumes, and it is undefined on the sphere.

### Shape of the combination arm

| Option | Description | Selected |
|--------|-------------|----------|
| Best-of-each single cell | Run both single-mode ladders, pick each mode's best weight, run one combination cell × seeds. Additive cost; the cell is a post-hoc confirmation and must be labelled so | ✓ |
| Small 2-D grid | Coarse product grid, declared up front; measures interaction honestly; multiplies fit count | |
| Fixed diagonal ladder | One shared index driving both weights at a pre-declared ratio; the ratio is a guess | |
| Skip the combination arm | Two single arms only; cheapest, but departs from the roadmap's stated scope | |

**User's choice:** Best-of-each single cell.

### Seeds per ladder cell

| Option | Description | Selected |
|--------|-------------|----------|
| 3 seeds, spread always printed | Matches Phase 3's own three-seed reporting unit, so numbers are directly comparable to the 52× spread that motivated the phase; reuse seeds 20260813/14/15 | ✓ |
| 5 seeds | D-01's roll precedent; better effect/noise separation; 67% more fits | |
| 2 seeds | What the halted spike declared; its own note admits 2 seeds could not have separated a small effect from noise | |
| 3 on the ladder, 5 on survivors | Two-tier; concentrates seed budget where the claim lands; two seed counts in one table | |

**User's choice:** 3 seeds, full spread always printed.

### How ladder weights are chosen

| Option | Description | Selected |
|--------|-------------|----------|
| Calibrate per mode at init | Measure each penalty's raw value at epoch 0, set weights as a declared fraction of base loss; puts both modes on one interpretable axis | ✓ |
| Independent decade ladders per mode | Hand-picked absolute weights per mode, fully pre-declared; the two arms' weights are not comparable | |
| One shared decade ladder | Simplest; given the ~2-decade magnitude gap, roughly half the cells land where one mode does nothing | |
| Bracket-and-refine | 2 far-apart weights to bracket, then refine; adaptive, so not fully pre-declared | |

**User's choice:** Calibrate per mode at init.
**Notes:** Raw magnitudes on real checkpoints differ by ~2 decades — `scale` 62.09/346.05 against `christoffel` 2.34.
