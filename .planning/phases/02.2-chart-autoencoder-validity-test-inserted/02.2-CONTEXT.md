<decisions>
## Implementation Decisions

### Verdict logic (relationship to 02.1's Krein recommendation)
- **D-01:** The gate is a **standalone absolute test**. CAE is judged only against its own pre-registered thresholds. The Krein (8,0) comparison (02.1-RECOMMENDATION.md) is computed and reported as evidence but is **not load-bearing** for PASS/FAIL. — **Reversibility:** costly — flipping to head-to-head after thresholds are pre-registered would violate CAE-01's ancestry-proved ordering and require a fresh pre-registration cycle.
- **D-02:** On **FAIL: halt for user decision.** Findings documented in `02.2-FINDINGS.md`, milestone stops at the phase-2 stage. Adopting 02.1's Krein handoff for Phase 3 is NOT automatic — the user decides the next move (adopt Krein, iterate CAE, or other). Downstream notebooks/plans must not auto-fall-back.
- **D-03:** On **PASS: Phase 3 decodes from the CAE representation** (per ROADMAP). The phase must emit a machine-readable handoff naming exactly what Phase 3 consumes.

### Architecture constants (pre-registered, not tuned)
- **D-04:** Chart latent dimension **d = 20**, justified by the local intrinsic dimension cluster (TwoNN 19.5, local-PCA median 25.0, range 19–29 — `02-FINDINGS.md` §6.3/§6.4). Charts are local objects; local estimates are the matching referent. The 02.1 global elbow (8,0) is deliberately NOT inherited for chart dimension; record this divergence and its rationale in the pre-registration doc. — **Reversibility:** costly — changing d after training invalidates all fits and thresholds.
- **D-05:** Initial-encoder embedding dimension **l = 40** (≈2d, Nash–Kuiper motivation per paper).
- **D-06:** Initial chart count **N = 16**, over-specified then pruned a-posteriori (weight decay + Lipschitz regularization; decoder-weight-norm tolerance). Phase 1 confirmed a single connected component; 16 gives ample headroom over the paper's 4-chart double torus. Surviving chart count is a reported outcome, not a tuned input.

### Compute budget & training protocol
- **D-07:** Wall-clock ceiling **≤ 2 hours per fit** on laptop CPU (torch 2.13.0+cpu). Achieve via epoch cap / early stopping on loss plateau (expect ~20–40 epochs, batch 64, Adam lr 3e-4 per paper). Cap and stopping rule are pre-registered compute constants, committed before training.
- **D-08:** **3 independent training seeds total** (main fit + 2 replicates). Verdict metrics computed on the main seed; replicates supply chart-count stability and metric spread (CAE-05). Full protocol must fit an overnight ~8–10 h envelope.

### Gate metrics & thresholds
- **D-09:** **Three load-bearing metric families**, each with a pre-registered numeric threshold; all three must pass for PASS:
  1. **Geodesic distortion** on the frozen 200,000-pair sample (`r2_pair_seed = 20260731`, cached `geo_pairs_r2`) — same statistic as 02.1's DISTORTION, preserving cross-representation comparability even though the Krein number is not load-bearing.
  2. **Chart-transition cycle residual R_cycle** (paper eq. 8) on held-out points — atlas consistency, the claim unique to CAE.
  3. **Held-out reconstruction error** vs both ROADMAP baselines at matched capacity (plain single-chart AE; classical-MDS/Isomap reconstruction at the working dimension) — CAE-03.
  Unfaithfulness, coverage, and chart-count stability are reported as evidence, non-gating. — **Reversibility:** one-way — once thresholds are committed with git-ancestry proof (CAE-01), changing which metrics gate is post-hoc tuning, the exact garden-of-forking-paths move the milestone's pre-registration discipline exists to prevent.
- **D-10:** **Thresholds: planner/researcher proposes defensible numbers; user ratifies at a blocking `checkpoint:human-verify` before any training cell runs.** Pre-registration document committed first, ratification checkpoint second, training third — ordering proved by git ancestry (mirrors `02-REFIT-PREREGISTRATION.md`, commit 057b084 pattern).

### Claude's Discretion
- C2-smooth activation choice (tanh / softplus / SiLU) for chart decoders + embedding decoder — required by DEC-02/CURV-01..03 downstream (paper's ReLU is disqualified); report the substitution and any reconstruction cost.
- FPS pre-training implementation details (eq. 5), optional PCA chart-orientation init (eq. 6), Lipschitz regularization weight (paper: 1e-2).
- Holdout split design (fraction, seed) — pre-registered but numbers at planner's discretion.
- Code placement: follow existing `notebooks/pu_manifold/` module + tests pattern (cache.py precedent); no new package installs (torch already pinned in `notebooks/requirements-notebooks.txt`).
- `cae_verdict_{fit_key}.json` schema fields, modeled on `gate_verdict_43cf438bc944c509.json`.
