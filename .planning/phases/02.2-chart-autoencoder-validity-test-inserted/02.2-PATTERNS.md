### Cache I/O (npz/joblib/json with sidecar-manifest guard)
**Source:** `notebooks/pu_manifold/cache.py` (full file, 121 lines)
**Apply to:** `cae.py` (verdict writer), `03_cae_validity.ipynb` (all cache reads/writes for CAE fit artifacts, chart-transition results, verdict)
```python
def json_cache(stem: str, cfg: Dict[str, Any], compute_fn: Callable[[], Dict[str, Any]]) -> Dict[str, Any]:
    """Load-or-compute a json-backed artifact, keyed by a sidecar manifest."""
    path = cache_path(stem, "json")
    if path.exists() and _manifest_matches(stem, cfg):
        return json.loads(path.read_text())
    result = compute_fn()
    path.write_text(json.dumps(result, indent=2, sort_keys=True))
    _write_manifest(stem, cfg)
    return result
```
`_manifest_matches` raises `ValueError` on a cfg mismatch rather than silently reusing stale data — reuse verbatim for every new `cae_*` cache stem (e.g. `cae_fit_{fit_key}_seed{n}`, `cae_verdict_{fit_key}`). Never hand-roll a JSON writer for the verdict artifact.
