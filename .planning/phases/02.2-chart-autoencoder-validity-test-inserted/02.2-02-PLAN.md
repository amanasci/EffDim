<objective>
Build the Chart Auto-Encoder architecture and prove it end to end on a synthetic fixture, from
input tensor all the way to a cache-manifest-guarded verdict JSON.

Purpose: this is the phase's tracer. Every later plan expands outward from this one proven path.
The two highest-risk architectural details in the whole phase both live here and are cheapest to
get wrong silently: the two-hop decode (per-chart decoders target the *embedding* space R^l, not
the ambient R^m, with exactly one shared embedding decoder) and the terminal verdict artifact
contract. Proving both on the first commit means an architectural dead end costs one commit rather
than ten.

The architecture constants this module is parameterised by come from the pre-registration and are
the user's locked decisions, not choices made here: chart latent dimension 20 per D-04, initial
encoder embedding dimension 40 per D-05, and an over-specified initial chart count of 16 per D-06.
The C2-smooth activation substitution is CAE-06's requirement. The module takes them as constructor
arguments so the runners supply them from the named pre-registered constants.

Output: `notebooks/pu_manifold/cae.py` carrying the full architecture, the paper's eq. 3 loss, a
minimal real training loop, the strict-less-than verdict rule, and the verdict writer;
`notebooks/pu_manifold/tests/test_cae.py` carrying the end-to-end smoke test and the verdict
contract tests.
</objective>

Wire ONE path through every layer. Implement, in this order:

`activation_module(name)` returning the C2-smooth activation module for the pre-registered
`ACTIVATION`, supporting at least `"silu"`, `"tanh"`, `"softplus"`, plus `"relu"` reachable only
for the CAE-06 control fit. `mlp_stack(in_dim, hidden, out_dim, activation, out_activation)`

`InitialEncoder(in_dim, embed_dim, hidden, activation)` — E, mapping ambient `R^m` to the embedding
space `R^l`, linear output.
`ChartEncoder(embed_dim, chart_dim, hidden, activation)` — E_alpha, mapping `R^l` to the chart
space, with a `sigmoid` output activation so coordinates land strictly inside `(0,1)^d`.
`ChartDecoder(chart_dim, embed_dim, hidden, activation)` — D_alpha, mapping the chart space back to
`R^l`, linear output. Its output dimension is `embed_dim`, never `in_dim`.
`EmbeddingDecoder(embed_dim, out_dim, hidden, activation)` — D, mapping `R^l` to ambient `R^m`,
linear output.
`ChartPredictor(embed_dim, n_charts, hidden, activation)` — P, mapping `R^l` to per-chart
probabilities via a softmax output.

`ChartAutoEncoder(nn.Module)` holding one `InitialEncoder`, an `nn.ModuleList` of `ChartEncoder`,
an `nn.ModuleList` of `ChartDecoder`, exactly ONE `EmbeddingDecoder` instance shared by every
chart's forward pass, and one `ChartPredictor`. The shared decoder must be a single attribute
called by every chart — instantiating one per chart is the failure mode RESEARCH.md Pitfall 1
describes, and the parameter count would balloon accordingly. Methods: `encode(x)` returning

The reconstruction term is the per-row minimum over charts of the squared error. The cross-entropy
term uses `ell = softmax(-e)` detached and treated as a fixed target distribution against the
predictor's already-normalized probabilities, with the log clamped away from zero. The returned
`total` is the batch mean of the sum.

returns a dict of native floats with `mse_per_dim` (mean squared error divided by the ambient
dimension), `mse_total`, `mean_norm` (mean unsquared L2 reconstruction norm), and the per-dimension

per-dimension array under `dim_mse` for callers that persist it.
