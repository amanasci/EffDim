## Accomplishments

- **CAE-05 a-posteriori chart pruning:** `chart_survival(model, prune_tol)` computes each chart decoder's log-mass as a float64 sum of per-`nn.Linear`-layer spectral-norm logarithms (the same per-layer quantity `lipschitz_penalty` already computes), then prunes a chart when its mass ratio against the largest chart is **strictly less than** `prune_tol`. A chart whose ratio equals the tolerance exactly survives. Working in log space rather than a float32 product means a chart with several small-norm layers cannot silently underflow to a reported mass of exactly zero.
- **CAE-04 chart-transition cycle residual (eq. 8):** `r_cycle(model, x, alpha, beta)` implements the paper's formula verbatim in both directions -- encode/decode through chart alpha, re-encode/decode through chart beta, compare to the input with an unsquared L2 norm, plus the symmetric direction. On a degenerate identity-map fixture the residual is exactly zero (well below the 1e-10 tolerance); on a real trained model, swapping alpha and beta leaves the value unchanged.
- **CAE-04 overlap-pair selection rule:** `select_overlap_pairs(p, p_min, min_points, surviving_indices)` admits a holdout row to the T2 evaluation set only when both its top-2 surviving-chart probabilities clear `OVERLAP_P_MIN`, and raises `ValueError` naming the shortfall when fewer than `OVERLAP_MIN_POINTS` rows qualify -- an under-populated overlap set halts the run rather than reporting an ill-defined value.
- **CAE-05 non-gating topology measures (eqs. 20/21):** `unfaithfulness_coverage` samples chart-space points round-robin across the surviving (post-pruning) charts, decodes each through its chart decoder and the shared embedding decoder, and reports the mean squared distance to the nearest training point (unfaithfulness) and the distinct-nearest-neighbour fraction (coverage), matching an independently-reconstructed hand computation on a tiny fixture.
- **CAE-03 geodesic distortion on the global embedding (T1):** `fit_global_scale` fits the one pre-registered global isotropic scale factor (median target/representation squared-distance ratio, training-split pairs only); `embedding_distortion` squares the `geo_pairs` array before comparison (the cached array holds unsquared geodesic distances despite the "r2" in its name), applies the fitted scale, and delegates to `geometry_probes.distortion_stats` -- imported, not reimplemented, keeping the number bit-comparable with 02.1's own measurement. On an exactly-reproducing synthetic fixture the distortion is below 1e-12, which only holds if the squaring convention is applied on exactly one side.
- **T-02.2-11 structural mitigation, demonstrated:** `embedding_distortion` raises `ValueError` when handed an array whose feature dimension equals the model's chart dimension while differing from its embedding dimension -- the exact "computed distortion on chart-local coordinates" failure mode the phase's threat register flags as high-severity. `test_distortion_uses_global_embedding_not_chart_coords` both triggers this raise and shows the same underlying formula computed on chart-local coordinates (bypassing the guard deliberately, to compute the number the guard exists to prevent a caller from ever reaching) gives a distortion more than 2x worse than the correct global-embedding computation.

## Decisions Made

- `chart_survival`, `r_cycle`, and `unfaithfulness_coverage` accept a duck-typed model object (only the specific attributes each function reads) rather than requiring a `ChartAutoEncoder` instance -- this let the boundary and identity-map known-answer tests use minimal, fully floating-point-controllable stand-in classes (`_ChartDecoderOnlyModel`, `_IdentityChartModel`) instead of fighting numerical precision through a trained SiLU network.
- The pruning boundary test reads off the function's own bit-exact computed `chart_mass_ratio` value first, then nudges the *tolerance* by one ULP relative to that value, rather than trying to construct chart weights whose ratio hits an arbitrarily pre-chosen target bit-exactly -- `exp(log(w))` does not round-trip to `w` bit-for-bit in general, so this was the only way to get a genuinely bit-exact strict-less-than boundary case.
- `embedding_distortion` takes `chart_dim`/`embed_dim` as explicit integer parameters rather than a model reference, since the function otherwise operates only on precomputed numpy arrays (`z`, `geo_pairs`, `rows`, `cols`, `train_mask`) -- consistent with `fit_global_scale` and `geometry_probes.distortion_stats` being pure numpy/dict evaluation functions decoupled from any live model instance, matching how a future runner will call this after loading a cached fit's `z_all` array rather than re-encoding through a live model.
- `select_overlap_pairs`, `fit_global_scale`, and `embedding_distortion` are numpy-based (post-hoc evaluation, no autodiff needed) while `r_cycle` stays torch-based (it must run the model's actual forward passes) -- matching the existing split `reconstruction_stats` already established between training-time torch functions and evaluation-time numpy functions in `cae.py`.
- `unfaithfulness_coverage` assigns samples to surviving charts round-robin (deterministic given `seed`, no separate random draw for chart choice) rather than a random per-sample chart draw -- simpler, still an even split across the surviving charts, and made the hand-check test's independent RNG replication tractable (only one `torch.rand` call needs reproducing, not an additional `torch.randint` draw whose exact call-sequencing would also have to match).
