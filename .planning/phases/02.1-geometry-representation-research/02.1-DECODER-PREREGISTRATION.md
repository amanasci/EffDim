# Decoder-Side Check — Pre-Registration

**Committed before any decoder is trained.** Ordering provable by git ancestry, not asserted.
This document fixes every decision rule before the numbers exist, because the question it settles
is whether a *rule change made after seeing evidence* (`02.1-AMENDMENT-02.md`) was justified. That
amendment is only discountable-but-defensible if this check is run blind.

## What this is, and what it is not

`02.1-AMENDMENT-02.md` §6.4 names the check that would settle GEOM-04 without a rule change:

> "A Phase 3 decoder trained on Krein (40,25) coordinates and evaluated on held-out reconstruction
> (DEC-03/04) would measure directly whether the 18.4% is reachable. … `signature_transfer` is a
> cheap proxy for it, not a substitute — it measures distance distortion under a Euclidean form,
> not decoder reconstruction."

This is that check. It trains decoders **to decide a representation question**, and nothing more.

It is **not** Phase 3 work and does not satisfy DEC-01..05: no C2 smoothness audit beyond the
activation choice, no per-output-dimension distribution study, no curvature field, no reproducibility
contract beyond the seeds fixed here. Any Phase 3 decoder is trained fresh under Phase 3's own plan.
Nothing measured here is adopted as a Phase 3 artifact.

decoder consumes real coordinates under the ordinary quadratic form, which is the whole point: a
Euclidean-latent decoder is what Phase 3 would build.

be measured in the same run and reported, but a good result there does not make `(20, 20)` a
candidate.

## Protocol — identical across every arm

Only the input coordinates differ. Every other quantity is fixed here and applies to all arms:

    ARCHITECTURE     input_dim -> 256 -> 256 -> 768
    ACTIVATION       tanh          (C2-smooth; DEC-02 forbids ReLU-family, whose second
                                    derivative is identically zero)
    OPTIMIZER        Adam, lr = 1e-3, default betas
    EPOCHS           300           (fixed for every arm; no early stopping, no per-arm tuning)
    BATCH_SIZE       256
    SPLIT            80 / 20 train / held-out
    SPLIT_SEED       20260805
    TORCH_SEED       20260805      (identical initialisation draw for every arm)
    LOSS             mean squared error over all 768 output dimensions

**Input preprocessing is run BOTH ways, and both are reported:**

- `standardized` — each input coordinate centred and scaled to unit variance. **Primary.** Equalises
  the wildly different natural scales of `sqrt(|λ|)` across eigendirections, so no arm is advantaged
  or handicapped by coordinate magnitude alone.
- `raw` — coordinates as constructed. **Robustness check.**

Running both forecloses the objection that a preprocessing choice was made to produce an answer. If
the two disagree on any decision rule below, that disagreement is itself the finding and **no rule
fires**; the result is reported as inconclusive and Amendment 02 stands unchanged pending a better
experiment.

## Primary statistic

    MSE_PER_DIM = mean over held-out points and all 768 output dimensions of (x_hat - x)^2

Lower is better. Reported per arm, per preprocessing.

    RELATIVE_IMPROVEMENT(P, Q) = (MSE_PER_DIM(Q) - MSE_PER_DIM(P)) / MSE_PER_DIM(Q)

positive when P reconstructs better than Q.

## Decision rules — fixed now, before any number exists

Let `RI = RELATIVE_IMPROVEMENT(A, B)` on the **standardized** preprocessing, and let
`PROMISED = 0.183742` — the `reduction_fraction` the distance-distortion ladder measured for
(40,25) over the q=0 best, and therefore exactly the improvement the recommendation's assumption (3)
claimed was real signal.

**Rule 1 — RETRACTION.** If `RI >= PROMISED`: the signature advantage is fully reachable by a
Euclidean-latent decoder. `signature_transfer` was a misleading proxy. **`02.1-AMENDMENT-02.md` is
retracted**, the falsifier is un-fired, the coordinate-producing verdict is reinstated, and GEOM-04
returns to pseudo-Euclidean/Krein retention — subject to the separate, still-standing user directive
of `02.1-AMENDMENT-01.md` §1.3, which this check cannot overturn.

**Rule 2 — PARTIAL.** If `0 < RI < PROMISED`: the advantage is real at the decoder but smaller than
the distance statistic promised. **Amendment 02 STANDS**, and the measured margin MUST be written
into `02.1-RECOMMENDATION.md`'s rejection of Krein — the recommendation may not continue to imply the
advantage is unreachable when it is merely smaller.

**Rule 3 — CONFIRMATION.** If `RI <= 0`: Krein does not reconstruct better than the flat floor.
**Amendment 02 is CONFIRMED on the expensive evidence**, the graph-native recommendation stands, and
`02.1-RECOMMENDATION.md` records that the proxy was checked against the real measurement and held.

**Rule 4 — SIGNATURE CONTROL, independent of Rules 1-3.** Let
`RI_ctrl = RELATIVE_IMPROVEMENT(D, C)` at matched input width. If `RI_ctrl > 0`, the signature
carries decoder-usable information even where the headline arm does not, and this MUST be reported
in `02.1-RECOMMENDATION.md` **even if Rule 3 fires**. A confirmation that suppresses a positive
control is not a confirmation.

**Tie handling.** `RI` within `±0.01` of `0` counts as `RI <= 0` (Rule 3). `RI` within `±0.01` of
`PROMISED` counts as `RI >= PROMISED` (Rule 1). Stated now so a boundary value is not adjudicated
after it appears.

## Prohibited moves

- **Tuning any arm after seeing its result** — no per-arm epochs, learning rate, width, or
  activation. One protocol, four arms, two preprocessings.
- **Re-running with a different seed and reporting the better outcome.** `TORCH_SEED` and
  `SPLIT_SEED` are fixed above. If a seed sensitivity study is wanted it is a separate, dated
  document with its own rule, run after this one reports.
- **Adopting arm D's rung.** Control only, declared before the fact.
- **Reading a Rule-1 retraction as reinstating Krein for Phase 3 outright.** Amendment 01 §1.3's
  user directive rejecting Krein is independent of this measurement and is not overturned by it;
  a Rule 1 outcome returns the question to the user, it does not answer it.
- **Treating this as Phase 3 work.** Nothing here satisfies DEC-01..05 or is adopted downstream.
