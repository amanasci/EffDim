# Amendment 01 — Krein rejected; geomstats admitted for evaluation

**Written and committed before any geomstats measurement is taken.** Two pre-registered rules are
being overridden here. Recording that explicitly, dated, is the point — the credibility of every
earlier result in this milestone rests on rules not being edited quietly once evidence exists.

## 1. What is being overridden

### 1.1 The no-install prohibition

Every plan in Phase 02.1 carries a prohibition against installing any package, and
`02.1-PREREGISTRATION.md`'s Scope Constants register zero installs. That scoping was the
planner's, on the grounds that fitting a candidate is Phase 3 pipeline work which ROADMAP.md
excludes from this phase.

**Overridden by user directive.** `geomstats==2.8.0` is installed into the project venv and added
to `notebooks/requirements-notebooks.txt`. `pyproject.toml` and `src/effdim/` remain untouched,
so the standing milestone constraint holds.

### 1.2 The SUS package gate

`geomstats` is one of seven candidate libraries that returned `SUS` from the legitimacy checker
in `02.1-RESEARCH.md`'s Package Legitimacy Audit. The driver was an `unknown-downloads` signal gap
in this environment, not a substantive finding. Each install was gated behind a
`checkpoint:human-verify`.

**That gate is satisfied by the user's explicit instruction to add geomstats and test it.** No
other SUS-flagged package is thereby approved.

### 1.3 The GEOM-04 recommendation

`02.1-RECOMMENDATION.md` recommends pseudo-Euclidean/Krein-space retention with working dimension
`(p, q) = (8, 0)`.

**Rejected by user directive.** Plan `02.1-04`'s human-verify checkpoint is NOT approved and the
phase is NOT sealed. The recommendation document stands as written on disk — it is not edited or
retracted — but it no longer carries the phase's answer to GEOM-04. A revised recommendation must
be written after the geomstats evaluation, and it must state that Krein was evaluated, measured,
and rejected, along with why.

The measured evidence behind the Krein recommendation is unaffected by this rejection and remains
valid input: the correction-blindness table, both falsifier conditions, and the (p,q) ladder were
measured, not argued, and are recorded in `geometry_probes_43cf438bc944c509.json`.

## 2. Known defect in the admitted dependency

`geomstats==2.8.0` — the latest release — **is incompatible with numpy 2.x**. It imports
`numpy.trapz`, removed in numpy 2.0 and renamed `numpy.trapezoid`. Importing geomstats under this
project's pinned `numpy==2.5.1` raises `ImportError` at module load.

Downgrading numpy is **not** an option and was not considered further: `pu_manifold.config_key`
hashes the installed numpy version into every cache key, so a downgrade would invalidate
`isomap_43cf438bc944c509.joblib`, `mds_eigenspectrum_43cf438bc944c509.npz`, and every Phase 1/2
artifact keyed off them, destroying comparability with the frozen results this phase is measured
against.

**Mitigation:** a compatibility shim aliasing the removed numpy names is applied before importing
geomstats. It is confined to the diagnostic entry point, is documented at its point of use, and
touches nothing else. This is a defect in geomstats, recorded here rather than hidden, and it is
a fact a reader weighing geomstats as a Phase 3 dependency is owed.

## 3. What is NOT overridden

- Phase 2's four gate thresholds (0.10 / 0.05 / 0.25 / 0.15) and its FAIL verdict. Settled.
- The distortion statistic and the fixed 200,000-pair sample. Any geomstats representation is
  judged on the **same** statistic over the **same** pairs, or the comparison is meaningless.
- The bit-identity requirement on that pair sample.
- The Working-Dimension Rule's prohibition on reselecting a curve point after seeing evidence.
- The fork verdict (coordinate-producing), ratified at a blocking checkpoint. geomstats
  representations are coordinate-producing, so this evaluation stays inside the ratified branch.
- The measured δ-hyperbolicity result. `delta_rel_max = 0.383921` exceeds the flat-Euclidean
  anchor at `0.360433`, so **hyperbolic and mixed-curvature-with-hyperbolic-factor candidates
  remain measurably contraindicated**. A geomstats hyperbolic embedding may still be run, but it
  is running against a standing prediction that it will do badly, and a good result there would
  need explaining, not celebrating.

## 4. The comparison this authorizes

Each geomstats representation produces coordinates; its induced pairwise distances are compared
to the trusted geodesic distances from `isomap_43cf438bc944c509.joblib` over the fixed 200,000-pair
sample, under the existing statistic:

    DISTORTION = median(|d2_rep - d2_geo| / d2_geo)

Existing anchors it is measured against, all previously computed:

| Representation | median_abs_rel |
|---|---|
| classical MDS `(p=18, q=0)` best on the q=0 curve | 0.079864 |
| classical MDS `(p=8, q=0)` — the elbow | (see `krein_ladder`) |
| pseudo-Euclidean Krein `(p=40, q=25)` — best measured | 0.065190 |

**A geomstats representation is only interesting if it beats 0.065190 on this statistic.** Losing
to it is a legitimate, reportable outcome and must be reported as such rather than re-framed.
