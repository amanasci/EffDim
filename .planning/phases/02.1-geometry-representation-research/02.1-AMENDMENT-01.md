## 2. Known defect in the admitted dependency

`geomstats==2.8.0` is **incompatible with numpy 2.x** — imports `numpy.trapz` (removed in 2.0);
ImportError under the pinned numpy 2.5.1. Downgrading numpy is not an option: `config_key` hashes
the numpy version into every cache key, so a downgrade would invalidate every Phase 1/2 artifact.
Mitigation: a compatibility shim aliasing the removed names, confined to the diagnostic entry
point, documented at point of use. A fact any reader weighing geomstats for Phase 3 is owed.

## 4. The comparison authorized

`DISTORTION = median(|d2_rep − d2_geo|/d2_geo)`. Anchors: classical MDS (p=18,q=0) 0.079864;
Krein (40,25) **0.065190**. **A geomstats arm is only interesting if it beats 0.065190.** Losing
is a legitimate, reportable outcome.

**No geomstats arm beats Krein; both lose by ~an order of magnitude.** Why (not a verdict on the
library): both arms measure *ambient sphere* geometry — great-circle distance ignores the ~20-25-d
manifold inside S^767, and tangent PCA at the Fréchet mean is a global linear projection. geomstats
has no fit-to-a-geodesic-matrix primitive — a toolkit for calculus on an already-specified
manifold, useful to Phase 3 *after* a representation is chosen, wrong instrument for choosing one.
A fairer arm would require committing to a manifold and fitting points to it — Phase 3 pipeline
work this phase excludes.

Consistency check passed: Isomap's own d=18 embedding scores 0.079864, bit-equal to classical MDS
(p=18,q=0) — expected, and confirms the distortion pipeline end to end.
