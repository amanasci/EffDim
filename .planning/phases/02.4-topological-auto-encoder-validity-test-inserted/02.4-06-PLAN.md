<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| long-running compute → pre-registered constants | Nine hours is long enough for a constant to be "adjusted" mid-run to rescue a struggling fit; that would silently void the phase's guarantee |
| fit cfg → cache manifest | A cfg that drifted between fits would produce artifacts that look comparable and are not |
| interrupted run → partial registry | A registry missing a baseline at some rung would make that rung's margin unmeasurable while still looking complete |
