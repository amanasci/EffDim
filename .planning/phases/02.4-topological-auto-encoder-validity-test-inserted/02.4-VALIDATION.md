## Sampling Rate

- **After every task commit:** Run `python -m pytest notebooks/pu_manifold/tests/test_topoae.py -q`
- **After every plan wave:** Run `python -m pytest notebooks/pu_manifold/tests/ -q`
- **Before `/gsd-verify-work`:** Full suite green, **plus** `notebooks/02.4_swiss_roll_topoae_check.ipynb`
  executed end to end with zero error cells
- **Max feedback latency:** 90 seconds

Note: the long TopoAE fits (`topoae_train_run.py`) are **not** part of the sampled suite — they are
the gated phase artifact, run once under the pre-registration. The suite samples the code those
runs depend on.
