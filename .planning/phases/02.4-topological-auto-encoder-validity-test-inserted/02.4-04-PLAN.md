**Section 1 — Metric definitions.** Three gating metrics, exactly three, named
`t1_topo_fidelity`, `t2_recon_margin`, `t3_rank_structure`, in that order, matching
`topoae.GATING_METRICS`.

- **T1, topological fidelity.** The paper's own topological loss evaluated on held-out data
  (D-01) — not a combinatorial matched-pair fraction and not a Wasserstein diagram distance. The
  minimum spanning tree is built over the **entire** held-out set in one pass (D-03), because a
  latent can preserve every 64-point neighbourhood while scrambling how regions connect; the
  batch-wise average at training batch size is reported, non-gating, for consistency with how the
  loss was optimised. The loss is a sum of two directional terms, computed separately, and the
  **worse** one gates (D-04): input-to-latent catches destroyed structure, latent-to-input catches
  invented structure, and these are different failures. The gating quantity is
  `max(loss_x_to_z_topoae / loss_x_to_z_baseline, loss_z_to_x_topoae / loss_z_to_x_baseline)` —
  the ratio is formed per direction and the max taken over directions, never over a summed total.
- **T2, reconstruction margin.** `mse_per_dim` from `cae.reconstruction_stats` on held-out data,
  divided by the same quantity for the matched-capacity `cae.PlainAutoEncoder` at the same latent
  dimension, under CAE-03's must-beat-not-tie rule.
- **T3, rank structure.** `1 - min(trustworthiness, continuity)` at the gating neighbourhood size
  (D-06, D-10), divided by the same quantity for the matched baseline (D-08). Continuity is
  `sklearn.manifold.trustworthiness` with the two spaces swapped. Neighbourhood sweep {5, 15, 30},
  gating at 15 — the same `k*` 01-04's pre-registered plateau rule froze the Isomap graph at, so
  the gating neighbourhood inherits an existing justification; the other two rungs are reported
  sensitivity.

Record D-09 explicitly: T1 and T3 gate independently, both are two-sided and may correlate — T1's
minimum spanning tree measures the connectivity skeleton, T3 measures local neighbourhood
ordering, and a latent can preserve one while breaking the other — so a joint FAIL on both is
**one** structural finding, not two independent ones.

Record D-05's cost explicitly: latent coordinates are normalised by one global isotropic scalar,
`z / sqrt(mean(var(z, axis=0)))` (`topoae.latent_unit_scale`), rather than by a scale fitted from
a target as `cae.fit_global_scale` does. Per-dimension standardization is rejected because it is a
non-isometric rescaling that would change which points are nearest neighbours. Consequently 02.4's
T1 number is **not** directly comparable to 02.2's CAE distortion figure — a different
normalisation is a different statistic, and no later reader should compare them.

Record the ambient normalization resolution as its own named constant
`AMBIENT_DIST_NORM = "none"`: raw float64 Euclidean distances, identically at training time and at
the T1 gate, because the ambient data is L2-normalized onto the unit sphere and the paper's
per-batch-maximum convention would differ between the 64-point training batches and the whole-set
gate. This resolves `02.4-RESEARCH.md` Open Question 1, which no locked decision covered.

**Section 2 — Numeric PASS thresholds and their derivation.**

- `THRESH_T1 = 0.90`. The worse-direction held-out topological loss must be strictly below 0.90
  times the matched baseline's — a ten percent margin, the same size 02.2 used for CAE-03.
  Justification: topological signature matching is this method's own central published claim, so
  a margin is warranted; a threshold at 1.00 would be cleared by a numerically trivial improvement
  the method achieves by construction, and would measure nothing.
- `THRESH_T2 = 1.00`. Held-out `mse_per_dim` must be strictly below the matched baseline's.
  Justification: CAE-03's rule is literally "must beat, not tie", and strict less-than against
  1.00 encodes precisely that and no more. 02.2's additional discretionary ten percent is **not**
  inherited, and the reason must be stated: the published method claims topological fidelity at
  comparable reconstruction, not better reconstruction, so importing a ten percent reconstruction
  margin would gate this method on a claim it never made — the same category error R4 forbids for
  geodesic distortion.
- `THRESH_T3 = 0.90`. `1 - min(trustworthiness, continuity)` at the gating neighbourhood size must
  be strictly below 0.90 times the matched baseline's, the same margin and the same reasoning as
  T1, since rank-structure preservation is also a claim the paper makes for itself.

State the verdict rule verbatim: PASS requires all three gates to hold; every comparison is strict
less-than, so a value exactly at a threshold does not clear it; there is no MARGINAL tier, because
every non-PASS outcome routes to the same halt-for-user-decision consequence. State that a run in
which any gating metric is absent or non-finite halts and writes no verdict at all.
