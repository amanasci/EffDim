<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| measured metrics → verdict | An absent, non-finite or wrongly-reduced metric crossing into the verdict is the one way a FAIL becomes an undetected PASS |
| verdict artifact → Phase 3 | The handoff is the only thing a downstream phase reads before spending compute; a stale one is indistinguishable from a live one |
| non-gating context → gate | Distortion sitting anywhere near the gate would rank this method on an axis it never optimised |
| partial fit registry → verdict | A verdict computed from whatever fits happen to be on disk would look identical to one computed from all sixteen |
