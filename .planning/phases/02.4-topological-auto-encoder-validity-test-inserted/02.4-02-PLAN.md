Add the three gate statistics to `topoae.py`.

`topological_fidelity(x, z)` — T1's raw statistic, per D-01/D-03/D-04/D-05. Take the **entire**
held-out array in one pass (n ≈ 2,000; a 2,000×2,000 float64 matrix is trivial), not a batch-wise
average: a latent can preserve every 64-point neighbourhood while scrambling how regions connect,
and D-03 gates on global topology. Compute `d_x = pairwise_distances_f64(x)` with **no ambient
normalization** — this resolves `02.4-RESEARCH.md` Open Question 1, and the docstring must record
the resolution and its reason: the PU ambient data is L2-normalized onto the unit sphere so its
Euclidean distances are already bounded in [0, 2], and the Swiss roll fixture is divided by one
global standard deviation, so both are O(1) without any per-batch-maximum rescaling; the paper's
per-batch-max convention is deliberately not adopted because a per-batch maximum differs between
the batch-wise training loss and this whole-set gate, which would make the two incomparable.
Compute `d_z = pairwise_distances_f64(z * latent_unit_scale(z))`. Then return
`topological_loss(d_x, d_z)`'s two directional terms as native floats plus
`worse = max(loss_x_to_z, loss_z_to_x)`. The docstring must state that input→latent catches
destroyed structure, latent→input catches invented structure, these are different failures, and
that summing them (which is what the *training* loss does) would collapse the two failure modes
D-04 keeps apart.

`rank_structure(x_ambient, z_latent, k)` — T3's raw statistic, per D-06/D-07/D-10. Two calls to
`sklearn.manifold.trustworthiness`: `trustworthiness(x_ambient, z_latent, n_neighbors=k)` and
`trustworthiness(z_latent, x_ambient, n_neighbors=k)`, the second being continuity by definition
(it is the same identity the paper's own reference `measures.py` uses). Do not hand-roll
continuity. Return `{"trustworthiness", "continuity", "gate_value"}` where
`gate_value = 1.0 - min(trustworthiness, continuity)` — the inversion D-10 requires so that
higher-is-better becomes lower-is-better and the strict-less-than comparison runs the same
direction as T1 and T2. Note in the docstring that `sklearn` raises when
`n_neighbors >= n_samples / 2`, which at the planned holdout size of ~2,000 and the k sweep
{5, 15, 30} is far from binding, so a future holdout-fraction change surfaces as an error rather
than a silent `nan`.

`t1_gate_value(fid_model, fid_baseline)`, `t2_gate_value(stats_model, stats_baseline)`,
`t3_gate_value(rank_model, rank_baseline)` — the baseline-relative margins D-02/D-08 lock and
that T2 inherits from CAE-03. Each returns `model_quantity / baseline_quantity` as a float:
T1 uses `worse` from each side, T2 uses `mse_per_dim` from each `cae.reconstruction_stats` dict,
T3 uses `gate_value` from each side. Each raises a `ValueError` naming the metric when the
baseline quantity is zero or non-finite — a division that silently produces `inf` must never
reach the verdict. Docstring for `t1_gate_value` records the per-direction alternative that was
rejected: forming one ratio from the summed `total` would collapse D-04's two failure modes, so
the max is taken over the two *directional* terms of each side before the ratio, exactly as
`cae_evaluate_run.py` takes a max over two controls.

`unfaithfulness_adapter(model, z_reference)` — the non-gating context metric's shim. Returns a
lightweight duck-typed object with `chart_dim = model.latent_dim`, `out_dim` equal to the ambient
dimension, `chart_decoders = [f]` where `f` is the affine map carrying the unit box `[0,1]^d`
onto the componentwise min/max bounding box of `z_reference`, and `embedding_decoder =
model.decode`, so `cae.unfaithfulness_coverage(adapter, x_holdout, [0], n_samples, seed)` runs
unmodified against a TopoAE. The affine map is what keeps the numbers comparable with 02.2's:
CAE chart coordinates live in `(0,1)^d` by construction while a TopoAE latent is unbounded, so
without the map the uniform sample would fall almost entirely outside the latent's support.
Record that rescaling in the docstring as a stated difference from 02.2's measurement, the same
way D-05 records T1's non-comparability.

Then add the five tests named in `<behavior>`, all on the small synthetic fixture, all inside the
