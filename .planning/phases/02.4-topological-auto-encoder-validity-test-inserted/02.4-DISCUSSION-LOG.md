## T1 — The Topological Fidelity Statistic

### Which scalar?

| Option | Description | Selected |
|--------|-------------|----------|
| Matched-pair fraction | `\|π_X ∩ π_Z\| / \|π_X\|` — scale-free, not the training objective, coarse | |
| The paper's `L_t`, held out | Compare edge lengths at selected index pairs, both directions, exactly as trained | ✓ |
| Wasserstein between diagrams | Optimal matching of the two 0-dim diagrams; blind to which points paired | |

**User's choice:** the paper's `L_t` on held-out data.
**Notes:** chosen over the recommendation. Buys comparability with published numbers and measures
the method's own claim, at the cost of gating on a held-out evaluation of the training objective and
inheriting the latent's arbitrary scale — which drove the follow-up question below.

### Where does the threshold come from?

| Option | Description | Selected |
|--------|-------------|----------|
| Baseline-relative margin | Beat the matched `PlainAutoEncoder` by a pre-registered margin | ✓ |
| Absolute, Swiss-roll calibrated | Set from what a known-good recovery scores on the fixture | |
| Beat baseline AND a null | Two conditions, adding a random-projection floor | |

**User's choice:** baseline-relative margin.

### Computed over what?

| Option | Description | Selected |
|--------|-------------|----------|
| Full held-out set, batch-wise reported | Gate on global MST at n≈2,000; batch-wise non-gating | ✓ |
| Batch-wise average only | Matches training, blind to global scrambling | |
| Both must pass | Closes local/global gap, doubles threshold work | |

**User's choice:** full held-out set gates, batch-wise reported.

### One direction or two?

| Option | Description | Selected |
|--------|-------------|----------|
| Both, gate on the worse | Catches destroyed AND invented structure; matches Phase 2's r/m rule | ✓ |
| Input→latent only | Simplest; blind to hallucinated adjacency | |
| Symmetric average | Closest to the paper; an average lets one direction mask the other | |

**User's choice:** both directions, worse gates.

### Follow-up: latent scale (raised because `L_t` compares lengths)

| Option | Description | Selected |
|--------|-------------|----------|
| Fit one global scale, as 02.2 did | Reuse `cae.fit_global_scale`, disclose the fitted value | |
| Normalise each latent to unit variance | Nothing fitted from the target; different statistic than 02.2's | ✓ |
| Report raw | Margin absorbs it; margin then partly measures a scale difference | |

**User's choice:** unit-variance normalisation.
**Notes:** chosen over the recommendation. Cleaner in that nothing is fitted from the target, but it
means 02.4's T1 is **not** directly comparable to 02.2's CAE distortion number. Recorded as a stated
cost in CONTEXT.md D-05 rather than left to surprise a later reader.

## Latent Ladder, Primary Dimension, and Seeds

### Ladder values?

| Option | Description | Selected |
|--------|-------------|----------|
| {8, 20, 40} | Three rungs, each answering a prior claim | |
| {20, 40} | Two rungs, cheapest, no point below the cluster | |
| {8, 16, 24, 32, 40} | Five rungs, a real curve; collides with the ceiling | ✓ |

**User's choice:** the five-rung ladder — then amended to six (below).

### Primary rung?

| Option | Description | Selected |
|--------|-------------|----------|
| d = 20 | Inside the local intrinsic cluster; matches 02.2's D_CHART exactly | ✓ |
| d = 40 | Takes dimension-starvation at face value; loses comparability | |

**User's choice:** d = 20.

### Seeds?

| Option | Description | Selected |
|--------|-------------|----------|
| 3 on primary, 1 on others | Verdict rung gets the variance estimate | ✓ |
| 3 on every rung | Uniform rigour; ~18h | |
| 1 everywhere, replicate on FAIL | Fastest; a PASS would rest on one seed | |

**User's choice:** 3 on primary, 1 elsewhere.

### Seed spread in the verdict?

| Option | Description | Selected |
|--------|-------------|----------|
| Worst seed gates, spread reported | PASS means "works reliably", matches worse-of-two elsewhere | ✓ |
| Mean gates | Standard; two good seeds can mask one failure | |
| Median gates | Robust, but discards best and worst at n=3 | |

**User's choice:** worst seed gates.

### Conflict resolution (raised by Claude after the above)

Two inconsistencies were surfaced rather than silently resolved:

1. **`d = 20` was not in the chosen ladder `{8, 16, 24, 32, 40}`** — a primary rung outside the sweep
   would be an unpre-registered configuration, exactly what SPEC prohibition 2 forbids.
2. **The finer ladder broke the compute envelope** — 5 rungs at 3+1 seeds is 7 fits × 2h = 14h
   against 02.2's 8–10h envelope; 6 rungs is 16h.

| Question | Options | Selected |
|----------|---------|----------|
| Primary fix | Insert 20 → `{8, 16, 20, 24, 32, 40}` | ✓ |
| | Primary becomes 24 | |
| | Swap 24 for 20 | |
| Compute | Lower the per-fit ceiling 2h → 1h | ✓ |
| | Widen the envelope to ~16h | |
| | Drop to 2 seeds on primary | |

**User's choice:** six-rung ladder with 20 inserted; per-fit ceiling cut to ~1h.
**Notes:** the ceiling cut carries a stated limitation — the larger rungs (32, 40) may be
under-trained at 1h, and the primary rung must be verified to converge within the cap before the
ladder is committed.
