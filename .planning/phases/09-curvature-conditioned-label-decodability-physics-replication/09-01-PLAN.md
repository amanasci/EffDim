<ordering_resolution>
## Tracer-first vs. freeze-before-any-number — resolved, not left implicit

D9-18 requires every Phase 9 constant to land in one freeze commit that is git-ancestry-proved to
precede **every measured value on the Physics embeddings**. A tracer that measured a Physics
number first would break the phase's central discipline — the same failure mode `02.2`'s sealed
FAIL and `08-PREREGISTRATION-AMENDMENT-01` both record, and the reason Phase 8's own tracer ran on
synthetic pairs.

**Resolution adopted:** the tracer runs entirely on **synthetic arrays generated in-process from a
fixed RNG seed**, where the alignment answer is known by construction (the label vector is built
from the embedding matrix at a known offset) and the curvature answer is anchored by a d-sphere
fixture whose `H_rad` is analytically `-d`. It touches every layer the phase will ever touch —
loader seam, alignment curve, OOF probe, AE fit, curvature, decomposition, partial, null, record
writer — so it is a genuine end-to-end slice, and it opens no HuggingFace dataset, so no Physics
number exists before the freeze.

**Mechanism that keeps it honest:** every gating constant in both modules is declared UNSET in
this plan (`None` for scalars, `()` for tuples and sequences, `""` for rule strings, `{}` for the
label-column map). Both `assert_preregistered()` functions raise here, and the commit that fills
them (09-05) is the freeze commit. Every pure function therefore takes its parameters as explicit
arguments — `alpha`, `k`, `n_folds`, `fold_seed`, `n_permutations` are all passed in, never read
from a module constant at a call site that only sees part of the problem. `--mode smoke` supplies
its own tiny literals at the call site and writes no `verdict` key.
</ordering_resolution>

From `notebooks/pu_manifold/cross_split_curvature.py` (line 232):
`partial_spearman(x, y, controls=None) -> float` — rank-transforms `x`, `y` and every column of
`controls`, residualises both against the rank-transformed controls with an intercept by least
