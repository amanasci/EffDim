**`run_dsweep(args)`** — the deliverable. Once, before the `d` loop: load the embeddings through
`physics_labels.load_physics_embeddings()`; load the label table for every canonical name in
`LABEL_COLUMN_MAP`; apply `ALIGNMENT_ASSUMED_OFFSET` when building each label vector, so an
adopted offset from 09-07 reaches every label through one constant; compute
`anchor_indices(n_rows, SPLIT_SEED, HOLDOUT_FRACTION, N_ANCHORS, ANCHOR_DRAW_SEED)`; compute
`knn_panel(X, anchor_idx, K_NEIGHBOURS)` once — the neighbourhoods are over all 86,471 rows and are
independent of the autoencoder split and of `d`; and compute
`oof_ridge_predictions(X, y, ALPHA_RIDGE, N_OOF_FOLDS, OOF_FOLD_SEED)` once per label — the probe
is one global fit, also independent of `d`. Record the wallclock of each of these once-only steps.

Then, serially for each `d` in `D_SWEEP` order: `fit_and_field_at_anchors` at the frozen protocol,
capturing `H_vec` and `model.decode(z_anchors)`; `decompose_radial_tangential(H_vec, image,
MIN_IMAGE_NORM)`; and for each label, `local_r2_panel(y, y_hat, neighbour_idx,
MIN_FINITE_NEIGHBOURS)`. Assemble the anchor table with the columns named in this plan's
`must_haves` and write it to `09_anchor_table_d{d}_{label}.npz` under the resolved output root.
Compute `controlled_partial` on `H_tan_norm` and, separately, on `H_norm`, each against the local
`r2` with the three-column control matrix; compute the raw Spearman beside each;
compute `stratified_partial_null_3control` on `log_knn_radius` strata at each entry of
`STRATA_GRID`; and compute `paired_anchor_bootstrap`. Append one record row per row kind.

After the `d` loop, compute `permutation_fwer` across ALL `d` at once — the family-wise envelope
needs every `d`'s curvature array against a common surrogate per draw — and append the per-`d` and
global rows. Print a per-`d` banner as each `d` starts, showing the cost-model estimate beside the
elapsed time so a human watching a multi-hour run can see whether it is on pace.

Record, per `d`: `var_explained`, median `cond(g)`, the `H_rad` median beside `-d`, the count of
anchors excluded for low image norm, and the per-label masked-anchor counts. Record whether
`local_evaluation_count` was constant for each label, since for a fully-populated label it will be
and the three-control partial then equals the two-control partial.

**`run_positive_control(args)`** — requires `--field-npz` naming a Wave A anchor table and refuses
to regenerate one, following `07_crossmodal_curvature_run.py`'s own discipline. Read the realized
`H_tan_norm`, the local `r2` and the three controls from that table. For each target in
`POSITIVE_CONTROL_TARGET_RHOS`, call `plant_curvature_positive_control` and push the planted array
through the identical three-control partial and `permutation_fwer`'s Freedman-Lane construction —
not `two_tailed_permutation_null`, which is Phase 7's null and the wrong one here. Record achieved
partial, target, cleared or not, and the null's `p_display` per target; print the smallest cleared
target as the detection floor.

**`run_shuffled_label(args)`** — requires `--field-npz` likewise. For `SHUFFLED_LABEL_REPEATS`
repeats from `SHUFFLED_LABEL_SEED`, call `shuffled_label_repeat`, holding the embedding matrix,
the curvature field and the anchor index array byte-identical and recomputing only the out-of-fold
predictions and both label-derived controls. Record each repeat's controlled partial, its null
`p_display`, whether it cleared, and the masked-anchor count. Print the false-positive count as a
fraction of the repeat count and beside the nominal `FWER_ALPHA`.

**`run_verdict(args)`** — reads the record and the anchor tables and recomputes nothing, so the
printed verdict cannot differ from the recorded numbers. Exit 2 with a message when the record
