RESIDUAL METRIC. `RESIDUAL_METRIC = "squared_l2_per_point"` — per-point
`r_i = sum_j (y_ij - yhat_ij)^2` — paired with `R2_MULTIOUTPUT = "variance_weighted"`. This is the
one pairing that satisfies 05-CONTEXT.md's "R-squared and per-point residual derivable from one
underlying quantity" constraint exactly, because the variance-weighted aggregate is
`1 - sum_i r_i / sum_i ||y_i - ybar||^2`, the same numerator as the per-point residual. Uniform
averaging across outputs does not share that numerator and is rejected. `05-01` Task 2 pins the
identity numerically rather than accepting the library's documented behaviour on citation.

`||H||` field over all 10,000 points by stable argsort and `np.array_split`, with a value equal to
an edge assigned to the HIGHER bucket. `BUCKET_EDGES` = the two float64 values read verbatim from
