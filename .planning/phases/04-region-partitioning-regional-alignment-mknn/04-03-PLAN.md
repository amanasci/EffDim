someone else produced. The estimator that produces that field is already covered by
`notebooks/02.5_swiss_roll_curvature_probe_check.ipynb`. The known-answer coverage this helper *can*
have is the two-antipodal-cone fixture in Task 1, which is a stricter test of the split itself than

`canonical_eigvec_sign(v)` returns `v` multiplied by the sign of its largest-magnitude component, so
that component is positive. `numpy.linalg.eigh` returns eigenvectors with an arbitrary sign; without
this the region labels would flip between otherwise identical runs.

`region_partition(H, min_norm_percentile)` implements D4-09's diametrical sign split.
`min_norm_percentile` is a required argument with no default, following the module conventions for a
pre-registered constant. Steps, in order: compute `norm = np.linalg.norm(H, axis=1)`; take
`floor = np.percentile(norm, min_norm_percentile)`; set `keep = norm >= floor` (greater-than-or-equal,
so a point exactly at the percentile is kept — a stated, deterministic tie rule); normalize the
surviving rows with the codebase's `np.maximum(..., 1e-12)` floor idiom; form the mean-centered
covariance `np.cov(unit, rowvar=False)`; take `eigvals, eigvecs = np.linalg.eigh(cov)` and
`v = canonical_eigvec_sign(eigvecs[:, np.argmax(eigvals)])`; compute `proj = unit @ v`; label
`np.where(proj >= 0, 0, 1)` — a projection of exactly 0.0 goes to region 0. Return a dict with `v`,
`labels`, `keep_idx`, `excluded_idx`, `proj`, `h_norm`, `floor`, `min_norm_percentile`,
`n_zero_projection`, `eigval_top`, `eigval_spectrum`, and `mean_unit_norm`
(`np.linalg.norm(unit.mean(axis=0))`).

`mean_unit_norm` is reported because D4-09's phrase is "the unit-`H` covariance" while the
diametrical-clustering literature conventionally uses the *uncentered* second-moment matrix. The two
coincide when the unit-vector mean is near zero. This module declares the mean-centered form —
matching 04-PATTERNS.md's composed snippet and D4-09's own word — and prints `mean_unit_norm` so a
reader can see for themselves whether the distinction bites on PU. It is not resolved silently.

Guards raising `ValueError` naming the offending argument: `H` non-finite; `H` not two-dimensional;
fewer than 2 surviving points after exclusion; `min_norm_percentile` outside `[0, 100)`.

`region_counts(labels, n_excluded)` returns `n_region_0`, `n_region_1`, `n_excluded`, `n_total`,
`fraction_region_0`, `fraction_region_1`, `fraction_excluded` and `n_zero_projection`, with counts
from `np.bincount(labels, minlength=2)` as plain ints and fractions to float.
