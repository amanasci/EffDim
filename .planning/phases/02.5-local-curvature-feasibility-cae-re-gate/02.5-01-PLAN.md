They are binding on every plan in this phase.

**OQ-1 — where stage-2 decoder-curvature code lives.** RESOLVED: new phase-scoped modules.
Stage 1's estimator goes in a new `notebooks/pu_manifold/curvature_probe.py`; stage 2's
`torch.func` chart-decoder differentiation goes in a new `notebooks/pu_manifold/chart_curvature.py`
(plan 02.5-08). `notebooks/pu_manifold/curvature.py`'s four `NotImplementedError` stubs
(`first_fundamental_form`, `second_fundamental_form`, `mean_curvature_vector`,
`metric_condition_number`, lines 18-35) are **not** edited, **not** filled, and **not** imported.
Rationale: each stub docstring reads `"Implemented in Phase 3 (CURV-0N)"` and
`.planning/REQUIREMENTS.md` maps CURV-01..08 to Phase 3 with status Pending. Filling them here
would silently deliver CURV-01..03 ahead of schedule and make a requirements-completion event out
of an incidental file choice. This is a stated, deliberate duplication of mathematics, not an
oversight.

**OQ-CONV — the curvature convention is inconsistent inside RESEARCH.md and is resolved here.**
RESEARCH.md's Pattern 1 derives `E[c - p] = (r^2/(2(d+2))) * H` with `H = tr(II)` (the
*unnormalized trace*), and `curvature.py`'s own stub docstring says "g-trace of the second
fundamental form", and RESEARCH.md's Pattern 4 computes `H = einsum("bij,boij->bo", g_inv, II)`
which is also the unnormalized g-trace. But RESEARCH.md's `swiss_roll_analytic_H` returns
`(t**2 + 2) / (2 * (1 + t**2)**1.5)`, which is `kappa(t)/2` — the *averaged* convention. These
differ by a factor of `d`: a factor of 2 at the Swiss roll's `d=2` and a factor of 20 at the PU
regime's `d=20`. Spearman is invariant to the factor so the D-01 gate is unaffected, but D-01's
non-gating median relative error and D-05's estimator-agreement check would both be wrong by
`d`. RESOLVED: this phase uses the **trace convention `H = tr(II)` everywhere**, matching
`curvature.py`'s stub, Pattern 1, and Pattern 4. Therefore the Swiss roll's analytic mean
curvature under this phase's convention is `kappa(t) = (t^2 + 2)/(1 + t^2)^{3/2}` — RESEARCH.md's
formula *without* the factor of 2 in the denominator — because the Swiss roll surface is a ruled
generalized cylinder whose second principal curvature is exactly 0, so `tr(II) = kappa + 0`.
Task 2's `test_curvature_convention_is_trace_not_averaged` pins this so it cannot drift.

   illustrative only; this is the deliberate deviation. Raise `ValueError` naming `d` and `k` if
