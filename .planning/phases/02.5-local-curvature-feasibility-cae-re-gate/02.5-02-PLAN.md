built here. RESEARCH.md Open Question 2 notes that Pattern 3's recommended `m = 1` Gaussian bump
is codimension 1, while the real regime is codimension ~748 (`D = 768`, `d ≈ 20`), and asks
whether a low-codimension fixture's boundary transfers honestly. It does not transfer without
being checked, and checking is cheap: `make_graph_of_function_fixture` takes an `n_bumps`

ambient dimension and codimension-of-curvature are independently controllable. If the two
variants disagree about where the boundary sits, that disagreement is itself the finding and
belongs in `02.5-FINDINGS.md`.

Add three functions to `notebooks/pu_manifold/curvature_probe.py`, keeping the module numpy-only.

`gaussian_bump_values(x, amplitudes, centres, sigma)` — for `x` of shape `(n, d)` and `m` bumps
given by `amplitudes` `(m,)`, `centres` `(m, d)` and a scalar `sigma`, returns a dict with
`"f"` `(n, m)`, `"grad"` `(n, m, d)`, and `"hess"` `(n, m, d, d)`. Use the closed forms:
for bump `j`, `f_j = A_j * exp(-||x - c_j||^2 / (2*sigma^2))`,
`grad f_j = -((x - c_j)/sigma^2) * f_j`, and
`hess f_j = f_j * (outer(x - c_j, x - c_j)/sigma^4 - I/sigma^2)`. Build the Hessian with
`np.einsum` over the batch; do not loop over `n`.

`graph_mean_curvature(grad, hess)` — the **exact** graph mean curvature under this module's trace
convention (`CURVATURE_CONVENTION = "trace"`), for a graph `M = {(x, f(x))}` with `f: R^d -> R^m`.
RESEARCH.md's Pattern 3 snippet gives only the leading-order codimension-1 form and says in its
own docstring that it is illustrative — use the exact form instead. Implement it as the general
graph construction: the tangent frame is `J = [I_d ; Df]` of shape `(d + m, d)`, the induced
metric is `g = I_d + Df^T Df` of shape `(d, d)`, the ambient second derivative of the embedding
is non-zero only in the `m` graph components, and the mean curvature vector is the `g`-trace of
the normal projection of that Hessian:
`H = P_normal( einsum('ij,cij->c', inv(g), Hess_embedding) )` where `Hess_embedding` has the `d`
identity components zero and the `m` components equal to `hess`. Compute `P_normal` as
`I_{d+m} - J g^{-1} J^T`. Return the `(n, d + m)` mean curvature vectors. For `m = 1` this must
reduce to the textbook `div(grad f / sqrt(1 + |grad f|^2))` result multiplied by nothing — i.e.
the trace convention, not the averaged one — and Task 1's test pins that against finite
differences rather than against a hand-transcribed formula.

`make_graph_of_function_fixture(n, d, D, n_bumps, seed, sigma=0.6, amplitude=1.0, density_skew=0.0, domain_radius=2.0)`

centres from a fixed-seed RNG inside the domain and set amplitudes to `amplitude` times a
fixed-seed sign pattern so bumps both bulge and dent. Embed as

one global scalar `X.std()`, record it as `"global_std"`, and scale `H_vec`/`H_norm` by that same

totally geodesic and carry no curvature, which is what makes `D` and codimension-of-curvature

Add `local_density_weights(X, k_density, d)` to `curvature_probe.py`. It returns `(n,)` weights
`w_i = 1 / rho_i` where `rho_i` is the standard k-NN density estimate at point `i`:
`rho_i = k_density / (n * V_d * r_i**d)` with `r_i` the distance from `i` to its `k_density`-th
nearest neighbour and `V_d = pi**(d/2) / gamma(d/2 + 1)` the unit `d`-ball volume (use
`scipy.special.gammaln` for numerical stability at `d = 20`, where `V_d` underflows a naive
`gamma` call). Normalize the returned weights to mean 1 so the correction cannot change the
overall scale. Docstring must state D-06's rationale in two sentences and must state explicitly
that `k_density` is the correction's **only** constant, that it is pre-registered in
`02.5-PREREGISTRATION.md`, and that there is deliberately no continuous regularization strength —
per D-05's rejection of a blind pre-registered dial.

Extend `centroid_mean_curvature` with two new keyword arguments: `density_correct: bool = False`
and `k_density: Optional[int] = None`. When `density_correct` is True: require `k_density` (raise
`ValueError` naming it if None), compute `w = local_density_weights(X, k_density, d)` once for the
whole cloud, and inside each neighbourhood replace the plain centroid and plain mean squared
radius with their `w`-weighted counterparts — `c = sum(w_j q_j) / sum(w_j)` and
`r2 = sum(w_j |q_j - p|^2) / sum(w_j)` over the neighbours `j` of `p`. Everything else (tangent
basis, normal projection, `2*(d+2)/r2` rescaling) is unchanged. Keep `density_correct=False` as
the default so the uncorrected estimator stays available as the contrast arm the D-06 proof needs.

sampling against `w(x) = exp(density_skew * <x, u>/domain_radius)` for a fixed-seed unit vector
