## Estimator & the underdetermination

### Q1 — Fit the full second fundamental form, or go for the mean curvature vector?

| Option | Description | Selected |
|--------|-------------|----------|
| Average-the-neighbours gates, bowl-fit reported | Centroid/Laplace–Beltrami gates; quadric fit as cross-check | ✓ |
| Average-the-neighbours only | Simplest; no independent check | |
| Bowl fit with regularization | Full tensor; regularization strength becomes a blind-pre-registered dial | |
| Run both as equal arms | Most information; defers the gating choice past pre-registration | |

**Notes:** The pivotal exchange of the discussion. Orchestrator identified that the `d(d+1)/2` count recorded in the ROADMAP re-scope applies to the **full** second fundamental form, while mean curvature is only its trace — recoverable via `Δ_M x = H` as an average over `k` vectors. This may mean the underdetermination does not bind at all. Two rounds of jargon explanation were requested and given before the decision.

### Q2 — How is non-uniform sampling density handled?

| Option | Description | Selected |
|--------|-------------|----------|

| Both arms: corrected and uncorrected | Quantifies contamination; more compute | |
| No correction — assume uniformity | Risks reporting clustering as curvature | |

**Notes:** Orchestrator flagged that a Swiss roll is evenly sampled by construction and would not catch this failure mode.

### Q3 — What working dimension does the tangent estimate use?
